💡 评估判定：该论文改进过程奖励模型（PRM），通过全局视角和四维评估提升步级验证准确性，属于推理扩展中验证器的核心组件；但未提出新的测试期训练或搜索算法，主要是PRM增强。机构为阿里巴巴与上海交大等，权威度中上。
白话概述：传统过程奖励模型（PRM）像只拿前半段草稿给每一步打分，容易误判：有些步骤当时看着错，后面却可能被修正或关键。GPRM 把问题、前面步骤及其对错标签、当前步和后续步骤一起喂给模型，从“回看历史是否自洽、前瞻未来是否合理、本步是否自检成立、是否服务最终目标”四个维度判断当前步对错。关键做法是把历史步骤和标签拼成文本序列、构造四维标注数据，再用监督微调（SFT）和 GRPO 强化学习训练；直觉是给评审员同时看前文和后文，比只看前文更准。
输入 Input: 问题文本、推理轨迹中的历史步骤及其预测正确性标签、当前步骤、未来步骤文本（推理时未来步骤可由模型生成完整轨迹获得）。
输出 Output: 每个推理步骤的正确性标签或正确概率，用于过程监督与测试时搜索验证。
核心机制与技术实现 (Method & Formulation)
  • 将第 $i$ 步评估建模为结构化预测：输入包含问题 $Q$、历史步骤及其预测标签 $\mathcal{H}_i=\{(s_j,\hat{y}_j)\}_{j=1}^{i-1}$、当前步 $s_i$ 和未来步 $\mathcal{F}_i=\{s_j\}_{j=i+1}^n$，使模型利用完整上下文诊断。
  • 设计回顾、前瞻、自检、目标对齐四维评估框架，并据此构造SFT与GRPO训练数据，用Qwen3-235B作为教师模型做错误注入和标注。
  • 采用SFT加GRPO两阶段训练：先获得基础步级评估能力，再用强化学习优化四维判断一致性，最终提升PRMBench和ProcessBench表现。
关键评测与消融结论 (Empirical Takeaway)
GPRM-4B在PRMBench和ProcessBench上分别达73.9和74.3，超过GPT-4o等强基线；在Greedy Guided Search@8测试时搜索中平均55.0，显著高于R-PRM-7B-DPO的49.4。

💡 评估判定：论文聚焦 SAE 在自消耗训练下的可靠性与表征漂移，属于机械可解释性方向（SAE 与稀疏探针）的扎实分析工作，但未触及 RLHF/DPO/RLAIF 等后训练强化学习算法，且主要贡献为诊断性分析而非新训练机制，故相关性未给满分；俄亥俄州立大学为知名研究型大学，实验覆盖两个模型、五代谱系与多种 SAE 配置，但评测仍以 SAE 诊断为主。
白话概述：论文研究一个实际问题：的大模型如果不断用自己生成的文本继续训练（自消耗训练，self-consuming），它内部的“神经元激活”会悄悄变化，那么之前训练好的稀疏自编码器（SAE）还能不能用来解读模型？SAE 可以通俗理解为一本“特征字典”：把高维、混乱的激活向量拆成少量可读的语义特征。该研究用相同预算的真实数据训练，并设置对照谱系，区分两种失效原因：一种是字典“过期”（激活分布变了，字典没有更新），另一种是表征几何真的变了（字典所描述的空间结构发生了改变）。接着区分“冻结不动的 SAE”和“在新一代激活上微调的 SAE”，并用稀疏探针检验任务信息是否仍集中在少数特征上。结论是：微调能修好“重构保真度”，也就是能把激活还原得更接近原值，却修不好“特征可用性”：信息还在，但不再集中于少数清晰特征。
输入 Input: 语言模型指定隐藏层的激活向量（Pythia-160M 第 8 层，Gemma-2-2B 第 5/12/19 层）、各代合成或真实训练语料，以及 SAE 的宽度与架构设定（BatchTopK、JumpReLU、Matryoshka-BatchTopK）。
输出 Output: 各代 SAE 的重构误差、$L_0$ 稀疏度、解释方差、top-$k$ 与全空间稀疏探针准确率、SCR/TPP 因果消融指标，以及相对匹配真实谱系的 damage 量化值。
核心机制与技术实现 (Method & Formulation)
  • 构造匹配双谱系：合成谱系 $p_{\mathrm{syn}}^{(t)}=\mathcal{A}(p_{\mathrm{syn}}^{(t-1)};\tilde{\mathcal{D}}^{(t)})$ 与真实数据谱系 $p_{\mathrm{real}}^{(t)}=\mathcal{A}(p_{\mathrm{real}}^{(t-1)};\mathcal{D}_{\mathrm{real}}^{(t)})$ 共享初始化、token 预算与优化器，从而把自消耗效应与一般持续训练效应分开。
  • 对比冻结 SAE $S^{(0)}$ 的零样本迁移与微调 SAE $S_{\ell}^{(t)}=\mathrm{SAEFT}(S^{(0)};h_{\ell}^{(t)})$，并用 $\mathrm{Damage}_m^{(t)}$ 衡量合成谱系相对真实谱系在各指标上的退化。
  • 以线性自编码器为代理推导过期字典惩罚 $S_{\ell}(t)=\mathrm{tr}[(P_{\ell}^{(t)}-P^{(0)})\Sigma_{\ell}^{(t)}]\ge 0$，用主角度与特征间隙给出上下界，说明重构恢复不等于特征可解释性恢复，并以 top-$k$ 与全 SAE 稀疏探针验证信息分散。
关键评测与消融结论 (Empirical Takeaway)
在 Pythia-160M 与 Gemma-2-2B 的五代实验中，冻结 SAE 的重构与稀疏度 damage 逐代累积，微调基本恢复重构但 top-$k$ 稀疏探针显示任务信息从少数 latents 分散到更大子空间，第 5 代合成谱系在真实文本上的困惑度升至约 2.13 倍。

💡 评估判定：论文直接面向 DPO 偏好优化与 LLM 后训练，提出对比激活引导的零阶优化与低秩动量，属于 RLHF/偏好优化核心赛道；但不涉及机械可解释性，实验仅限 Qwen2.5-1.5B 与 HH-RLHF，机构为乌普萨拉大学，权威度与评测广度中等。
白话概述：大模型做 DPO 偏好对齐通常要反向传播，必须保存每一层的中间激活，显存开销大。零阶优化则用“只试不导”的办法：在参数上撒随机方向、看损失往哪边降，从而绕开反向传播；但撒扰动的方向是各向同性的（四面八方均匀乱撒），大多与被选回复、被拒回复之间的差别无关，信号被噪声淹没。本文把每条偏好对里 chosen 与 rejected 的激活差提取成一个低秩子空间（少数几个最能区分好坏的“方向”），只在这个子空间里撒扰动与累积动量，等于把随机试探聚焦到“好坏差异”方向，从而在明显省显存的同时保住偏好学习效果。
输入 Input: 偏好三元组（提示词、被选回复、被拒回复）、策略模型各线性层的输入激活，以及固定参考模型的打分。
输出 Output: 更新后的 LLM 策略参数（对齐后的语言模型），用于生成更符合人类偏好的回复。
核心机制与技术实现 (Method & Formulation)
  • 以中心差分替代反向传播：$g=\frac{\mathcal{L}_{\mathrm{DPO}}(\theta+\epsilon\Delta)-\mathcal{L}_{\mathrm{DPO}}(\theta-\epsilon\Delta)}{2\epsilon}$，从而无需保留反向传播所需的中间激活。
  • 由 chosen/rejected 激活差构造对比矩阵 $H_{\Delta}^{(l)}=\operatorname{concat}\big(\operatorname{Mean}(H_{\mathrm{ch}}^{(l)})-\operatorname{Mean}(H_{\mathrm{rej}}^{(l)}),\;H_{\mathrm{ch}}^{(l)}-H_{\mathrm{rej}}^{(l)}\big)$，用少量幂迭代取前 $r_l$ 个主方向 $A_l$，并令扰动 $\Delta_l=\frac{R_l A_l^{\top}}{\sqrt{r_l}}$ 落在偏好相关低秩子空间内。
  • 在低秩系数空间维护动量：$N_t=\mu\widetilde{N}_{t-1}+(1-\mu)g_t R_t,\quad W_{t+1}=W_t-\eta_t\frac{N_t A_t^{\top}}{\sqrt{r}}$，使每层仅存基与低秩动量而非参数级优化器状态。
关键评测与消融结论 (Empirical Takeaway)
在 Qwen2.5-1.5B 与 Anthropic HH-RLHF 上，CA-ZODPO 相对 SFT 取得 34.6% 胜率对 28.6% 败率并接近一阶 DPO 的 34.2% 对 33.0%，同时在序列长度 2048 时相比一阶 DPO 降低约 59% 峰值显存。

白话概述：视觉语言模型常会"看图说话"说过头，描述图里根本没有的物体、属性或关系，这就是视觉幻觉。这篇论文把"哪里说错了、错得多严重"的细粒度反馈整理成偏好对，再让视觉语言模型当裁判审批"好回答/坏回答"，最后用DPO做对齐：DPO可以理解为不训练奖励模型，直接让模型提高好回答概率、压低坏回答概率。作者还提出严重度感知变体，让越严重的幻觉被压得越狠。核心直觉是不同幻觉危害不同，惩罚力度应随严重度变化；但结果显示收益依赖评测基准，并非全面领先。
输入 Input: RGB图像、文本指令、原始模型回答、细粒度幻觉反馈（错误类别、证据、理由、严重度）以及chosen-rejected偏好对；训练时还包括视觉语言模型裁判的审批结果与修复信号。
输出 Output: 经DPO或严重度感知HSA-DPO对齐的LLaVA-1.5-7B LoRA适配器，以及对齐后生成的文本回答；推理输出为降低物体、属性和关系幻觉的文本响应。
核心机制与技术实现 (Method & Formulation)
  • 将细粒度幻觉批评归一化为物体、属性、关系错误，并按1/2/3级严重度计算拒绝回答的平均严重度 $S_i$，为偏好对附加严重度元数据。
  • 用Gemini-2.5-Flash-Lite与GPT-4o-mini作为视觉语言模型裁判审批chosen-rejected偏好对，任一裁判通过即接受；被拒偏好对由LLaVA-1.5-7B修复chosen回答并二次验证，形成 $D_{\mathrm{judged}}$。
  • 在标准DPO偏好间隔 $\Delta_i$ 上引入严重度间隔：$\mathcal{L}_{\mathrm{margin}}=-\mathbb{E}_i\log\sigma(\beta[\Delta_i-\lambda\bar{S}_i])$，其中 $\bar{S}_i=\operatorname{clip}(S_i,0,3)/3$，严重度越高要求chosen相对rejected的概率差越大。

💡 评估判定：论文直接解决自回归长视频生成中的 KV 缓存外观漂移问题，核心是冻结视频生成模型上的锚点注意力、区域引导蒸馏与值校正，属于视频生成基础模型的核心机制改进；罗切斯特大学与 Adobe 的组合具备较强研究与工业落地背景，评测覆盖多基座和多时长。
白话概述：长视频逐块生成时，模型会把历史帧的键值存进 KV 缓存当记忆，但短窗口训练让这些记忆越用越偏，主体和背景会慢慢变形、变色，这就是外观漂移；只保留或检索历史缓存，也可能把已经漂移的内容继续传下去。本文把第一段视频当作外观锚点：先训练一个教师模型，用分割和光流给每个新帧区域指定首帧中的对应区域去关注，再把这个行为蒸馏成学生模型里一条独立的锚点注意力路径，并用值校正把近期缓存中漂移的值拉回首帧匹配值。关键直觉是把一致性和运动解耦：原缓存路径继续提供局部运动上下文，独立锚点路径专门补首帧外观，门控决定新出现的内容何时不启用锚点。
输入 Input: 文本提示、首段参考视频块 $X_0$、近期已生成块及其 KV 缓存、当前待去噪的潜变量块
输出 Output: 后续视频块或潜变量帧序列，解码后得到长视频 RGB 帧
核心机制与技术实现 (Method & Formulation)
  • 在冻结的自回归视频模型每个注意力层增加独立锚点路径：$y = y_{cache} + w y_{anchor}$，锚点路径对首块 $X_0$ 做无位置编码的内容匹配注意力，门控 $w$ 控制外观注入强度。
  • 教师用 Grounding DINO 与 SAM 2 分割主体、光流匹配背景，构造掩码 $M$ 让当前 token 只关注首块同区域；学生通过 LoRA 适配 query/key 与门控线性层蒸馏教师行为，推理时无需外部分割或光流模型。
  • 值校正将近期缓存中已漂移的 $V_{n-2}$ 向首块 $X_0$ 中 key 匹配的 $V_0$ 拉近，并以锚点门控作为校正强度，从而同时抑制主体和背景漂移。
关键评测与消融结论 (Empirical Takeaway)
在 MovieGenBench 的 VBench-Long 上，Reference Forcing 在 LongLive 与 Self-Forcing 基座上取得 30/60/120 秒长视频的综合平均排名第一，主体和背景一致性优于 MemRoPE、LongLive-RAG、$\infty$-RoPE、Deep Forcing，且优势随视频长度增加而扩大。

💡 评估判定：论文直接面向流匹配视频生成的长程流式生成、少步蒸馏与 KV 缓存压缩，属于目标轨道核心算法突破；机构为腾讯混元与北京大学，实验覆盖 10/30/60 秒及多事件基准，权威度与扎实度较高。
白话概述：MovieRoll 解决流式视频生成模型在超过训练时长后画面漂移、历史缓存越滚越大、少步蒸馏难以长程自回归的问题。它先把双向视频基座改造成“滚动窗口”生成器：每次只联合去噪当前窗口内的几个视频块，窗口内双向互看让相邻块互相修正，窗口外只能因果地看已生成的历史，类似边写文章边回看前文但不能偷看后文。再用分层 KV 缓存省显存：浅层记住全部历史，深层只留最早和最近的内容，像“浅层记全史、深层记开头和最近”，并在历史过长时重算缓存。最后用长自 rollout 的分布匹配蒸馏，把多步教师模型的长程行为平均成少步学生模型的更新方向，配合引导退火稳定生成。核心直觉是：不追求无限上下文，而是让模型在有限窗口和有限缓存内稳定地边生成、边遗忘、边重算。
输入 Input: 文本提示词（单事件或多事件长描述），可选首帧图像作为初始历史；推理时还包含已生成视频块的潜变量历史与 KV 缓存
输出 Output: 连续流式输出的长时视频帧或潜变量块，支持单事件与多事件提示下最长约 60 秒的视频
核心机制与技术实现 (Method & Formulation)
  • WinTF 将视频分成滚动窗口，窗口内多个块按递增噪声级联合去噪，窗口内双向注意力、窗口间因果访问干净历史，从而并行监督多个窗口并学习事件转换。
  • HieraKV 按层利用注意力模式压缩历史 KV：浅层保留全历史，深层仅保留 sink 与最近历史，并用阈值触发的 KV 重计算限制上下文，降低显存同时保持长程一致性。
  • CuLT-DMD 在长自 rollout 中固定参数、累积各时间位置的局部梯度后统一更新，只用一份局部计算图完成少步生成器长程蒸馏；AnnealCFG 在去噪过程中逐步降低引导尺度以稳定基座模型。
关键评测与消融结论 (Empirical Takeaway)
在 HeliosBench 上，MovieRoll-Distilled 在 10/30/60 秒单事件与多事件评测中取得最高总分，721 帧评测总分 7.515，优于 MemFlow 与 Helios-Base 的 7.143，并保持自然度与动态性。

白话概述：这篇论文追问：在少步流生成里，能否不先训练一个流匹配教师模型，而是利用经验数据分布下可解析写出的概率流向量场，直接构造从噪声到数据的配对（即耦合），再用这些配对训练少步生成器。所谓闭式耦合，就是不用学模型、直接按公式积分得到噪声和数据端的对应关系；概率流向量场则描述样本沿概率路径如何从噪声流向数据。作者发现，在高维实际数据上这条路几乎失效：反向积分得到的端点基本只是初始噪声，外加一个很弱、类似数据点的漂移，因此这种配对接近随机噪声-数据配对，不能提供有效教师信号；只有维度较低或数据量很大时，解析耦合才可能更有用。
输入 Input: 高维经验数据样本、高斯噪声样本、高斯条件概率路径调度、闭式概率流场或预训练流匹配模型；用于构造少步训练耦合的条件

核心机制与技术实现 (Method & Formulation)
  • 把经验分布下的闭式概率流场写成有限高斯后验加权和 $v_t^{PF}(x)=\sum_i w_t^i(x)(\frac{d\alpha_t}{dt}x_0^i+\frac{d\log\sigma_t}{dt}(x-\alpha_t x_0^i))$，从 $x_\epsilon$ 积分到 $t=1$ 构造耦合 $\pi^{PF}$。
  • 在相同耦合数量、学生架构和优化设置下，对比闭式场耦合 $\pi^{PF}$、预训练流模型耦合 $\pi^{FM}$ 与随机配对 $\pi^{Random}$，隔离耦合质量对少步rectified-flow学生的影响。
  • 理论刻画高维端点：积分结果近似为初始噪声加弱漂移，漂移携带的端点能量占比按 $\log N/d$ 标度，故 $\pi^{PF}$ 接近独立噪声-数据配对。
关键评测与消融结论 (Empirical Takeaway)
在CIFAR-10/CelebA等数据集上，单步采样时 $\pi^{PF}$ 训练学生的FID比 $\pi^{FM}$ 差约4-5倍且更接近 $\pi^{Random}$；随采样步数增加差距缩小，低维或大样本时闭式耦合才可能成为更有效教师。

💡 评估判定：论文直接面向大语言模型核心架构，提出逐层持久横向状态来条件化注意力、KV 缓存写入与 MLP，并与 Mamba-2、Gated DeltaNet 等主干结合，属于目标轨道的核心机制创新；但未专门验证数学推理或代码生成，规模主要在 400M-600M 参数，故相关性未给满分。MIT CSAIL 与 Adobe Research 组合权威度高，实验覆盖多主干与消融，较扎实。
白话概述：标准大模型每个 token 只有一条残差流随网络深度向上更新，层内没有跨 token 持久保留的计算状态；这篇论文在每一层额外加入一条横向潜在状态，让它像“每层专属的跨时间工作记忆”一样递归更新，并参与决定该层的注意力、KV 缓存写入、MLP 计算与解码。通俗说，纵向残差流是 token 从底层到顶层的加工流水线，横向状态是每层自己跨 token 保存并更新的便签；模型不靠简单加宽或加深，而是增加“同时活跃的计算状态数量”。核心直觉是让每层拥有独立持久状态来调节本层计算，从而在参数量与前向计算大致不变时提升语言建模，并能接入 Mamba、Gated DeltaNet 等循环主干。
输入 Input: 离散 token 序列及其嵌入向量，每层沿时间递归维护的横向潜在状态，以及因果历史中的 KV 缓存或循环主干状态
输出 Output: 下一个 token 的概率分布，用于自回归语言建模与解码
核心机制与技术实现 (Method & Formulation)
  • 将标准 Transformer 的纵向残差流 ${h}_t^{\ell}$ 与每层新增的横向潜在状态 ${r}_t^{\ell}$ 组成二维格点：${h}_t^{\ell}$ 沿深度更新，${r}_t^{\ell}$ 沿时间递归更新，并通过 ${r}_t^{\ell}=f_\ell({r}_{t-1}^{\ell},{h}_t^{\ell-1})$ 吸收当前纵向信息。
  • 横向状态 ${r}_t^{\ell}$ 直接条件化该层的查询、键、值、KV 缓存写入、MLP 调制与最终解码，使每层拥有独立持久计算状态，而不是仅作为序列混合的内部记忆。
  • 该方法可与 hyper-connections、输入残差等残差流增强组合，也可增强 Gated DeltaNet、Mamba-2、Triadic GDN 及混合主干的循环状态，在等参数或等前向计算约束下比较困惑度。
关键评测与消融结论 (Empirical Takeaway)
在 20B FineWeb-Edu token 预训练下，406M 参数 Lattice 模型将参数匹配 Transformer 的验证困惑度从 15.41 降至 14.40，结合 hyper-connections 与输入残差进一步降至 13.61，并在多种循环主干上于各原生状态尺寸均优于纯基线。

💡 评估判定：论文聚焦推理模型与代码生成场景下的在线策略蒸馏监督分配和训练成本优化，属于 LLM 后训练与推理模型效率方向的重要工作，但并非 KV cache、Mamba、MoE 等长上下文架构层面的核心机理突破，因此相关性为中等偏上。中国人民大学为知名研究型高校，实验覆盖数学推理与代码生成且给出成本-性能权衡，但机构与实验规模未达顶尖工业界实验室水平。
白话概述：在线策略蒸馏（OPD）会让学生模型在自己生成的整条回答上，逐步对照教师模型给出的 token 级偏好信号来学习，看起来每个 token 都要算一遍监督。本文追问：回答越长，后面的 token 真的还能带来同样多的有效学习信号吗？实验发现，越往后的监督边际收益越小，不同位置之间存在大量可共享的梯度更新方向；但越深位置的位置特异梯度在不同采样之间越不稳定，近似一种“噪声”。为此作者提出随机视野 SH-OPD：每个训练 batch 随机抽取一个共享的回答截断长度（horizon，即本次监督覆盖到多长的前缀），只在这段范围内做密集监督，既减少重复且低效的 token 监督，又保留偶尔监督到较深位置的机会。用大白话说，就是不再每次都从头到尾逐一检查整条长回答，而是成批地随机决定“这次只批改到第几段”，从而降低训练成本，同时不让模型只学浅层回答。
输入 Input: 数学或代码任务的提示文本、学生模型自回归生成的回答轨迹，以及教师模型在各前缀位置上给出的 token 概率或偏好信号
输出 Output: 更新后的学生模型参数，从而提升数学推理准确率与代码生成执行通过率
核心机制与技术实现 (Method & Formulation)
  • 将完整 OPD 损失按 token 块精确分解为 $\widehat{\mathcal{L}}_{\mathrm{OPD}}(\theta,x,y)=\sum_{k=1}^{K}\frac{n_k}{N}\mathcal{L}_k(\theta,x,y)$，用块级损失考察监督效用随回答深度的变化，发现后段位置仍可学习但新增监督边际收益递减。
  • 通过梯度分析识别跨位置共享的参数更新分量与位置特异残差，指出深层位置特异梯度在不同 rollout 间一致性下降，说明原始监督 token 数会高估可复用学习信号。
  • 提出 SH-OPD：每个 batch 采样一个共享 horizon $H$，用指数参数 $\alpha$ 控制 horizon 分布，$\alpha=0$ 回退为标准全长度 OPD；仅在截断范围内计算监督，减少冗余 token 监督并保留对深层的访问。
  • 刻画随机 horizon 引入的重加权偏差，并在标准优化假设下给出计算量-重加权权衡，用于解释数学与代码任务偏好不同 $\alpha$ 的原因。
关键评测与消融结论 (Empirical Takeaway)
数学推理中 SH-OPD 在 $\alpha=1.0$ 时最终准确率 63.21% 略高于标准 OPD 的 62.50%，而每次更新 token 计算代理成本约为 45.1%、墙钟时间约为 45.5%；代码生成中 $\alpha=0.5$ 取得 26.00% 峰值准确率高于 OPD 的 25.00%，成本约为 61.8% token 计算和 60.0% 墙钟时间。

输出 Output: 当前 token 的 Mamba-3 层输出激活与更新后的递归状态，以及自回归解码时逐 token 生成的输出。
