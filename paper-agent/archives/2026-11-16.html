💡 评估判定：论文直接属于机械可解释性方向，并聚焦 LLM 智能体真实失败归因，与目标主题中的 interpretability/circuit analysis 高度相关；但它不是 RLHF/DPO 等后训练算法突破，且以单模型、单失败类型的案例分析为主，实验覆盖有限，因此综合分保持中等偏上。
白话概述：这篇论文研究网页智能体“凭空点一个网站上不存在的按钮”这类真实失败，想知道模型内部到底哪一步出了错、能不能在动手前就拦住。作者把模型最后一个提示词位置的内部激活当作“体检指标”，训练一个很简单的线性分类器（线性探针）来读这个指标，提前判断它会不会产生幻觉；再沿着这个“幻觉方向”推拉模型内部激活（steering），看行为能否被纠正。还用电路分析追踪信息在哪些注意力头和前馈层之间流动（circuit），结果发现信号对提示格式很敏感、计算分散在很多位置，说明标准可解释性工具在长轨迹智能体上只能解释一部分。
输入 Input: 网页环境观测（DOM/HTML/可访问性树或文本化页面）、候选动作列表、历史交互上下文与当前提示词；以及 Qwen2.5-7B-Instruct 各层内部激活。
输出 Output: 下一步网页动作（点击/输入等元素级动作）；以及基于内部激活的幻觉预测分数、探针方向干预后的动作，和电路/特征归因分析结果。
核心机制与技术实现 (Method & Formulation)
  • 在最后一个提示词 token 的隐藏状态 $h_T$ 上训练线性探针，把“下一步动作是否幻觉”变成二分类，实现生成前预警。
  • 沿探针法向 $\hat{d}$ 对推理激活做加性干预，检验该方向是否因果地控制动作选择，并统计纠正率与误伤率。
  • 用电路发现与激活修补分析智能体轨迹，指出局部性、平稳性与特征稳定性假设在上下文随 $t$ 变化时失效，导致归因分散且不可比。
关键评测与消融结论 (Empirical Takeaway)
在 Qwen2.5-7B-Instruct 与真实网站交互中，末提示词线性探针以 0.80 AUC 预判幻觉，沿探针方向干预可纠正 85% 的幻觉但破坏 7% 的有效动作，且轻微改变动作表示格式会显著削弱干预效果。

Right Token, Right Time: From Per-Token Gating to Trajectory-Aware Activation Steering

💡 评估判定：论文直接研究 SAE 特征驱动的激活转向与可解释性控制，把逐 token 干预分配建模为固定预算下的闭环控制问题，属于目标轨道中 SAE/机械可解释性控制的核心算法推进；机构为多伦多大学与 Vector Institute，实验覆盖两个模型、三类行为目标和多类基线，较扎实。
白话概述：激活转向是指不微调大模型，只在中间层残差流上加入一个由稀疏自编码器 SAE 找到的“行为方向”，让模型更常说或更少说某类内容；SAE 可理解为把模型内部激活拆成许多较单一、可读的稀疏特征。常见做法是每个 token 都推进这个方向，等于全程用力，容易把内部表示推离训练分布、把生成质量弄差；本文把“何时推进”变成固定干预预算下如何分配有限推进次数的问题，提出只看当前 token 是否偏离的 CFP，以及会记住整段生成已累计偏离多少、像恒温器一样闭环调节的 CLABS（PI 反馈控制）。核心直觉是：同样只推固定次数，把力气花在模型最跑偏的 token 上，比全程均匀用力更能改变行为且更保流畅。
输入 Input: 大语言模型在指定中间层的逐 token 残差流激活、由预训练 SAE 与目标/中性语料校准出的固定行为探针方向，以及用户提示词和已生成前缀。
输出 Output: 逐 token 的二值转向门控与修改后的残差流激活，最终体现为受控的自回归生成文本，例如去毒化续写或诱发指定情绪。
核心机制与技术实现 (Method & Formulation)
  • 用目标语料与中性语料的 SAE 特征差分挑选 top-$k$ 特征，以对应解码器行构造单位转向方向 $v$，并定义任务无关探针 $u=\operatorname{sign}(\alpha)v$，使 $\langle h_t^{\ell},u\rangle$ 越大表示当前 token 越符合目标行为。
  • CFP 是无记忆门控：当探针投影 $s_t^{\mathrm{CFP}}=\langle h_t^{\ell},u\rangle$ 低于阈值 $\tau$ 时转向，即 $m_t=\mathbb{1}[s_t^{\mathrm{CFP}}\leq\tau]$，并把 $\tau$ 校准到固定预算 $p$。
  • CLABS 将分配视为闭环反馈控制：对投影标准化得 $\hat{s}_t$，计算误差 $e_t=s^{\star}-\hat{s}_t$ 与泄漏积分 $\bar{e}_t=(1-\beta)\bar{e}_{t-1}+\beta e_t$，再按 $p_t=\operatorname{clip}(p_0+\kappa_p e_t+\kappa_i\bar{e}_t;0,1)$ 采样伯努利门控 $m_t$，优先补偿累计偏离。
关键评测与消融结论 (Empirical Takeaway)
在 Gemma 2 2B 与 Llama 3.1 8B 上，相同干预预算下 CFP 与 CLABS 取得最大行为偏移，CLABS 在紧预算时优势最明显，同时更好保持生成流畅性。

VEPO: Mitigating Multilingual Hallucinations in LVLMs via Visual Evidence-guided Preference Optimization

💡 评估判定：论文核心是面向多语言LVLM幻觉的后训练偏好优化，直接改进了DPO的偏好对构造方式，属于目标赛道核心算法工作；但可解释性仅作为证据定位工具，实验主要限于LLaVA-1.5-7B和三种语言，故未给最高分。
白话概述：这篇论文解决低资源语言下视觉语言模型的“物体幻觉”：模型答得流畅，却没有真正看图像，而是靠语言先验猜答案。做法是把英语当作高资源“探针”，用英语问句在模型中间层对图像块的跨模态注意力找出关键视觉证据，再人为涂黑这些关键块，构造“同一正确答案下，完整图像优于证据缺失图像”的偏好对，用DPO训练低资源问句更依赖完整视觉证据。通俗说，跨模态注意力就是文本词对图像区域的关注权重；证据遮挡就是遮住关键区域制造“缺依据”的负例；DPO是让模型提高偏好样本相对非偏好样本的答案概率。
输入 Input: 图像与多语言问题文本；训练时额外使用同一图像的英语平行问句来定位关键视觉证据，推理时仅需图像与目标语言问句。
输出 Output: 目标语言文本答案；在POPE中为物体存在的是/否判断，在MME中为感知与认知问答；训练阶段输出为偏好优化后的模型参数更新。
核心机制与技术实现 (Method & Formulation)
  • 用英语问句最后一个token在中间层（11-14层）对图像patch的跨模态注意力平均得到证据分数 $s_i = \frac{1}{|\mathcal{L}|}\sum_{l\in\mathcal{L}} A^{(l)}(t_n^{\mathrm{en}}, v_i)$，取Top-$\rho m$ patch涂黑构造证据缺失图像 $I^l$，原图为 $I^w$。
  • 构造同一正确答案 $y$ 下 $(I^w,x^{\mathrm{lr}},y)\succ(I^l,x^{\mathrm{lr}},y)$ 的偏好对，优化VEPO-DPO损失，提高完整证据下 $y$ 的相对概率并压低遮挡证据下 $y$ 的相对概率。
  • 训练无需外部翻译或奖励模型，仅用已有英语平行问句定位证据；采用LoRA微调，$\beta=0.1$、$\rho=0.2$，推理不增加额外模块。
关键评测与消融结论 (Empirical Takeaway)
在LLaVA-1.5-7B上，VEPO将Hindi的平均POPE F1从0.302提升到0.644（+34.2），中文和法文分别提升+3.5和+5.2，且在SFT后仍有一致增益。

💡 评估判定：论文聚焦少步蒸馏图像/视频扩散生成器的多样性坍缩与激活方向修复，属于视频扩散生成与少步生成的重要问题，但并非流匹配/整流流核心机制或视频生成基础模型架构的突破。作者来自 UIUC、JHU 与 fal，实验覆盖多组师生模型，权威度与扎实度较高。
白话概述：少步蒸馏能把扩散/视频生成模型的采样从几十步压到几步，但会让不同随机种子生成的内容几乎一样，也就是多样性坍缩。作者对比教师和学生的中间激活，发现学生并非不会生成，而是把激活变化“挤”进了少数几个方向，丢掉了控制姿态、构图等结构变化的方向；主方向可以理解为教师模型中承载随机结构变化的主要坐标轴。于是提出 ReDiverse，用轻量适配器把学生激活拉回教师，或在推理时沿教师主方向补回这些变化，从而在不明显掉质量的情况下恢复多样性。
输入 Input: 初始噪声潜变量、文本提示/条件；诊断与干预阶段读取教师和学生指定中间块、初始去噪步的中间激活。
输出 Output: 生成的图像或视频；ReDiverse-FT 输出轻量适配器权重，ReDiverse-TF 输出修正后的中间激活及最终生成结果。
核心机制与技术实现 (Method & Formulation)
  • 对教师和学生同一初始噪声、同一提示下的中间块激活协方差做几何比较：总方差 $\mathrm{Tr}(\Sigma_b)$ 看整体波动，参与率 $\mathrm{PR}(\Sigma_b)$ 看有效方向数；定位到首步去噪的“坍缩块”，发现学生总方差未降但方向数只剩教师的 37%-60%。
  • ReDiverse-FT 在坍缩块用 LoRA 做特征回归 $\mathcal{L}_{reg}=\|h_{\ell,t}^{S}-h_{\ell,t}^{T}\|_2^2$，只在第一个去噪步把学生激活对齐到冻结教师。
  • ReDiverse-TF 免训练，取教师激活协方差前 $K$ 个主方向 $u_k$，在首步按 $h \leftarrow h + a\sigma u_k$ 注入扰动，补回学生丢掉的结构变化方向。
关键评测与消融结论 (Empirical Takeaway)
在 SDXL、SD3、Wan 2.1、MiniMax-H3 四组师生对上，ReDiverse 在 CLIPScore/HPSv2/VBench 质量基本保持的同时，提升 DINO、DreamSim、LPIPS、Vendi 等多样性指标，用户研究也支持。

💡 评估判定：论文正面攻坚像素空间视频扩散的架构与训练形式，属于视频生成基础模型核心赛道；机构为浙江大学与上海AI Lab，声誉较高；但技术贡献以对 DiT、干净数据预测、寄存器令牌与联合生成的系统组合和消融为主，原始机理创新有限。
白话概述：多数视频扩散模型得先把视频压进自编码器的潜空间再扩散，还要配细节修复器、级联阶段或 U-Net 跳连，流程又重又绕；JVT 想说明的是：去掉这些零件，直接用一个“切大块”的 DiT 式 Transformer 在原始像素上做去噪就够了。这里的关键名词可以这样理解——patch embedding 就是把视频切成时空小方块、每块压成一个向量当 token，相当于模型自己做下采样来顶替自编码器；寄存器令牌是在序列里插入几个可学习的“便签”，专门缓存噪声水平、类别这类条件信息，采样时再用寄存器引导把这块便签的贡献额外放大；训练沿用整流流（rectified flow）的思路，不预测噪声而是直接回归“干净视频”再换算成速度。由于全程留在像素空间、没有 RGB 专用编码器，RGB 与视差这类像素对齐模态能拼在同一张时空网格上一起生成，顺带白送出一个显式几何。
输入 Input: 带噪视频像素序列、噪声水平时间步与类别条件；相机条件任务额外输入相机位姿
输出 Output: 干净视频像素（或等效速度场）；相机条件任务联合输出 RGB 视频与像素对齐视差图
核心机制与技术实现 (Method & Formulation)
  • 以干净视频预测替代噪声预测：由 $x_t=(1-t)x_0+t\epsilon$ 得到 $\hat{x}_0=f_\theta(x_t,t,c)$，换算速度 $\hat{v}=(\hat{x}_0-x_t)/t$，用整流流损失 $\mathbb{E}\|(\hat{x}_0-x_0)/t\|_2^2$ 监督。
  • 视频 patch embedding 用 tubelet 3D 卷积，并引入通道瓶颈与时空分解（先 2D 空间卷积、再 1D 时间卷积），压缩 token 维度与计算量。
  • 寄存器令牌在第 $L_1$ 个块后插入、经后 $L_2$ 个块后丢弃，通过 $e_r$ 注入条件；采样时用 $v_{rg}=v_r+w_{rg}(v_r-v_{nr})$ 与 CFG 组合，并按通道拼接 RGB 与视差实现像素对齐联合生成。
关键评测与消融结论 (Empirical Takeaway)
256×256、16 帧设置下，JVT+RG 在 UCF-101 类别条件生成达 FVD 129.2（Latte 为 477.97），无条件 FaceForensics、SkyTimelapse、Taichi-HD 分别为 31.80、47.80、124.3，整体优于或接近主流潜空间扩散基线。

白话概述：视频扩散 Transformer 里每个画面 token 都要和其余所有 token 做注意力比对，token 数一多，计算量按平方暴涨，是生成速度的最大瓶颈；但注意力其实高度稀疏，绝大多数权重很小，只有少数关联真正重要。难点在于“算得准”希望每个 query（查询 token）各自挑自己关心的 key（键 token），而“跑得快”要求 GPU 按 tile（成块的矩阵分块）批量执行，两者粒度冲突。Token2Tile 用一个免训练、随请求在线算出的低秩空间（把 128 维的 Q/K 压到 32 维，但专门保证两者内积即注意力打分基本不变，于是聚类、打分、补偿都能在这个小空间里廉价完成）：先对 query 和 key 分别聚类，每个 query 只保留得分最高的若干个键簇，同一 query 簇内取并集后把这些 key 打包成 GPU tile 精确计算，未入选的键簇则用簇质心加逐 query 权重做残差补偿，把被丢弃的注意力质量“补回来”，避免直接截断造成的精度崩塌。

输出 Output: 近似稠密注意力的逐 token 输出，最终得到生成的多帧视频序列
核心机制与技术实现 (Method & Formulation)
  • 用二阶矩乘积的 SVD 求出匹配投影 $P_q,P_k$，最小化 $\lVert QK^\top-\tilde{Q}\tilde{K}^\top\rVert_F^2$，得到保 logits 的 32 维共享空间，聚类、打分与残差近似全在该空间完成，无需训练。
  • 每个 query 对键簇质心打分为 $g_{ic}=\tilde{q}_i\mu_c^\top/\sqrt{d}$，保留累计规模达到预算 $bN$ 的最短簇前缀 $\mathcal{S}_i$；同一 query 簇执行并集 $\mathcal{U}_a=\bigcup_{i:a_i=a}\mathcal{S}_i$，再把选中的 key 跨簇打包成 GPU tile。

输入 Input: 离线机器人操作轨迹：当前本体/仿真状态、冻结世界模型提取的潜表示、记录动作与一步状态变化目标、候选非动作控制变量；按回合划分训练/验证/测试。

核心机制与技术实现 (Method & Formulation)
  • 匹配预测器路线：状态路线仅用 $S_t$，潜变量路线用 $(S_t,Z_t)$，控制路线用 $(S_t,b)$；三者预测同一目标且共用损失与预测器族，分别得到留出风险 $E_{\mathrm{state}}$、$E_Z$、$E_{\mathrm{ctrl}}$。
  • LASR 比值为 $\rho_{\tau,k}(Z)=E_Z/\min\{E_{\mathrm{state}},E_{\mathrm{ctrl}}\}$，小于1表示潜变量路线同时胜过状态和非动作控制；GeoLASR 取几何平均，WorstLASR 取最大比值。
  • 基准以记录动作 $A_t$ 和一步状态差 $S_{t+1}-S_t$ 为目标，采用回合留出、仿射岭回归预测器和验证集选择的负控制，并用 LASR 训练/审计轻量残差适配器。

输出 Output: 双臂各6维关节目标加1维夹爪命令组成的动作块；同时输出结构化子任务意图（操作类型、执行手臂、目标物体、关系与朝向）以及教师的纠正或续接决策。
