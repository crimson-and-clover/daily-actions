白话概述：本文研究在推理阶段多花算力（测试时计算）能否提升表格基础模型（把训练表当作上下文、直接预测查询行的预训练模型）的精度，并把可选策略拆成三块：改参数（适配）、合并多个预测（聚合）、挑选放入上下文的行或列（上下文构造）。关键发现是，不必大改模型：只训练控制注意力里查询-键相似度的极少量对角乘子（DiagScale）就能接近全量微调；聚合时逐步挑出互补的成员（贪心选择）比把大家均匀平均更稳。核心直觉是，测试时算力要用在修正“查询与支持样本的相似度”或“成员之间的互补误差”上，而不是盲目增加预测数量或上下文长度。
输入 Input: 带标签的表格训练数据（特征列与目标列，可划分验证集）、查询表格样本特征；上下文构造时还可包括候选支持行/列或检索得到的上下文；模型侧为预训练表格基础模型（如 TabPFN-3、TabICL v2、TabFM）。
输出 Output: 查询样本的最终预测（分类标签或回归值）；以及产生该预测所需的适配后参数、成员预测池与聚合规则，或检索/构造出的支持上下文。
核心机制与技术实现 (Method & Formulation)
  • 将测试时计算统一因子化为 $\hat{y}(\mathbf{x})=\mathcal{R}_{\mathbf{w}}(\{f_{\theta_m}(\mathbf{x};g_m(D,\mathbf{x}))\}_{m=1}^M)$，分别对应参数适配 $\theta_m$、聚合 $\mathcal{R}_{\mathbf{w}}$ 与上下文构造 $g_m$。
  • DiagScale 受 SoftScale 启发，在注意力中学维度特定 query 乘子，可写为 $\tilde{\mathbf{q}}=\mathbf{q}\odot \mathbf{s}(n)\odot \mathbf{g}(\mathbf{q})$；仅更新 0.003-0.03% 参数，达到接近全量微调的收益。
  • 聚合同时考虑成员池组成和选择策略；在 96 种配置池上用贪心选择比默认预测器降低约 2.4% 误差，而均匀平均可能变差，说明验证集驱动的选择性合并更稳。
关键评测与消融结论 (Empirical Takeaway)
在 TabArena 上，DiagScale 仅更新约 0.003-0.03% 参数，Elo 增益为 +26，与全量微调的 +25 相当；96 配置池上贪心选择比默认预测器降低约 2.4% 误差，但适配与聚合叠加需显著更多算力。

EgoVoice: Proactive Spoken Assistance from Egocentric Multimodal Streams

创新性 Novelty

白话概述：可穿戴 AR 助手需要像旁边的真人教练一样，看着你干活、在你快出错前主动开口提醒，而不是等你提问。EgoVoice 解决的就是这个联合难题：在连续的第一人称视频和音频流里，同时决定“现在要不要说话”（时机）和“该说什么”（内容）。关键技术名词拆解：所谓“主动干预”就是助手自己判断何时插话，而非被动应答；“全双工流式”指模型能一边看画面、一边听声音、一边说话，三者同步进行；“源分离”是把混在一起的背景噪音、用户说话、教练说话拆成独立音轨；训练上用 SFT 教会它靠谱的基础行为，再用 DPO（直接偏好优化，即用“哪种干预更好”的对比数据来调教模型）进一步打磨开口时机，核心直觉是语音播放本身要花时间，因此说话必须提前到与用户动作精确对齐，而不是把文本指令简单读出来。
输入 Input: 第一人称连续 RGB 视频帧流与同步音频流（含用户语音、背景声、教练语音），外加系统提示中的任务名称和分步操作配方。
输出 Output: 每个时间块（一帧视频加约一秒音频）输出 Listen 或 Speak 决策；若为 Speak，则生成指导文本 token，并进一步解码为语音 token 与最终语音波形。
核心机制与技术实现 (Method & Formulation)
  • 数据构建：用 SAM-Audio 分离并保留背景声，经 Silero VAD 确认无残留人声；再用 IndexTTS2 重合成用户与教练语音，按时长不超原句和 ASR 转录一致来筛选，使语音时间线与真实动作对齐。
  • 流式听/说接口：按块处理一帧视频加一秒音频，逐块输出 Listen 或 Speak；在 Speak 块上 LLM 生成文本 token，语音 token 解码器将其转为 S3 语音 token 并合成波形。
  • 训练与偏好优化：先对 MiniCPM-o 4.5 用 LoRA（$r=32$，$\alpha=64$）做 SFT，再以 DPO（$\beta=0.1$）优化干预行为，使模型更常在对齐窗口内提前给出有用指导。
关键评测与消融结论 (Empirical Takeaway)
在 170 个测试会话上，EgoVoice-DPO 把 onset F1 从 MiniCPM-o 4.5 的 0.113 提升到 0.324，并将 end-vs-act 由约 $-4.69$s 的负值转为约 $+1.75$s 的正值，说明主动干预时机与内容均明显优于零样本骨干及现有对话/主动助手基线。

白话概述：WorldGuide 要解决的是长程程序性任务视频生成不能只看开头一次性生成，必须像闭环控制一样边生成边根据已生成的画面调整下一步。给定初始图像和目标，它用 ContextPlanner 从当前视觉状态和最近动作-片段历史预测下一个原子动作或完成信号，再用 Executor 生成该动作对应的短视频片段，循环直到完成。关键概念：闭环任务执行是把视频生成当作在“视觉世界空间”里逐步行动，即每一步的产物决定下一步；原子动作是任务拆解后不可再分的步骤（如“拿起杯子”）；层级视觉记忆是对越旧的画面用越粗的空间压缩来存，从而让长历史不爆显存。核心直觉是让规划与执行在同一套步骤级演示上训练，从而缩小“决定动作”与“真正生成出该动作效果”之间的鸿沟。
输入 Input: 初始单帧 RGB 图像、任务目标自然语言描述；执行循环中额外输入当前已生成的视频片段作为当前视觉状态，以及最近 K=3 个动作-片段对组成的历史，Executor 另接收层级视觉记忆中的历史隐帧。
输出 Output: ContextPlanner 输出下一个原子动作的自然语言指令，或任务完成标记；若未完成，Executor 输出条件于该动作和当前状态的下一段短视频片段，最终所有片段拼接为完整程序性任务视频。
核心机制与技术实现 (Method & Formulation)
  • 闭环规划-执行循环：$\pi_\theta$ 从 $(g,x_t,h_t)$ 预测 $a_t \in \mathcal{A} \cup \{\mathtt{DONE}\}$；若未完成则 $f_\phi$ 生成 $x_{t+1}=f_\phi(a_t,x_t,M_t)$，并更新 $h_{t+1}=h_t+a_t$ 与 $M_{t+1}=\mathrm{update}(M_t,x_{t+1})$。
  • 规划器由 Qwen2.5-VL-7B 做步骤级监督微调，仅凭视觉进度预测下一原子动作或完成，抑制重复步骤；执行器由 HunyuanVideo-1.5 以冻结规划器嵌入的动作条件训练。
  • 执行器用流匹配目标 $\mathcal{L}_{\text{exec}}=\mathbb{E}_{z,\epsilon,\sigma}\!\left[\frac{\|m\odot(\hat{y}_\phi-(\epsilon-z))\|_2^2}{\max(\sum m,1)}\right]$，配合层级视觉记忆按帧龄分配空间压缩率，约束历史 token 开销。
关键评测与消融结论 (Empirical Takeaway)
在 WorldGuide-Bench 上，仅用初始图像和目标的 WorldGuide 达到 33.33% Task Success，高于接收参考动作计划的 MiniMax-H3 的 29.90%；在 VideoCraft-Bench 目标条件下达到 47.69%，远超 MiniMax-H3 的 32.73%。

DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training

白话概述：DreamTrue 解决机器人世界模型动作跟随不准和预测偏向成功的问题。它先把不同机器人的动作渲染成统一的图像空间条件（RGB、深度、掩码、相机射线），让视频扩散模型能按动作生成未来多视角画面；再用反事实后训练修改动作轨迹生成各种扰动未来，并用一个视频奖励模型（人类标注机器人、物体、交互缺陷训练）通过强化学习筛选更物理合理的预测。关键概念：反事实推演就是“如果动作变了未来会怎样”，用来补足失败数据；图像空间动作条件是把抽象动作变成视觉图，使跨本体共享同一生成器。
输入 Input: 多视角初始RGB观测、任务指令、动作序列、机器人URDF及标定参数；训练时还有成对多视角未来视频。
输出 Output: 未来多视角RGB视频。
核心机制与技术实现 (Method & Formulation)
  • 离线几何标定：用机器人渲染与记录视频的像素、时序背景、跨视角对应关系，联合优化相机参数与臂安装偏移，最小化重投影误差和射线共面误差：$\min_{\Theta,\xi} \lambda_a \langle \|u_i - \pi_i(X_i(s,\xi);\Theta,\xi)\|_2^2 \rangle_{\mathcal{P}_{align}} + \lambda_e \langle |(r_a\times r_b)^\top(o_a-o_b)| \rangle_{\mathcal{P}_{view}\cup\mathcal{P}_{time}}$。
  • 跨具身统一动作表示：将动作渲染为图像空间条件 $\mathcal{C}=\{(\tilde{R}_t^v,D_t^v,M_t^v,P_t^v)\}$，经VAE和几何编码器后通过VACE分支注入视频DiT，多视角latent按宽度平铺预测未来视频。
  • 反事实后训练与奖励引导：修改动作轨迹生成更广动作和接触，训练视频奖励模型评估本体、物体、交互缺陷，并用其分数通过强化学习后训练提升物理合理性。
关键评测与消融结论 (Empirical Takeaway)
在AgiBot上，完整DreamTrue将反事实动作下的交互缺陷率从48.12%降至6.25%，nDTW达0.8831，并获AgiBot World Challenge 2026世界模型赛道第一。

创新性 Novelty

白话概述：现有强大多模态基础模型直接控机器人时，精细操作常失败，关键不是策略不会，而是物理相机看不到任务关键的空间关系。SpatialHarness 在测试时维护一个与真实执行同步的在线仿真场景（数字孪生），识别关键空间关系并渲染物理相机之外的互补虚拟视角，作为空间脚手架喂给冻结策略，无需微调或改动硬件。核心直觉：把看不见的几何关系主动显式呈现，就能释放基础模型已经具备的精细操作能力。
输入 Input: 任务指令、双 Intel RealSense RGB-D 图像（腕部与固定第三人称视角）、机器人关节状态与夹爪宽度、执行反馈；SpatialHarness 额外提供两个虚拟 RGB 视图与物体 6-DoF 位姿。
输出 Output: 七维末端执行器动作增量向量（三维平移增量、三维旋转向量增量与夹爪命令）及动作块长度。
核心机制与技术实现 (Method & Formulation)
  • 交互感知场景同步按 $m_{i,t}\in\{\text{static},\text{held},\text{transition}\}$ 选择更新：静止对象保持 $p_{i,t}=p_{i,t-1}$，抓取对象由物理引擎传播并经视觉与约束校验，过渡阶段用假设重放 $\tilde{s}_t^{(k)}=f(s_\tau^{(k)},u_{\tau:t})$ 选择与真实执行一致的当前仿真状态。
  • 初始化时，模型从多视角图像构建 CAD 资产，视觉校正得候选位姿集 $\mathcal{P}_{i,0}$，再生成约束程序 $z_{i,0}=\pi(\mathcal{C}_{i,0})$ 并执行 $p_{i,0}=\phi(\mathcal{P}_{i,0},z_{i,0})$，确定满足关系约束且通过视觉验证的初始 6-DoF 位姿。
  • 任务导向视角选择由模型在任务前配置互补虚拟视角并渲染，策略每步结合虚拟视图与结构化物体位姿，输出七维动作块 $a=[\delta x,\delta y,\delta z,\delta r_x,\delta r_y,\delta r_z,g]$，块长 $H\in\{10,20,30\}$。
关键评测与消融结论 (Empirical Takeaway)

DVD: Dynamic Vector Decoding for Efficient MLLM-based Perception

发表日期: 2026-10-08 作者: Jinghua Hou, Zhe Liu, Hengshuang Zhao arXiv ID: 2610.12266v1
创新性 Novelty
7.5/10
工程可行性 Engineering
8.5/10
实验完备性 Empirical
7.5/10
综合指数 Overall

白话概述：现有MLLM感知方法要么把2D/3D坐标写成文本（token开销大），要么用固定范围量化（在无界3D场景中精度差）。本文提出动态向量解码（DVD），将2D框、2D掩码和3D框统一转成1D向量序列，再通过一个可学习的码本压缩成紧凑的离散token，就像给每种感知结果分配一个“数字身份证”；推理时MLLM只需输出这些token，一个轻量去token器就能还原出原始坐标或形状。关键突破是引入基于双向Chamfer距离的几何损失，确保还原出的形状在几何结构上忠实于原表示，从而在统一2D/3D任务的同时大幅减少token数量和推理延迟。
输入 Input: 输入：2D任务为单目RGB图像，3D任务为RGB-D图像或点云，并附带自然语言指令（如指代表达式或类别查询）。
输出 Output: 输出：2D边界框坐标、2D掩码多边形顶点序列、或3D边界框参数（中心坐标、尺寸、旋转矩阵）。
核心机制与技术实现 (Method & Formulation)
  • 将2D边界框（左上右下角点）、2D掩码（沿边缘均匀采样的归一化点序列）和3D边界框（中心、尺寸、旋转矩阵）统一展平为1D向量序列 $\mathbf{s} \in \mathbb{R}^{B \times L \times 1}$，经1D编码器映射到潜在空间 $\mathbf{z} = E(\mathbf{s})$，再通过可学习码本量化得到离散token，最后由1D解码器重建 $\hat{\mathbf{s}} = D(\text{Quantize}(\mathbf{z}))$。
  • 引入任务无关的几何损失 $\mathcal{L}_{\text{geo}}$，基于双向Chamfer距离计算预测与目标点集（或3D框顶点）之间的平均最小L1距离，该损失对点序排列不变，克服了L1重建损失对参数化顺序敏感的缺陷，统一监督2D和3D感知任务。
  • 训练时扩展MLLM词表并微调，推理时仅需一个轻量去token器将MLLM输出的离散token解码回原始2D/3D表示，无需修改MLLM架构，显著降低序列长度和推理延迟。
关键评测与消融结论 (Empirical Takeaway)
在3D接地任务SUN-RGBD上，DVD-2B达到40.0 AP3D@15，比Qwen3-VL-8B的36.2提升3.8，同时大幅减少token开销；在2D接地和指代分割任务上也全面超越基线，验证了统一离散表示的高效性与精度。
