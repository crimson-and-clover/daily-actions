白话概述：表格数据（Excel 那种每行一个样本、每列一个特征的表）领域也出现了类似 GPT 的预训练大模型，称为表格基础模型（TFM）：它们不需要重新训练，只要把训练样本当成「上下文示例」塞进输入就能直接预测新样本。本文追问一个关键问题：既然模型固定不变，在推理阶段额外多烧算力（test-time compute）到底能不能提升它、提升多少、又在哪里白费？作者把「测试期算力」拆成三条可独立操作的路径：适配（只在推理时微调极少参数贴合当前任务）、聚合（对同一样本做多种预处理得到多个预测再挑选或平均）、上下文构造（检索或合成更合适的示例行喂给模型）。其核心突破是提出 DiagScale：不动整张网络，只在注意力的「查询-键相似度」上学习每个维度的缩放因子，训练参数仅占全模型的 0.003-0.03%，却在三个预训练骨干上取得与全量微调几乎相同的收益。直觉是：模型真正需要微调的只是注意力的相对缩放取向，而非全部权重。
输入 Input: 带标签的表格训练数据（多行多列的样本集合）与一个待预测的查询样本行；部分方法额外使用验证集切分来挑选聚合成员或权重。
输出 Output: 查询样本的预测结果（分类类别标签或回归连续数值），以及聚合器对各成员预测的选择或加权输出。
核心机制与技术实现 (Method & Formulation)
  • 把推理流水线形式化为 $\hat{y}(\bm{x})=\mathcal{R}_{\bm{w}}(\{f_{\theta_m}(\bm{x};g_m(D,\bm{x}))\}_{m=1}^M)$，将测试期算力解耦为三类正交干预：适配改变 $\theta_m$、聚合改变成员集合与归约器 $\mathcal{R}_{\bm{w}}$、上下文构造改变条件化函数 $g_m$。
  • 提出 DiagScale：在注意力中仅学习维度特定的查询乘子，等价于对查询-键相似度施加对角缩放，更新参数仅占全模型的 0.003-0.03%，却在三个独立预训练骨干上取得与全量微调（58.3M 参数，$+25$ Elo）相当的收益（$+26$ Elo）。
  • 在 25 种适配设置扫描中发现，仅训练长度相关缩放分支 $\bm{s}(n)$ 即可恢复 93-106% 的联合微调增益，而查询相关门控 $\bm{g}(\bm{q})$ 仅贡献 8-16%，说明增益来源是维度级相对缩放而非整体重标定。
关键评测与消融结论 (Empirical Takeaway)
在 TabArena 上，DiagScale 以 1.03M 可训练参数获得 $+26$ Elo（接近全量微调的 $+25$ Elo），96 配置池的贪心选择相对默认预测器降低 2.4% 误差，而均匀平均反而增加误差；适配与聚合叠加可再提升但需显著更多算力。

白话概述：测试期训练(TTT)指模型在部署阶段直接用测试输入更新自己的参数，在数学竞赛等特定任务上能显著变强，但它并非万能：不同TTT算法只擅长不同场景，乱用会白白烧掉推理算力，甚至把模型越改越差。这篇论文的做法是给模型装上“自主判断”的能力——把每种TTT算法打包成可随时调用的工具，把每次微调得到的LoRA小适配器当成可复用的“技能”存进技能库，再训练一个策略来决定：这道题值不值得做TTT、该调哪个算法、是复用已有技能还是新建一个。核心突破在于用“答案质量的提升减去多花的算力成本”作为奖励来学习这套决策，让模型学会为自己的部署经验买单。
输入 Input: 一个按顺序到来的文本测试查询流（数学、代码、逻辑、医学问答等），外加当前的跨查询状态（技能库中每个LoRA适配器及其自然语言能力描述、存放待联合训练材料的适配池）和本查询的历史交互记录。
输出 Output: 一系列动作（添加材料到适配池、对适配池执行某TTT算法生成新技能、加载已有技能、直接生成答案）构成的轨迹，最终输出文本答案，并在过程中更新技能库与适配池。
核心机制与技术实现 (Method & Formulation)
  • 将测试查询流建模为序贯决策，跨查询状态为 $S_t=(\mathcal{L}_t,\mathcal{P}_t)$，策略每轮从 $\mathcal{A}=\{\textsc{Assign}(\rho),\textsc{Adapt}(m,\rho),\textsc{Load}(s),\textsc{Generate}\}$ 中选定一个动作。
  • 以相对冻结基座直接回答的回报 $R(\tau_t)=[U(\tau_t)-U(\tau_t^{\textsc{Generate}})]-\lambda[C(\tau_t)-C(\tau_t^{\textsc{Generate}})]$ 为优化目标，求解 $\theta^{\star}=\arg\max_{\theta}\mathbb{E}_{\pi_{\theta}}\sum_{t=1}^{T}R(\tau_t)$，使效用增益必须覆盖额外算力。
  • 两阶段训练：先用提示引导采样并对齐金动作做 Guidance Distillation 冷启动，再用结果驱动强化学习最大化净回报；每次适配结果以 LoRA 形式存入技能库。
关键评测与消融结论 (Empirical Takeaway)
在 Qwen2.5-7B 上总体效用从直接回答的 0.256 提升到 0.650，明显超过仅 SFT 的 0.510，并在训练未见的领域上仍能迁移。

DeltaTTT: Layerwise Optimization for Nonlinear Recurrent Memory

白话概述：这篇论文研究序列建模里的测试期训练 (Test-Time Training, TTT)：不把上下文存成一个外部缓存，而是让一个内部小网络 (如两层 MLP) 在推理时一边读序列一边把自己的参数当成记忆，把'键-值'关联动态地背进网络权重里。作者发现一个反直觉现象——按直觉，串行更新 (每一步梯度都基于上一步已更新的记忆，即 $W_{c-1}$) 应该比固定基准并行更新 (所有梯度都基于初始记忆 $W_0$) 更聪明，因为串行能'顾及已学内容'；但对非线性记忆恰恰相反，串行明显更差。诊断出的病根是：非线性记忆在只跑一遍序列的单次优化预算内太难拟合，容量优势发挥不出来。为此提出 DeltaTTT：不再把两层记忆网络做联合内循环优化，而是改为逐层学习，给每一层设定各自的局部预测目标，并用'状态依赖的 delta 规则'逐层更新——delta 规则说白了就是用残差 (目标值减去当前记忆预测值) 做纠正式修正，学得不对就按误差方向补。这样既保住非线性读出能力，又能按分块并行计算。核心直觉是把'一个大而难优化的非线性目标'拆成'多个小而好优化的逐层目标'，在有限单次预算内真正释放状态依赖更新的潜力。
输入 Input: 序列中的查询、键、值特征三元组 $(Q,K,V)$，由输入 token 经投影得到。
输出 Output: 查询经记忆网络读出结果 $O=f_W(Q)$，用于下一 token 语言建模预测；评测中体现为 4K-32K 长上下文的单针检索准确性与逐位置预测损失。
核心机制与技术实现 (Method & Formulation)
  • 把两层非线性记忆网络的联合内循环优化改为逐层学习：为每层设局部预测目标，用状态依赖的 delta 规则更新参数 $W \leftarrow W - \eta \nabla_W \mathcal{L}(f_W(K), V)$。
  • 串行 TTT 梯度基于前序分块更新后的记忆 $S_c = S_{c-1} - \eta \nabla \mathcal{L}_c(W_{c-1})$，固定基准并行版本基于共享初始记忆 $\nabla \mathcal{L}_c(W_0)$；DeltaTTT 逐层分解后既保留状态依赖纠错，又让梯度可跨分块做因果前缀和并行计算。
  • 逐层 delta 规则使各层更新近似仿射可分块累加，缓解非线性记忆在单次遍历序列预算内的优化困难，同时保留非线性读出能力。
关键评测与消融结论 (Empirical Takeaway)
在 LaCT 骨干上，DeltaTTT 单针检索达 50.47，显著超过固定基准并行版的 37.87 与串行版的 28.25，相比并行 LaCT 提升 12.60 点且训练损失更低；在 DeltaNet 骨干上亦优于 DeltaNet 与 Gated DeltaNet。

白话概述：大模型做推理时要生成很长的思维链，常常绕远路、算力浪费；而且它在一次解题中悟出的好策略，很难带到之后的问题上复用。这篇论文把这类策略（一段段自然语言的解题套路）做成一个会自己长大、自己整理的贝叶斯小抄：用层次狄利克雷过程高斯混合模型（一种能自动决定聚成几类、还能让不同领域共享类别的概率聚类方法）把策略嵌入按语义分簇。来一个新问题时，靠后验预测（根据已有数据算出'它最可能属于哪一簇'的概率）挑出最相关的几条策略塞进提示词；每见到一个样本就用极低成本更新聚类参数，遇到足够新的策略就自动新建一类，并偶尔用塌缩吉布斯采样重新归类。核心突破是把死板的扁平检索换成会自适应重组的结构化概率记忆，让测试期适应既便宜又有效。
输入 Input: 待求解问题的文本查询，以及在线测试期依次到达的（问题，行为）对及其行为描述文本经句编码器与PCA投影后的低维嵌入向量

核心机制与技术实现 (Method & Formulation)

  • 检索用后验预测分布 $p(z_x=k\mid e(x),X)\propto n_k\,p(e(x)\mid\phi_k)$ 选择相关行为，实现软分配与域感知，而非硬性最近邻。
  • 在线测试期训练中，每个新样本软更新所分配组件的充分统计量，按CRP先验在新行为足够新颖时创建新组件，并用一步塌缩吉布斯采样重新分配行为以重组记忆。

Universal Test-Time Training

白话概述：大模型的"长记忆"有两种做法：一是把上下文压缩进每层自己的"快速权重"（fast weights，可以在推理时临时改写的记忆矩阵），每次读到新内容就在线更新一次，靠它记住很久之前的 token；二是干脆加长注意力窗口，但那样算力和显存吃不消。现有 TTT 的问题是每层各自维护一份记忆，记忆只在"时间"这一个方向滚雪球，深度方向只是把 L 份记忆并排摆着，互不通信。本文让所有层共用同一份快速权重记忆，于是记忆同时沿"时间"和"深度"两个方向递归：深层的某一块写进去的东西，浅层在下一块就能读到。这样在每 token 计算量不变的情况下把有效记忆容量放大，两种落地形式是 uTTT-MoE（共享一个专家池、每个 token 头只路由到少数几个专家）和 uTTT-Dense（每层直接吃全部共享记忆）。
输入 Input: 语言建模：长 token 序列（按 4096 token 分块，配合 4096 窗口的滑动局部注意力）；新视角合成：多视角 RGB 图像与相机位姿
输出 Output: 语言建模：下一 token 的概率分布；新视角合成：指定视角下的 RGB 图像
核心机制与技术实现 (Method & Formulation)
  • 跨深度共享快速权重：把 $L$ 层分成 $p$ 组，每组共享一组 SwiGLU 状态 $W=(W_0,W_1,W_2)$，读函数 $f_W(\mathbf{x})=W_1[\operatorname{SiLU}(W_0\mathbf{x})\odot(W_2\mathbf{x})]$；$p=L$ 退化为层私有，$p=1$ 即全局共享。
  • 写入由关联损失 $\ell_{\rm in}(W;\mathbf{k},\mathbf{v})=-\langle f_W(\mathbf{k}),\mathbf{v}\rangle$ 驱动，块边界聚合组内各层梯度后单次更新 $W^{(c)}=\operatorname{Update}(W^{(c-1)},\sum_{\ell}G_{c,\ell})$，形成时间与深度二维递归。
  • uTTT-MoE 全层共享一个专家池并逐 token 头路由，uTTT-Dense 每层无路由地直接用整份共享记忆。
关键评测与消融结论 (Empirical Takeaway)
124M/760M 参数下 uTTT-MoE 的 RULER 平均准确率为 15.5/27.9，较层私有 LaCT 高 2.6/2.1 点，为等状态、等激活计算的有界状态模型中最优，且逐 token 损失不输甚至优于全注意力。

RouterInterp: Understanding Superposed Specialisation in Mixture of Experts Routing

白话概述：这篇论文要破解大模型可解释性的一个难题：稀疏专家混合模型（MoE）里每个「专家」到底在学什么。MoE 的做法是让每个 token 只送给少数几个专家网络处理，省算力；主流假设认为每个专家管一个语义连贯的大领域（如「数学」「法律」），但按这个假设做的解释实验几乎都失败。作者提出「叠加专精假设」：专家其实不管一整个领域，而是负责一堆彼此无关的细粒度特征拼起来的「不相交并集」——好比一个人同时会修表、做菜、下棋，技能之间毫无关联。为了验证，他们提出 RouterInterp：先用稀疏自编码器（SAE，一种把稠密的神经元激活拆解成大量「一次只代表一个概念」的稀疏特征的解耦工具，用来对付多个概念挤在同一批神经元里的「叠加」现象），找出最能预测路由去向的那些特征，再拼成人能读懂的自然语言解释。
输入 Input: MoE 路由层输入处的 token 激活向量（残差流表示），以及配套的稀疏自编码器（SAE）特征字典
输出 Output: 该 token 被路由到哪个/哪些专家的决策解释、对路由贡献最大的稀疏特征集合，以及对应的自然语言解释文本
核心机制与技术实现 (Method & Formulation)
  • 把 MoE 路由决策与 SAE 解耦出的单概念特征对齐，筛出对路由 logits $h(\mathbf{x}) = \mathbf{W}_r \cdot \mathbf{x}$ 预测力最强的稀疏特征，将专家专精刻画为特征的「不相交并集」而非单一领域。
  • 形式化对比两种假设：当微领域数 $D > E$（专家数）时，领域专精假设预测相近微领域路由到同一专家，叠加专精假设预测无关微领域被并入同一专家。
  • 采用 Top-K SAE（$\sigma = \text{TopK}(\cdot, s)$，优化重建损失 $\mathcal{L} = \|\mathbf{x} - \hat{\mathbf{x}}\|_2^2$）提取稀疏特征，再拼装成统一自然语言解释。
  • 在 gpt-oss-20b 上验证，RouterInterp 相比基于 token 统计的旧方法，路由解释检测准确率提升约 $65\%$。
关键评测与消融结论 (Empirical Takeaway)
在 gpt-oss-20b 上，RouterInterp 对专家路由的解释检测准确率比基于 token 统计的旧方法高出约 $65\%$，支持叠加专精假设优于领域专精假设。

输出 Output: 每条响应中每个有效 token 的标量权重(同响应内中心化并归一化，有效 token 权重均值约束为 1)，以及由此加权蒸馏更新后的学生推理模型参数；最终体现为数学推理准确率 Avg@8 / Pass@8 的提升。
核心机制与技术实现 (Method & Formulation)
  • 把 OPD 目标改写为 token 加权形式 $\mathcal{L}_{\mathrm{in}}(\theta,\eta;B)=\frac{1}{N_B}\sum_{i,t}m_{i,t}w_{\eta,i,t}\ell^{\mathrm{OPD}}_{i,t}(\theta)$，其中逐 token 项为带裁剪的 reverse-KL 代理 $\ell^{\mathrm{OPD}}_{i,t}(\theta)=\max(-A_{i,t}r_{i,t}(\theta),-A_{i,t}r^{\mathrm{clip}}_{i,t})$，$A_{i,t}=\operatorname{sg}[u^{\mathrm{T}}_{i,t}-u^{\mathrm{old}}_{i,t}]$ 为教师减 rollout 的对数概率差，$r_{i,t}(\theta)=\exp(u^{\theta}_{i,t}-u^{\mathrm{old}}_{i,t})$ 为当前策略对旧策略的概率比。
