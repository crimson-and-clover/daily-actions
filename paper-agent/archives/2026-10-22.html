💡 评估判定：把MoE原生路由统计转成步级置信度，用于测试时选择性重生成与PRM自动标注蒸馏，属于测试时计算分配与过程监督的核心机制创新；但不是测试期参数更新的TTT，故相关性未给满分。机构为CityU/CMU/HKU，实验覆盖广、基线较强。
白话概述：多步推理里最缺的不是最终答案，而是判断“中间哪一步想错了”的过程标签，人工标注又贵又不可靠。这篇论文发现，MoE（混合专家）大模型在正常答题时，每个词都会“派发”给少数几个专家，而派发得集不集中、半路是否摇摆，本身就隐含了这一步想得稳不稳：派发得集中且平稳，往往说明这一步可靠。作者据此把这种“路由统计”换算成逐步置信度，做两件事：一是测试时只挑最没把握的那一步之后重新生成，把算力花在关键处，而非整篇重写；二是让强MoE用这套置信度自动给推理轨迹打过程分，再“蒸馏”教给一个独立的过程奖励模型（PRM，专门给每一步打分的裁判），从而无需人工标注。
输入 Input: 自然语言问题与已生成的多步推理轨迹，以及MoE各层每个token的专家路由概率和Top-k专家选择；训练PRM时还包括由路由置信度自动生成的步级分数。
输出 Output: 最需重生成的步骤位置与重写后的推理轨迹及最终答案；或独立PRM对每步输出的置信度分数。
核心机制与技术实现 (Method & Formulation)
  • 用路由质量、步首路由质量与步内路由波动构造步级置信度 $C_i=\tilde{M}_i+\tilde{H}_i-\tilde{D}_i$，全部量在普通MoE前向中已产生，无需额外rollout或外部验证器。
  • RoCo-Rethink 取 $i^*=\arg\min_i C_i$，保留前缀 $(s_1,\ldots,s_{i^*-1})$ 并从 $s_{i^*}$ 起重生成后缀，迭代至答案稳定或达最大轮数，实现测试时算力向低置信步骤集中。
  • RoCo-PRM 用强MoE的路由置信度自动标注轨迹步级分数并蒸馏为独立PRM，使其可迁移到MoE与稠密模型及不同任务。
关键评测与消融结论 (Empirical Takeaway)
RoCo-Rethink 在3个MoE模型的18个模型-任务设置全部最优，平均较最强测试时基线提升1.2/1.9/1.5分；RoCo-PRM 在5个模型30个设置中29胜1平。

💡 评估判定：核心是把测试期训练从单智能体扩展到分层多智能体，并用任务内反馈交替更新协调器与科学家的 LoRA，属于目标轨道中的 TTT 算法设计；但评测集中在 MLGym/MLE-bench 科学发现任务，对 o1 式推理扩展、MCTS 与过程奖励的直接覆盖有限。机构为乔治·华盛顿大学，权威度中等。
白话概述：这篇论文要解决多智能体科学发现中的耦合难题：团队怎样分工，既决定当前该做哪些实验，也决定每个智能体之后能从哪些经历中学习。作者提出 MELD，在一个全新任务上同时更新团队级协调者和个体科学家两套策略，用一棵共享推导树组织研究分支，并让两层策略交替根据任务反馈改进。通俗讲，测试期训练就是不改动底座大模型，只在任务内用少量可训练适配器快速调参；GRPO 式更新可理解为对同一轮多个候选做组内相对比较，好于平均的被奖励；best-of-budget 则是在固定预算内尽量让已验证候选中的最好结果更优。
输入 Input: 未见可执行科研任务的任务说明、数据、基线工件与评估器，以及当前共享推导树的节点历史、反馈、效用分数和剩余预算。
输出 Output: 团队级协调器输出的研究组合（父节点选择与研究指令），以及各科学家输出的可测试假设与执行计划；这些计划经冻结执行器产生候选工件并接受评估。
核心机制与技术实现 (Method & Formulation)
  • 将联合策略分解为团队级协调器与个体科学家：$\pi_\Theta(Z_t,U_t\mid\mathcal{S}_t)=\pi^{\mathrm{coord}}_\phi(Z_t\mid\mathcal{S}_t)\prod_{i\in\mathcal{I}_t}\pi^{\mathrm{sci}}_{\theta_i}(u_t^i\mid\mathcal{S}_t,z_t^i)$，协调器决定在哪做和做什么，科学家决定怎么做。
  • 在冻结骨干与冻结 Executor 上，为协调器挂载 LoRA 适配器 $\phi$、为每个科学家挂载私有 LoRA 适配器 $\theta_i$，任务开始时重置，只用任务内交互数据更新。
  • 两层策略在共享 best-of-budget 目标 $J_T(\Pi;\mathcal{P})=\mathbb{E}_{\Pi}[\max_{c\in\{c_0\}\cup\mathcal{C}^{\mathrm{val}}_T(\Pi)} s(c)]$ 下交替做 GRPO 式更新，使团队分工与个体研究行为递归共进化。
关键评测与消融结论 (Empirical Takeaway)
在 22 个 MLGym/MLE-bench 任务上 MELD 在 20 个取得最佳点估计，并在 MLGym 归一化聚合指标上最高，仅用 4B 骨干即可与使用专有 Scientist 的基线竞争。

💡 评估判定：论文直接命中测试时推理扩展中的算力分配与验证器误差建模问题，给出可解析成功率公式加经验贝叶斯预算规划，属于该赛道核心机制突破；但它不涉及测试期参数更新或自训练，因此与 TTT 主线仍有区别。微软研究院印度背书较强，七基准实验与量化遗憾结论扎实。
白话概述：大模型常见做法是测试时多采样几个答案，再让验证器挑一个，但“信谁”很脆弱：单元测试、多数投票、LLM 裁判、奖励模型都会把错答案判对（假阳性）、把对答案判错（假阴性），不同模型还会在同一类题上一起栽跟头（共享盲区），同一个验证器反复调用也并非独立。更麻烦的是，给定固定预算，“采几个、从哪些模型采、留多少预算做验证”目前基本靠拍脑袋。SPLIT 先用少量带标签的 pilot 任务拟合出一个精确成功率公式——其中生成器有正确率、验证器有真阳性率与假阳性率、任务难度和模型间相关性也被显式建模——再用经验贝叶斯把任务难度、跨模型相关性、验证器相关误差估出来，进而在没见过的任务上规划采样数与验证次数。核心直觉是：测试时算力存在“精度天花板”，采样再多也只能逼近验证器能挑对的上限，所以预算必须同时买到覆盖率和验证精度，否则多采样只是喂给假阳性。
输入 Input: 少量带标注的 pilot 任务数据：各生成模型对任务产生的候选答案、代码或推理轨迹，验证器给出的接受或拒绝判定或连续分数，生成器与验证器的身份信息，以及总算力、价格和时延预算约束。
输出 Output: 面向未见任务的测试时算力分配方案：各生成器的采样数量与混合权重、验证器调用或重复投票次数、接受阈值与选择规则（均匀接受或取最高分），并附带该配置的预测成功率。
核心机制与技术实现 (Method & Formulation)
  • 在条件独立下给出 verified best-of-N 的精确成功率：单生成器为 $S_N=\frac{a}{s}\bigl(1-(1-s)^N\bigr)$，其中 $a=\tau p$、$s=a+f(1-p)$，成功率等于“至少一个被接受”乘以“被接受样本的精度”，并收敛到精度上限 $a/s$。
  • 把多模型混合、共享盲区与重复验证纳入同一框架：混合是否有益取决于生成器在彼此仍失败任务上的条件优势，用高斯 copula 相关系数 $\rho$ 刻画共同盲区；重复验证用候选级倾向 $q_c$ 与 Beta 分布建模，多数投票只有在 $F_k/F_1>T_k/T_1$ 时才不会压低大预算下的精度上限。
  • SPLIT 从 pilot 用经验贝叶斯拟合任务难度、跨模型相关性与验证器相关误差，再在未见任务上搜索采样数、混合权重、验证调用数与阈值以最小化遗憾；对 top-score 选择给出 $P_N=Np\,\mathbb{E}_{Y\sim G_c}\bigl[H(Y)^{N-1}\bigr]$ 的解析形式。
关键评测与消融结论 (Empirical Takeaway)
在 MATH、CodeContests、HumanEval、MBPP、MATH-500、GPQA、SWE-Bench Verified 七个基准、26 个模型、175 个 agent 系统和六类真实验证器上，SPLIT 与事后最优分配仅差 0.02 到 0.8 个百分点，而所有固定规则在至少一个设置中损失不少于 2.5 个百分点。

💡 评估判定：该论文聚焦 RLHF 后训练中的私有稀疏偏好奖励估计，首次给出 Sample-DP 与 Label-DP 的理论上下界，属于目标轨道的核心 RLHF 算法突破；但不涉及机械可解释性、SAE 或回路分析，且机构权威度非 DeepMind/OpenAI 级，故相关性与权威度未满。
白话概述：这篇论文解决 RLHF 对齐时偏好数据敏感、且奖励模型参数维度 $d$ 很大导致隐私噪声把估计误差放大的问题。它假设真正影响人类偏好的只有 $s^*$ 个特征（稀疏奖励），在 Bradley-Terry-Luce 成对比较模型下，用差分隐私（让单条样本或单个标签的改变几乎不改变输出分布）和迭代硬阈值（每轮只保留最重要的 $s^*$ 个参数坐标）来估计奖励。核心直觉是把有效维度从 $d$ 压到 $s^*$，从而在同样隐私预算下少加噪声、保住对齐效果。
输入 Input: 成对偏好数据：提示或上下文、两个候选回复、二值偏好标签；已知特征映射及隐私预算 $\varepsilon,\delta$。
输出 Output: 满足差分隐私的稀疏奖励参数 $\theta$（即奖励函数），供后续策略优化与对齐使用。
核心机制与技术实现 (Method & Formulation)
  • 在 BTL 模型下将成对偏好转为逻辑回归：奖励线性参数化为 $r_\theta(k,a)=\langle \phi(k,a),\theta\rangle$，比较特征为 $x_i=\phi(k_i,a_i^1)-\phi(k_i,a_i^0)$，并最小化逻辑损失 $\mathcal{L}_n(\theta)$，同时约束 $\|\theta\|_0\le s^*$。
  • Sample-DP 方法用噪声梯度加迭代硬阈值（IHT），每轮只保留绝对值最大的 $s^*$ 个坐标，得到参数误差上界 $\widetilde{O}(s^*/n+{s^*}^2/(n^2\varepsilon^2))$。
  • Label-DP 方法先对偏好标签做随机响应以保护单个标签，再执行稀疏 IHT，误差上界为 $\widetilde{O}(s^*/n+s^*/(n\varepsilon^2))$，并用下界说明 Sample-DP 近最优、Label-DP 在随机响应框架内不可再改进。
关键评测与消融结论 (Empirical Takeaway)
在 IMDb 情感生成与 AI2 有害提示安全对齐上，稀疏 DP-IHT/RR-IHT 在 $\varepsilon=2$ 和 $\varepsilon=8$ 时均以更低 KL 代价取得更高奖励，例如 $\varepsilon=8$ 时情感奖励为 2.87/2.88，高于 DP-SGD/RR 的 2.26/2.20。

💡 评估判定：论文直接针对 DPO 训练计算图做随机剪枝与无偏梯度估计，属于后训练偏好优化效率方向的核心算法与工程改进，但并非新的对齐目标或机械可解释性突破，且机构权威度中等。实验覆盖多种模型并量化加速、显存和精度权衡，较为扎实但未达顶尖水准。
白话概述：DPO 是一种让大模型学会偏向“好回答”、远离“坏回答”的偏好对齐训练方法；它每一步都要把好、坏两条回答完整跑一遍模型，对全词表逐个 token 打分，再对两条回答都做反向传播，因此非常昂贵。本文在真正开始计算之前就先做随机抽取：只给部分位置打分，只执行回答的前一段，并且只挑好或坏其中一条分支做反向传播，被跳过的计算直接不算，从而减少计算图的开销。为了不让“抽样”把训练目标带偏，作者用逆概率加权，也就是按被抽中概率的倒数放大该样本的梯度，等价于把抽样造成的偏差在期望上补回来，保证梯度估计条件无偏。核心直觉是：节省计算不应靠少看监督信号，而应对 DPO 计算图的各个阶段做可证明近似无偏的剪枝，用可控的目标方差换取显存与时延收益。
输入 Input: 偏好数据中的提示词、选中回答、拒绝回答，以及参考策略与当前策略在这些回答上的逐 token 对数概率；训练时还包含当前策略参数。
输出 Output: 随机剪枝后的 DPO 梯度估计及更新后的策略模型参数；推理阶段不改变模型原有的输出形式。
核心机制与技术实现 (Method & Formulation)
  • 将逐 token 的策略-参考对数比定义为 $u_{b,t}=\log \frac{\pi_\theta(y_{b,t}\mid x,y_{b,<t})}{\pi_{\mathrm{ref}}(y_{b,t}\mid x,y_{b,<t})}$，在长度归一化奖励 $R_b$ 与间隔 $\Delta=R_w-R_l$ 上最小化 $\mathcal{L}_{\mathrm{DPO}}=\log(1+e^{-\beta\Delta})$。
  • 在语言模型输出头之前采样位置子集 $\mathbb{S}_b$、执行前缀长度 $M_b$ 与单条偏好分支 $b^\star\in\{w,l\}$，只对选中位置计算 logits 与反向传播，并对采样分支乘以 $1/q_{b^\star}$，得到条件无偏的单分支梯度估计。
  • 理论分析给出位置剪枝的方差与最优性间隙上界；selected-head 实现在保留全部监督时也省去未被选位置的词表投影，避免引入 Proposition 1 描述的损失偏差。
关键评测与消融结论 (Empirical Takeaway)
在 Qwen3-4B/8B 与 Mistral-7B 上，分支剪枝相对拼接式 DPO 基线取得 $1.426\times$ 单步加速，训练时间较原始 DPO 减少约 30%，但平均准确率略降且开放生成分数随基准而变。

白话概述：线性注意力类模型（如门控 delta 网络）不像 Transformer 那样每 token 都追加一份 KV cache，而是把整段上下文压缩成一个固定大小的“循环状态矩阵”，显存占用与序列长度无关；但服务端每并发解码一条序列仍要独占一份该状态，于是把状态压成 4 比特就能让一张卡多跑几路请求。痛点是：已有做法“每生成一个 token 就把状态取整一次”，取整误差被递推公式一步步带进后续所有 token，导致 4 比特掉点明显，只能加位宽或微调补救。PACE 的直觉是三点：其一，像预填充阶段分块计算那样“隔几个 token 才取整一次”，中间新 token 先放进小缓冲区，减少误差注入次数；其二，作者发现状态里的大数值是按“列”（即 value 通道方向）聚集的，因为某些 value 通道在大量 token 上持续偏大，所以把量化步长（scale）的分组沿 key 轴切，让同组数值落在同一列内共享一个步长，避免小数值被大数值的粗步长抹平；其三，把衰减慢、误差最难消散的少数 head 单独保留 8 比特。三者叠加即得到免微调的四比特状态量化器。
输入 Input: 解码时每个 token 的循环更新量（逐 head 的标量衰减门、key 向量、value 向量）以及门控 delta 层维护的二维循环状态矩阵；量化前统计各列最大幅值与各 head 平均衰减系数
输出 Output: 量化压缩后的四比特（部分 head 八比特）循环状态与每列共享的 fp16 缩放因子，反量化后继续自回归解码，最终输出生成的文本 token 序列
核心机制与技术实现 (Method & Formulation)
  • 周期性取整与解码缓冲：状态仅由 kernel 写回处取整，预填充周期 $P=C=256$，解码周期 $dP$ 可调，中间 token 的 $(a_t,k_t,v_t)$ 存入缓冲区；误差每 token 被 $a_t(I-\beta_t k_t k_t^{\top})$ 衰减，单次注入误差 $e_h$ 的稳态累积上界为 $E_h=\frac{e_h}{1-a_h^{2\,dP}}$，周期越长误差越小。
  • 通道对齐的量化分组：把每个 head 的状态 $S\in\mathbb{R}^{d_k\times d_v}$ 沿 key 轴切成长度 $g$ 的组，使每组落在同一列内共享一个 fp16 缩放因子；依据是大值按列聚集（沿 value 轴分组的 max/RMS 比值更差），并通过置换 $u_t$ 通道的实验确认列结构源自跨 token 持续偏大的 value 通道。
  • 按 head 分配精度：由 $E_h$ 随 head 平均衰减 $a_h$ 增大的关系，把误差滞留最久的四分之一个 head 保持八比特（PACE-4/8），其余四比特；缓冲区中 key 用低比特、value 保留 bf16，因为对缓冲 value 降比特损伤更大。
