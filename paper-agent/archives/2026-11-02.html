💡 评估判定：核心贡献是对 DPO 偏好优化目标的原理性改造并用对抗训练强化，属于后训练对齐赛道内的实质算法突破；不含机械可解释性内容，工程上依赖大量攻击者与评判模型调用。
白话概述：提示注入指不可信数据（邮件、网页、文档）里夹带的指令被模型当成用户命令执行，现有最强防御 Meta-SecAlign 用 DPO 训练，却仍被自适应攻击打到接近 100% 成功率。问题出在 DPO 的“参考模型”项：它要求新模型不要偏离原始未防御模型太远，等于把防线拴在一个本就不安全的模型上；作者改为向一个“注入不变、效用不降”的理想 oracle 靠拢，并提出 SecPO 损失，这个 oracle 的输出分布在训练时恰好可近似获得。同时他们不再用弱模板攻击，而是让攻击者反复搜索出最强注入样本做对抗训练，让模型在“最坏情况”下学会只听从可信指令。
输入 Input: 按角色分离的对话消息：可信的用户指令放在 user 角色，不可信数据放在单独的 input 角色；不可信数据中可能嵌入攻击者指令，训练时使用攻击者搜索合成的强注入样本。
输出 Output: 防御后模型对可信指令的正常回复或智能体工具调用动作，不执行不可信数据中的注入任务；训练阶段额外产出安全对齐后的模型权重与带优化注入的训练集。
核心机制与技术实现 (Method & Formulation)
  • 沿用 prompt-data 角色分离：可信指令置于 user 角色，不可信数据置于 input 角色，训练模型只遵循前者；注入输入记作 $x_{\text{inj}}$，安全回复为 $y_w$，被注入劫持的回复为 $y_l$。
  • SecPO 用注入不变且保持效用的理想 oracle $\pi^{*}$ 替换 DPO 中的未防御参考模型 $\pi_{\text{undef}}$，损失为 $-\log\sigma\left(\beta\log\frac{\pi_\theta(y_w\mid x_{\text{inj}})}{\pi^{*}(y_w\mid x_{\text{inj}})}-\beta\log\frac{\pi_\theta(y_l\mid x_{\text{inj}})}{\pi^{*}(y_l\mid x_{\text{inj}})}\right)$，从而避免向不安全模型锚定。
  • 对抗训练每步让攻击者提出 $n=8$ 个候选注入，按推进注入目标的程度打 1-10 分，迭代 $T=30$ 轮得到 best@240 强注入；据此构建偏好数据，用 LoRA 微调 Llama-3.1-8B，并对 Qwen3.6-27B 做离线对抗训练。
关键评测与消融结论 (Empirical Takeaway)
SecPO+AT 相对 Meta-SecAlign 在三种自适应攻击下将 ASR 降低 1.5-14.5 倍，相对纯 DPO 再降 2.4-4.6 倍；AgentDojo 的 AttackerMovesSecond 攻击下 ASR@800 由 78.8% 降至 8.8%，九个良性基准无明显效用损失。

💡 评估判定：论文直接处理 DPO 偏好数据中的标签反转与噪声，提出可靠性加权联合估计机制，属于后训练偏好优化的核心算法工作；但机构为肯尼索州立大学，实验以线性索引模拟和有限语言模型微调为主，权威度与评测广度限制了综合分。
白话概述：DPO 默认把每条人类偏好比较都当成正确标签，但真实数据里常有标反、平局或随手乱标的噪声。RW-DPO 给每条比较配一个 0 到 1 的可靠性权重：权重为 1 表示完全相信这条标签，权重为 0 表示应当反转，权重为 0.5 表示这条比较没有信息量。它让权重直接乘在模型与标注的一致度上，并加一个稀疏惩罚，使模型认同的比较保持满权重，只对被模型强烈矛盾的少数比较降权或反转。权重和策略交替优化，额外开销很小，因此能在不显著增加成本的情况下，从含噪偏好数据里学出更稳的策略。
输入 Input: 文本偏好数据，包括提示词、同一提示下的两个候选回复，以及可能含反转、平局或噪声的偏好标签。
输出 Output: 微调后的语言模型策略参数，以及每条比较的可靠性权重和疑似反转标签标记。
核心机制与技术实现 (Method & Formulation)
  • 为每条比较引入可靠性权重 $w_i\in[0,1]$，将观测标签概率写成 $r_i(\theta,w_i)=\frac{1}{2}+(w_i-\frac{1}{2})m_i(\theta)$，其中 $m_i(\theta)=Y_i\tanh(d_i(\theta)/2)$，统一表达 DPO、降权、平局和反转四种情形。
  • 在 $u_i=-\log w_i$ 上施加 minimax-concave penalty $\varrho(u_i;\lambda,a)$，使 $w_i=1$ 成为精确解，只对模型矛盾的比较按证据降权，并允许以有限代价处理完全反转。
  • 采用交替优化：固定策略时对权重做闭式或近似闭式更新，固定权重时执行加权 DPO 更新；理论分析表明在间隔约 $\log n$ 时可识别反转比较并一致恢复偏好方向。
关键评测与消融结论 (Empirical Takeaway)
在 10-30% 标签反转的 DPO 微调中，RW-DPO 的胜率不随反转率上升而下降，甚至超过用干净标签训练的 DPO；模拟中相对估计误差为 0.381，DPO 为 0.632，且修正主要集中在真正反转的标签上。

白话概述：端到端自动驾驶模型能规划但内部像黑箱，难以观察和信任。本文先训练一个仅用前视单目图像、历史自车状态和路线意图的轻量规划模型，再把模型内部激活送入稀疏自编码器（SAE）拆解：SAE 强制用少量稀疏特征重建激活，类似把混杂信号拆成可单独检查的开关。作者用无监督聚类发现特征对应路线意图和车速，用反事实图像编辑（只改红绿灯或停止标志再看特征是否响应）证明特征有视觉依据，并通过直接调大或调小单个特征观察轨迹横向偏移、曲率和刹车是否按预期变化，从而把黑箱内部表示变成可解释、可干预的部件。
输入 Input: 前视单目RGB图像、历史自车状态（速度、转向等）、路线意图（直行/左转/右转的one-hot向量）。
输出 Output: 未来多步自车轨迹位姿序列；模型先生成多个候选轨迹并逐条评分，最终输出评分最低的轨迹。
核心机制与技术实现 (Method & Formulation)
  • 构建单目轨迹评分器SMTS：ViT提取前视图像特征，路线意图与历史自车状态仅注入初始查询token，经4层Transformer解码出多组候选轨迹，再由评分头选出最低代价轨迹。
  • 在每层Transformer的查询激活上训练TopK稀疏自编码器，编码为$z=\mathrm{ReLU}(\mathrm{TopK}(W_{\mathrm{enc}}\tilde{x},k))$，并用AuxK辅助损失缓解死特征，得到稀疏潜在表示。
  • 对最终层潜在$z_3$做共激活聚类、反事实图像编辑和单特征操控，验证语义对齐与因果效应；再用SAE特征训练轻量适配器改善轨迹选择。
关键评测与消融结论 (Empirical Takeaway)
SMTS在WOD-E2E验证集取得1.40米ADE，SAE特征聚类以98.3%准确率无监督恢复路线意图，基于SAE特征的适配器将轨迹选择误差降低3.44%。

💡 评估判定：论文针对 DMD 少步蒸馏的 critic 容量匹配与步感知设计，属于 flow/diffusion 与视频生成加速的核心机制改进，但并非新的流匹配或视频生成基础模型，故相关性未给满分；Adobe Research 与 MIT 机构权威度高，实验覆盖 ImageNet、SDXL、FLUX.2 与 Wan2.1，结论扎实。
白话概述：这篇论文研究少步生成模型蒸馏方法 DMD 中的一个关键瓶颈：学生模型靠“教师模型的分数场”减去“在线 critic 估计的学生分布分数场”来学习，但 critic 若太小或看不到步数信息，教师再大也会把学生带崩。通俗说，score（分数场）就是指向“更像真实数据”的梯度方向，critic 是边训练边判断学生当前输出像不像真实分布的裁判；作者发现裁判必须和教师同步扩容（joint scaling），并且要知道学生现在走到第几步（STAC），否则会把不同步的输出混成一个平均目标，给出错误方向。核心直觉是：蒸馏不是单向模仿，而是一个动态对抗式的分布匹配过程，裁判的质量决定学生能走多远。
输入 Input: 预训练教师生成模型、待蒸馏学生模型、训练图像或视频及文本/类别条件、当前采样步与含噪潜变量。
输出 Output: 蒸馏后的少步学生生成器与在线 critic 的分数估计；推理时由条件与噪声直接生成图像或视频。
核心机制与技术实现 (Method & Formulation)
  • DMD 用教师与学生分布分数场之差构造学生更新方向：$\Delta s=s_{\phi}(x_t,t)-s_{\mathrm{teacher}}(x_t,t)$，学生沿该差的反传梯度更新，使少步分布逼近教师。
  • Joint scaling：控制实验发现只放大教师而 critic 固定会使 FID 先降后升甚至崩溃，因此让 critic 容量与教师同步放大，以持续跟踪学生变化分布。
  • STAC：不再让 critic 拟合与步数无关的学生输出混合分布，而是条件于学生生成步 $k$ 估计步专属分数场 $s_{\phi}(x_t,t,k)$，减少多步分布混叠。
关键评测与消融结论 (Empirical Takeaway)
ImageNet 1-step B 学生上 XL/XL 教师-critic 达 FID 13.5，优于 B/B 的 16.8，错配 XL/B 后期恶化至 41.7；FLUX.2 4-step 4B 学生配 32B 教师/critic 与 STAC 达 HPSv3 12.32、DPG-Bench 85.28，SDXL FID 从 18.95 降至 16.88，并扩展到 Wan2.1 文生视频。

白话概述：自回归视频生成靠逐帧流式预测省算力，但现有方法通常固定在某个采样步数，少步或一步时画质下降，长序列还会因误差累积导致画面漂移甚至崩溃。Any Forcing 用一个共享特征的对抗判别器同时扮演三类裁判：真实分布对齐（输出得像真视频）、跨步一致性对齐（让 2 步和 4 步的结果别差太远）、首帧质量增强，从而让同一生成器可在任意步数采样且一步也稳定。长视频部分用免训练的自适应记忆挑选历史帧：按全局语义相关性和局部贡献决定哪些历史进入缓存，并把它们的时间位置重映射到模型训练过的范围，避免缓存越堆越乱。
输入 Input: 文本提示嵌入、初始高斯噪声潜变量和目标采样步数；长视频自回归生成时还包括历史帧潜变量与记忆缓存。
输出 Output: 解码后的视频帧序列（480p），覆盖 5 秒短视频及 30/60 秒长视频。
核心机制与技术实现 (Method & Formulation)
  • 统一对抗判别器复用 fake-score 模型的中间特征 $\boldsymbol{h}_t=\mathcal{H}_\phi(\boldsymbol{x}_t,t)$，共享主干、三个分类头分别做真实分布对齐、跨步一致性对齐和首帧增强，使同一生成器支持任意采样步数。
  • 学生生成器 $G_\theta(\boldsymbol{z},\boldsymbol{c},k)$ 与 fake-score 模型 $F_\phi$ 交替优化，以 DMD 反 KL 梯度 $\nabla_\theta \mathcal{L}_{\mathrm{DMD}}$ 做分布匹配蒸馏，并在前 200 步加入教师 ODE 端点监督。
  • 免训练记忆选择按全局语义相关性与局部价值贡献筛选历史状态，并把记忆的时间位置重映射到已训练的 RoPE 范围内，以稳定一步长视频生成。
关键评测与消融结论 (Empirical Takeaway)
在 VBench 上，四步降到两步总分仅降 0.24%、后续帧降到一步仅降 0.04%，而 Causal Forcing 对应降 2.37%；单张 H100 上短/长视频分别达 20.9 FPS 与 24.7 FPS。

白话概述：端到端自动驾驶的视觉模型每帧要处理几千个图像 token，但其中大部分是天空、楼房和空路面，这些内容与规划无关，还会分散 planner 的注意力；作者发现随机丢掉 75% 的 token 反而比稠密模型更好，说明“看哪里”本身比“看得多”更重要。为此提出 GATS：在视觉 backbone 运行之前，先用 LiDAR 和雷达点投影到图像上形成的几何统计（深度、离地高度、多帧运动残差、雷达径向速度）给每个 patch 打分，只把少数关键 patch 送进网络。被选中的 patch 会获得一个“3D anchor”，即该 patch 内 LiDAR 点的真实世界坐标，相当于给每个 token 贴上一个米制坐标标签，让不同相机、不同历史帧的 token 能在同一个 3D 空间里对齐。然后这些 token 进入自监督 latent world model，也就是在压缩的特征空间里预测未来视觉特征和未来 3D 位移，不需要 3D 框标注；最后由规划头读出状态并输出自车轨迹。核心突破是用“测得的几何”而不是“学出来的视觉注意力”来决定看哪里，因此在极低 token 预算下仍能超过稠密模型。
输入 Input: 多相机 RGB 图像序列、多帧 LiDAR 点云、雷达检测、自车状态与历史位姿；LiDAR 与雷达点投影用于 patch 打分、生成 3D anchor 与几何统计。
输出 Output: 未来 3 秒自车轨迹（各未来时间步的位移量），以及 world model 预测的未来视觉 latent 特征与 3D 位移。
核心机制与技术实现 (Method & Formulation)
  • GATS 把多帧 LiDAR 与雷达检测投影到图像 patch，构造 16 维几何统计向量，并用障碍物流、道路流、视觉保留流三路打分，在视觉编码前选出 $K=\lceil \beta N\rceil$ 个 token，使稠密视觉编码变为稀疏编码。
  • 每个保留 token 以 patch 内 LiDAR 中值点作为 3D anchor $\mathbf{a}_i$，历史 anchor 经里程计变换 $\tilde{\mathbf{a}}_i^{t-k}=\mathbf{T}_{t-k\to t}\,\mathbf{a}_i^{t-k}$ 对齐到当前自车坐标系，并用于跨相机关联、跨帧对齐与 3D 位置编码。
  • 稀疏 token 进入自监督 latent world model 预测未来特征与 3D 位移，规划头输出轨迹；训练时用 Gumbel 噪声加 stop-gradient 门控 $w_i=1+\tilde{s}_i-\operatorname{sg}(\tilde{s}_i)$，让离散 top-$K$ 选择仍可反向传播。
关键评测与消融结论 (Empirical Takeaway)
25% token 预算下 GATS 在 nuScenes 取得 0.520 m 的 3 秒 L2 误差、在 NAVSIM 取得 88.9 EPDMS，均超过稠密基线（0.573 m / 85.9），且总 FLOPs 少 6.6 倍；10% 预算下仍保持领先。
