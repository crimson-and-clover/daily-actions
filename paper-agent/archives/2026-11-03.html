💡 评估判定：论文直接把测试时训练用于多轨迹推理聚合，通过 LoRA 内循环和双层元学习实现参数级信息整合，属于目标赛道的核心机制突破；EPFL/Bosselut Lab 权威度较高，但每题多步 TTT 带来额外推理开销，工程实时性一般。
白话概述：对同一道题让模型采样多条推理链，多数投票只看最终答案，会丢掉错误轨迹里有用的中间推导；把整堆轨迹塞进上下文又会被长上下文拖累。TTT-Consolidate 把这条轨迹集合当作“临场训练数据”，在测试时用少量梯度步把信息写进一个很小的 LoRA 适配器参数里，相当于让模型先“消化”这些思路再答题。它还通过双层元学习训练“如何消化”：内层用自监督语言建模把轨迹编码进 LoRA，外层用 SFT 或可验证奖励强化学习调整元参数，使消化后的参数真正帮助生成最终解。
输入 Input: 自然语言数学/STEM 题目 $Q$，以及多个 LLM 对该题采样得到的多条推理轨迹（每条含中间推理步骤与候选答案）；测试时不需要真实答案。
输出 Output: 聚合后的最终答案或完整解题文本；训练阶段还会输出更新后的 LoRA 参数。
核心机制与技术实现 (Method & Formulation)
  • 内层测试时训练：以多条轨迹 $\mathcal{R}$ 的负对数似然为目标，从基座参数 $\theta$ 出发仅更新 LoRA 参数，执行 $S$ 步梯度下降得到 $\phi^{(s)}=\phi^{(s-1)}-\alpha\nabla_{\phi^{(s-1)}}\mathcal{L}_{\text{NLL}}(\phi^{(s-1)};\mathcal{R})$，把轨迹信息从上下文转移到参数中。
  • 外层元学习：用双层优化 $\theta^\star=\arg\min_\theta \mathbb{E}_{(Q,\mathcal{R},y^\star)}[\mathcal{L}_{\text{outer}}(\phi(\theta,\mathcal{R});Q,y^\star)]$ 学习内循环元参数，使整合后的模型在问题 $Q$ 上生成最终解；外层目标可采用 SFT 或 RLVR。
  • 构造 OpenParallelThinking 语料：12,810 道数学题配六个 LLM 的混合推理轨迹，用于训练整合器，并在 AIME、IMO、GPQA 等数学与 STEM 基准上评测。
关键评测与消融结论 (Empirical Takeaway)
在匹配算力与运行时间下，TTT-Consolidate 在数学与 STEM 推理基准上最高超过最佳聚合基线 20 个百分点，且可用轨迹数增加时对错误轨迹的鲁棒性提升。

💡 评估判定：论文直接研究测试时算力在视觉 token 与思维链之间的分配，并给出黑盒阶段诊断协议，属于推理扩展与测试时计算方向，但不是 TTT 参数更新、过程奖励模型或 MCTS 搜索式推理的核心突破。机构为孟菲斯大学与新加坡国立大学，实验覆盖两模型六数据集且含反事实对比与自助法区间，扎实度较好。
白话概述：视觉语言模型答错时，开发者往往只看到最终答案错了，却分不清是没看见、没想清，还是看见了却没用上，于是测试时算力（多给视觉 token 还是多给思维链）不知道该加在哪里。作者提出 See, Think, Use 黑盒诊断协议：用定位探针让模型框出问题涉及的每个实例来测“看见”，用文本替换探针把图片换成文字描述再作答来测“思考”，用反事实图像对（同一问题、图像被编辑以改变证据）比较模型自己的框与最终答案来测“使用”。核心直觉像分科室查病灶：若模型框随图像编辑改变而答案不变，就是“看见但没用”；若框本身错，就是“看”的问题；若框对但脱离图像答错，就是“想”的问题，由此把测试时算力加到真正短板。
输入 Input: 输入为 RGB 图像与问题的配对及同一问题下的反事实图像对；模型侧额外接收定位探针提示（框出每个实例）、文本替换探针提示（用文字描述替代图像作答），并可在不同视觉 token 预算与是否启用思维链/多票采样下作答。模型视为黑盒，不读取权重或激活。
输出 Output: 输出每个样本的失败阶段诊断（看错、想错、看见未用、真实正确等五类结果），以及推荐的测试时算力配置（视觉 token 预算、是否思维链、是否先定位再作答或裁剪放大）；最终仍输出视觉问答答案。
核心机制与技术实现 (Method & Formulation)
  • 三探针黑盒归因：定位探针返回框集合 $A(v,q)$ 并判断 $a(v,q)$，文本替换探针返回 $B(v,q)$ 或 $B_{\text{self}}$ 并判断 $b(v,q)$，据此把答案分为真实正确、未看而正确、看见未用、想错、看错五类。
  • 使用率无需答案标签：在反事实图像对集合 $\mathcal{P}$ 上计算 $\text{Use}=\Pr[C(v,q)\neq C(v',q)\mid A(v,q)\not\sim A(v',q)]$，即模型自身感知改变时最终答案是否跟随改变。
  • 测试时算力调度：用 see 旋钮 $s$ 控制视觉 token 预算，用 think 旋钮 $r$ 控制直接作答或五票思维链，并用先定位再作答/裁剪放大改变固定预算下的使用方式，再按诊断出的短阶段分配算力。
关键评测与消融结论 (Empirical Takeaway)
在 V* 的 Qwen 定位探针错误样本上，提高视觉 token 预算把准确率从 49.0% 提到 77.6%；在 MathVerse 的 Qwen 文本替换探针错误样本上，启用思维链把准确率从 32.3% 提到 68.2%，说明有效旋钮随失败阶段而变。

💡 评估判定：论文把 test-time compute 档位当作唯一自变量，量化其在形式语法难度梯度上的收益与代价，直接命中“推理扩展”主题，并给出能分辨细粒度档位差异的可计算理论基准；但它是评测与分析型工作，未提出新的推理算法或扩展机制，且只覆盖单一模型家族与两类语法，故相关性与创新性未打满。Dartmouth College 属知名研究型高校但非顶级 AI 实验室，权威度居中上。
白话概述：论文要回答一个很直白的问题：模型在推理阶段多花算力（test-time compute，即让模型在作答前“多想一会儿”，对应 medium/high/xhigh 三档思维链预算），它的计算能力究竟有没有真的变强？作者用可计算理论造了一把“语法透镜”：按形式语法的强弱层级，机器生成一批“由英文单词拼成、语法结构合规但语义毫无意义”的句子，让模型零样本判断“这句话合语法吗”。关键直觉是：句子内部的依赖结构越复杂（比如嵌套、跨长距离的呼应关系），正确解析它所需的计算能力就越高，所以若模型真的“多想了”，就该在最难那档句子上接受率更高。结果 GPT-5.5-Pro 随推理档位提升，在最强语法（上下文相关语法）上的接受率单调上升 16%→40%→43%→52%，说明这个基准能分辨出极细微的推理档位差异；但同时模型与人类判断的分歧也随算力增加而扩大，提示可能存在“能力越强、越偏离人类直觉”的通用张力。
输入 Input: 由形式语法生成器产出的英文单词串：IXG 类由树邻接语法生成，含嵌套与长距离依赖、接近自然语言结构；CSG 类由上下文相关语法生成，依赖强度超出任何人类语言规则。每条句子配上“是否合语法”的二分类提示，并标注所用推理努力档位与重复采样次数。
输出 Output: 每条句子的二值合语法判断（yes/no）、追加提示下生成的具体句法解析结构，以及各配置的接受率、单次查询耗时与相对人类判断的一致率。
核心机制与技术实现 (Method & Formulation)
  • 用可计算理论构造难度梯度：树邻接语法生成的 IXG 语言严格位于上下文无关语言与索引语言之间，而上下文相关语法生成的 CSG 依赖强度超出自然语言，从而把“解析所需计算能力”变成可控自变量，而非依赖人工标注难度。
  • 把推理努力档位作为唯一自变量，固定提示与采样参数，每个“模型—语法”格子重复 50 次（约 $2{,}500$ 次查询），以接受率 $A_{m,g}=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}[\hat{y}_i=\text{yes}]$ 与单查询耗时刻画算力—能力曲线。
  • 增加解析生成校验：在判断之后要求模型输出具体 parse，检验“答 yes”是否真对应成功解析而非投机接受；并以人类判断为参照统计分歧率 $D=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}[\hat{y}_i\neq y^{\text{human}}_i]$ 随档位的变化。
关键评测与消融结论 (Empirical Takeaway)
在最难的 CSG 语法上，GPT-5.5 与 Pro 的默认/medium/high/xhigh 接受率单调升至 16%/40%/43%/52%（IXG 已近 97% 天花板），证明该基准能分辨细微的 test-time compute 差异，但模型与人类判断的分歧同时随算力增加而扩大。

💡 评估判定：论文属于机械可解释性与 SAE 特征操控的核心研究，直接回答技能条件如何改变内部概念知识的“使用”而非“编码”，契合目标轨道的可解释性方向；但它并非 RLHF/DPO 等后训练强化学习算法创新，故相关性未给满分。多伦多大学团队权威度较高，实验覆盖百万级局面与 172 个概念且含迁移与消融，结论扎实。
白话概述：同一个国际象棋 Transformer（Maia-2），只要附上“低水平棋手”的标签就会走出明显昏招，但它究竟是“不懂棋”还是“懂棋却不用”？作者用线性探针（在模型内部激活向量上训练一个极简线性分类器，看某个概念能否被读出来）检验 172 个人类可解释的棋类概念（如王的安全、战术模式），发现无论技能标签高低，这些概念的编码都同样清晰，还能跨档位迁移，说明知识并未丢失；接着只重训最后一层输出头，或沿着稀疏自编码器（SAE，把高维激活拆解成大量稀疏、可解释特征方向的字典学习方法）找到的概念特征方向去“操控”内部激活，低档位下最佳着法的准确率就从 14.4% 跃升到 82.8%。核心直觉是：技能条件更像一个调音旋钮，改变的是已保留知识如何参与走子选择，而不是知识本身，因此较弱的对外行为会低估模型内部实际掌握的东西。
输入 Input: 棋盘局面（棋子位置与行棋方）、玩家与对手的 Elo 技能类别嵌入（实验中令两者相同）；分析阶段读取 Transformer 残差流内部状态用于探针与 SAE 分析。
输出 Output: 每个局面的走子概率分布及首选着法；以及探针预测的 172 个棋类概念标签、微调输出层或 SAE 特征操控后的走子预测。
核心机制与技术实现 (Method & Formulation)
  • 将 Maia-2 记为 $\hat{a}=f_\theta(\mathcal{B},e_a,e_o)$，固定棋盘 $\mathcal{B}$ 与权重 $\theta$，只改变技能嵌入 $e$，构建从失误着法单调转为最佳着法的 Blundered Transitional Dataset，以隔离技能条件引发的行为差异。
  • 在每层平均池化残差流 $\mathbf{z}(\mathcal{B})$ 上训练 $\ell_1$ 正则线性探针 $g(\cdot\mid\mathbf{w})$ 预测 172 个二元棋类概念，比较各技能档的探针准确率并做跨档迁移测试，以衡量知识编码是否稳定。
  • 仅微调共享输出层，或沿 SAE 学到的概念相关特征方向做 steering（激活干预），检验低技能状态中保留的知识能否被直接恢复为更强着法。
关键评测与消融结论 (Empirical Takeaway)
在最低技能档，仅重训输出层即可将最佳着法准确率从 14.4% 提升到 82.8%，且用最高技能档表示训练的该层仍能在低档保留大部分增益，同时探针测得的概念编码几乎不变。

白话概述：临床电子健康记录（EHR）上的深度模型预测准，但内部到底在“看”什么很难说清；传统逐单元格归因方法（例如把每个时间点、每个化验值单独打分）得到的是一张散乱的热力图，既没有时间连贯性，也无法复用到别的病人身上。论文提出 TI-SAE，在冻结的预训练预测模型表示上学习一个跨患者共享的“临床概念字典”：每个概念都配有一个“时间高斯岛”（一个可学习中心与宽度的软时间窗，用来表示这个概念在病程的哪一段被激活）和一个稀疏变量组成向量（表示它由哪几个化验指标或生命体征构成）。训练完之后，再用一个独立的预测选择器挑出真正驱动该患者预测结果的那几个概念，从而把“学概念”和“做归因”解耦。关键直觉是：与其在输入上逐点打分，不如先把模型内部表示压成少量结构化、可命名的概念，再回头看哪些概念在起作用。

输出 Output: 预训练：被掩码时空片段的潜在视觉表征预测（非像素重建）；下游：未来自车轨迹 / 规划动作。
核心机制与技术实现 (Method & Formulation)

  • 辅以自车运动与单目深度探针定量刻画冻结表征中时序与几何信息的随规模增长规律。

输入 Input: 慢系统在较早时刻输出的3D语义占据logits、快系统在该时间段内连续到达的占据logits序列、自车运动位姿与各帧时间间隔

核心机制与技术实现 (Method & Formulation)
  • 将快慢融合写成连续时间受控动力系统，状态取慢/快logits残差，由快logits流在任意时间间隔上驱动演化：$dH_t^w=\mathcal{G}_\theta^w(H_t^w,X_t^w)dX_t^w$，摆脱固定步长对不规则延迟的失配。

  • 以体素语义监督加射线引导几何一致性联合训练，仅训练演化模块而不改动上游快慢系统，对具体占据架构保持无关性。
