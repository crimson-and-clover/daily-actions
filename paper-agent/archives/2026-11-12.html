白话概述：稀疏自编码器（SAE）常被当作模型内部特征的“词典”，但常用指标（方差解释率、消融损伤）会被巨量激活带偏：少数维度或位置上的极端大值让第一主成分 PC1 占据绝大部分方差，而 PC1 没有唯一的稀疏拆法，不同随机种子便用不同特征去拼它，导致重要特征排序不可复现。作者的做法是先减掉 PC1 再训练 SAE，重构时再加回 PC1，让稀疏特征只学习剩下的“内容子空间”。直觉是：不要把全局最大方差方向误当成可解释特征，否则评测会被它绑架。
输入 Input: 大语言模型中间层残差流激活向量（GPT-2、Pythia、Qwen、Llama、Gemma 等模型在 WikiText-103 上的 token 激活）
输出 Output: SAE 稀疏特征字典与激活重构；特征重要性与消融排序；修正后的方差解释率、内容重构误差和跨种子特征共享率
核心机制与技术实现 (Method & Formulation)
  • 定位混淆：巨量激活使未中心化激活的方差高度集中在第一主成分，$w_1$ 可接近 0.999；PC1 缺乏唯一稀疏分解，不同种子会用不同特征铺满该方向，使 top-50 重要特征跨种子共享率低于随机基线。
  • 修正训练：先去掉 PC1 投影 $P_\perp = I - \mathbf{v}_1\mathbf{v}_1^\top$，在 $P_\perp\mathbf{x}$ 上训练 SAE，重构时加回 PC1 分量，使稀疏特征只解释内容子空间。
  • 评测拆解：用 $\mathrm{FVU}_{\mathrm{content}}$ 度量 PC1 外重构误差，用 decoder 余弦匹配 $\max_l \cos(\mathbf{d}_j,\mathbf{d}'_l)\ge 0.7$ 度量跨种子可复现性，并配合消融与 splice cost 检验模型损伤。
关键评测与消融结论 (Empirical Takeaway)
在受 PC1 主导的模型中，修正后 top-50 特征共享率从 4–39.5% 提升到 73–99.5%，同等 TopK 稀疏度下消融损伤最多降低 44%，内容重构误差最多降低 33.9%。

💡 评估判定：论文直接剖析 RLHF/Constitutional AI 中损失式奖励建模与偏好聚合的公理性质，属于对齐后训练的理论核心；但不涉及 SAE、回路分析等机械可解释性内容，且为理想化理论构造、无实证基准，故实验分低。作者来自牛津大学理论计算机方向，权威度较高。
白话概述：RLHF 训练奖励模型时只用人写的成对比较（“A 比 B 好”）来拟合打分函数；Constitutional AI 进一步把多条原则（更有帮助、更少毒性等）当成多个“投票人”。这篇论文问的是：如果所有原则都认为 A 比 B 好，聚合出来的奖励会不会仍然给 B 打高分？这就是 Pareto 最优性（PO）被违反。作者把每条原则看作嵌入空间里的一个线性方向（依据线性表示假设：语义属性可用一个向量方向近似表示），把奖励模型看成对这些方向的加权打分，并证明：即使把奖励模型升级成任意固定次数的多项式或任意宽度 $d\ge 2$ 的一层 ReLU 网络，只要仍用损失函数去拟合比较数据（如 Bradley-Terry 交叉熵 $\log(1+e^{x})$），PO 依然可能失效；真正的解法在于设计比较数据的分布，比如让比较方向均匀、长度一致。
输入 Input: 多条对齐原则各自的成对响应比较集合（每个原则给出“响应 A 优于 B”的偏好对）、候选响应的固定嵌入向量，以及所选损失函数与奖励模型族（线性、多项式或单隐层 ReLU 网络）。
输出 Output: 训练得到的奖励函数及其诱导的候选排序；理论层面输出该排序是否满足 Pareto 最优性、成对多数一致性等公理。
核心机制与技术实现 (Method & Formulation)
  • 把每条原则建模为选民，偏好数据为 $(a,b)\in P_i$ 且 $a\prec_i b$；线性奖励取 $r_\theta(x)=\langle \theta,x\rangle$，通过最小化 $\mathcal{L}(r)=\sum_{i}\sum_{(a,b)\in P_i}\ell\bigl(r(a)-r(b)\bigr)$ 聚合偏好，Bradley-Terry 损失对应 $\ell_{\mathrm{BT}}(x)=\log(1+e^{x})$。
  • 构造反例证明：奖励模型扩展为任意固定次数多项式或宽度 $d\ge 2$ 的一层 ReLU 网络（参数有界）后，仍存在数据使最优解违反 Pareto 最优性，即模型容量提升不足以修复公理违背。
  • 在线性奖励、比较方向均匀且比较长度相等等理想假设下给出恢复 PO 的条件；并据此提出以数据集设计（控制比较方向与覆盖）作为 constitutional 风格对齐中保留损失式训练同时满足公理的手段。
关键评测与消融结论 (Empirical Takeaway)
全文为理论分析、无基准实验，核心结论是增大奖励模型容量（多项式或单隐层 ReLU）仍无法保证 Pareto 最优性，比较数据的方向与长度设计才是恢复 PO 的关键。

💡 评估判定：该方法属于机械可解释性核心工作：它把反事实激活对比、残差流组件归因和定向权重编辑结合起来，用来消除虚假特征依赖；虽然不属于 RLHF/DPO 一类后训练优化算法，但在可解释性与行为修正机制上有扎实突破。机构包括西湖大学、剑桥、耶鲁、图灵研究院与阿里，实验覆盖五个推理模型、五个基准，较为充分。
白话概述：论文要解决的问题是：大模型做数学推理时，只要在题目里塞进一句完全无关的废话，正确率就会明显下降；这说明它有时靠的是“虚假相关特征”（看见某些字眼就照套路走），而不是真正按条件推演。作者提出 SWEET：先做“反事实对照”，即把同一道题加上无关干扰，但保证答案不变，然后比较模型在两种输入下的内部激活差异，从中提取一个“行为方向”，也就是内部表示空间中指向虚假推理倾向的一根箭头。接着用“残差流加和分解”的思路，把模型每一层的注意力头和 MLP 神经元看作各自往同一块公共黑板（残差流）上加一笔输出；把每个组件的输出投影到这个方向上，看得分正负，就能知道谁在助推这种错误行为。最后直接改动这些组件的权重，削弱它们的贡献，全程不训练、不微调，推理时也不增加任何开销。
输入 Input: 编辑阶段：原始数学题、加入无关干扰的 NoOp 扰动题，以及模型在两者下的推理轨迹和残差流激活；部署阶段：任意数学推理题文本。
输出 Output: 编辑后的模型权重，以及该模型对输入题目生成的分步推理与最终答案。
核心机制与技术实现 (Method & Formulation)
  • 用 NoOp 构造原题与扰动题对，只保留模型原题答对、扰动题答错的样本；固定参考轨迹，按 token 级 KL 分歧挑选关键位置，对比残差流激活得到 token 级与序列级行为方向，并用跨对标准差归一化 $\mathcal{V}_\ell$ 抑制噪声维度。
  • 依据残差流可加分解 $c_{\ell,h}^{\mathrm{Attn}}(s)=W_O^{\ell,h}z_{\ell,h}(s)$ 与 $c_{\ell,j}^{\mathrm{MLP}}(s)=a_{\ell,j}(s)W_{\mathrm{down}}^{\ell}[:,j]$，用方向投影 $A_u^{g}(s)=(d_\ell^{g})^{\top}c_u(s)$ 对每个注意力头与 MLP 神经元打分排序，定位应对虚假推理负责的单元。
  • 对选中单元施加定向权重编辑以压低其沿该方向的贡献，并进行组件分配与稀疏度校准；仅需约 20 对样本，无需训练，推理时零额外开销。
关键评测与消融结论 (Empirical Takeaway)
在五个开源推理模型与五个数学推理基准上，SWEET 使扰动输入准确率平均提升 11.8 个百分点、原题提升约 2 点，并把原题与扰动题之间的相对精度差从 17.6% 压到 2.5%。

💡 评估判定：论文直接研究 Flow Matching 训练目标在目标损坏与标签噪声下的鲁棒性，属于流匹配核心训练机制而非边缘借用，但未涉及视频生成基础模型或大规模生成架构突破；KTH 与 Cambridge 机构权威度较高，实验覆盖 2D、CIFAR 与 WebVision 但规模有限。
白话概述：Flow Matching（流匹配）把生成过程学成一个随时间变化的速度场：从噪声出发，按预测速度一步步走到数据。通常训练假设终点样本和标签都干净，但现实会有目标损坏（样本本身坏了）和标签噪声（类别标错）。论文把训练看成速度回归，发现样本损坏会让残差（预测速度与真实速度之差）随时间变大、标签错会把模型拉向错误类别的速度场，于是提出两种残差评分给可疑样本降权，相当于让模型少跟坏样本学。
输入 Input: 训练时输入目标样本（可能损坏）、条件标签（可能含噪声）、源噪声样本、插值状态与时间步；推理时输入源噪声与条件标签。
输出 Output: 条件速度场预测，以及沿该速度场积分生成的干净样本或图像。
核心机制与技术实现 (Method & Formulation)
  • 将条件 Flow Matching 视为逐样本速度回归，损失为 $\mathcal{L}_{\mathrm{CFM}}(\theta)=\mathbb{E}[\|v_{\theta,t}(x_t,y)-u(x_0,x_1)\|_2^2]$，并以残差 $r_\theta=v_{\theta,t}(x_t,y)-u(x_0,x_1)$ 作为鲁棒加权信号。
  • 目标损坏时插值状态变为 $\tilde{x}_t=x_t+t\Delta_1$、速度目标偏移为 $\tilde{u}=u+\Delta_1$，TRS 利用中后段 $t$ 残差更可分的特性对可疑样本降权。
  • 标签噪声下 CCS 比较观测类条件速度场残差与替代类条件速度场残差，将错类条件更新降权，并通过评分到权重映射 $\omega$ 实现鲁棒训练。
关键评测与消融结论 (Empirical Takeaway)
2D 螺旋目标损坏中 FM-TRS 的 $W_2$ 与 MMD 低于 OT-FM 及 L1/Huber 基线且 Coverage 更高，CIFAR 与 WebVision 上相对标准 FM 和鲁棒训练基线也有提升。

💡 评估判定：论文面向视频扩散 Transformer 的混合分辨率生成加速，属于视频生成基础模型的核心架构与效率问题，但并非流匹配或连续时间生成本身的机理突破；UT Austin 与 Roblox 联合团队实验规模较扎实。
白话概述：视频扩散 Transformer（DiT，用 Transformer 逐步去噪生成视频的模型）画质好但算力极贵；混合分辨率生成的思路是让主体等视觉重要区域用高分辨率、背景用低分辨率来省算力，但现有做法画质明显变差，还必须提前知道哪块区域重要。论文指出三个根本原因：注意力里每个 query 要读取所有 token 的键值（K/V），而低分辨率 token 数量少，在 softmax 归一化下无法等价替代多个高分辨率 token，因而影响其他区域；VAE 解码器（把压缩潜变量还原成像素的模块）依赖邻域 patch，直接拼接会在边界留下接缝；其实 DiT 本身就知道主体位置。对应提出双分辨率注意力（每个 query 只读自己分辨率的 K/V，并用线性映射补齐缺失位置）、先融合再解码的混合分辨率解码器、以及从 DiT 早期特征自选高分辨率区域，只处理约 30% 全分辨率 token 即可加速 4.8 倍并接近全分辨率画质。
输入 Input: 文本提示、随机噪声潜变量（图像任务另含文本与图像联合 token），以及 DiT 早期特征用于定位高分辨率区域
输出 Output: 多帧 RGB 视频（或单张图像），由混合高/低分辨率潜变量经统一解码产生
核心机制与技术实现 (Method & Formulation)
  • 证明共享 K/V 下 softmax 无法用单个低分辨率 token 等价替代 $n$ 个高分辨率 token（即使加 logit bias $\beta$，也仅在所有 HR token 相同时成立），改为每个 query 只读自身分辨率的 K/V，并用逐 block 线性映射在 $k_{HR}/v_{HR}$ 与 $k_{LR}/v_{LR}$ 间补全缺失位置。
  • 提出混合分辨率解码器：在 VAE 解码前把 HR 与 LR latent 融合成统一 latent，使每个 patch 邻域一致，消除 resize-and-paste 在分辨率边界产生的接缝与伪影。
  • 用 DiT 早期去噪特征上的线性区域头自选 HR 区域，无需预先给定 gaze/mask；K/V 映射、mixer/upscaler 与区域头分别训练，总体仅处理约 30% 全分辨率 token。
关键评测与消融结论 (Empirical Takeaway)
Wan2.1 14B/720p 上仅用 30% token 实现 $4.8\times$ 去噪加速，MANIQA、Imaging、DOVER 等指标全面优于既有混合分辨率方法，用户研究中对该方法的偏好率超过 90%，接近全分辨率。
