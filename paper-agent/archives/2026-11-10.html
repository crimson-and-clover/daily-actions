💡 评估判定：核心做法是交互式世界模型在每个转移后用自监督下一帧损失在线更新全部参数，并以 MechEval 按机制暴露次数量化学习速度，属于测试期训练的核心算法与评测突破；但它不涉及推理扩展、MCTS 或过程奖励方向，机构为东京大学与初创公司组合，权威度未达顶级工业实验室水平。
白话概述：世界模型本质上是智能体的“想象引擎”：动手之前，先在脑海里预演后果。但进入陌生游戏时，它并不知道这个世界的隐藏规则。本文把规则拆解成一条条“机制”，也就是“某个动作或交互在特定条件下会改变棋盘上哪几个格子”，并把该机制在游戏过程中被实际触发的次数称为一次“暴露”。核心问题是：一条新机制要被观察几次，模型才能预测它的效果？做法是让模型每看完一个“这一步做了什么动作、棋盘随后变成什么样”的样本，就立刻用预测下一帧的误差微调自身全部参数，也就是测试期训练：不是把新规则当作上下文临时记住，而是把这份规律内化进权重，符合“学而不只是记”的直觉。
输入 Input: 连续的 64×64、16 色离散网格帧与对应动作序列（最多 5 个按键或点击某个格子），以流式方式逐帧输入；预训练阶段则使用其他游戏的人类录播转移。
输出 Output: 下一帧网格预测，评测聚焦机制触发后被改色（状态改变）的单元格；在闭环智能体 WARC-Agent 中还用于驱动固定图搜索器进行动作选择与规划。
核心机制与技术实现 (Method & Formulation)
  • 把游戏动力学分解为机制集合 $M_t=\{m:c_m(s_t,a_t)=1\}$，状态转移写作 $s_{t+1}=s_t\oplus\bigcup_{m\in M_t}e_m(s_t,a_t)$，使学习进度可逐机制度量，而不被全帧平均稀释。
  • WARC 用 35M 参数 ViT 从最近 $h$ 帧与动作预测下一帧 $\hat{o}_{t+1}=f_\theta(o_{t-h+1:t},a_{t-h+1:t})$，并在每个转移后在线更新全部参数 $\theta_{t+1}=\theta_t-\eta\nabla_\theta\mathcal{L}(\theta_t;o_{t-h+1:t+1},a_{t-h+1:t})$。
  • MechEval 用暴露计数 $k_m(t)=|\{u<t:m\in M_u\}|$ 对齐不同方法的比较基准，并只在机制真实改色的单元格集合 $C_m(t)$ 上计算 $\mathrm{acc}_m(t)=\frac{1}{|C_m(t)|}\sum_{g\in C_m(t)}\mathbf{1}[\hat{o}_{t+1}(g)=o_{t+1}(g)]$。
关键评测与消融结论 (Empirical Takeaway)
在未见过的新游戏上，WARC 能对五分之四的机制在其改色单元格上达到至少 80% 的预测准确率，约半数机制在单次游玩的约 80 次暴露内达标（不做在线更新时仅七分之一能达标）；闭环 WARC-Agent 把图搜索器的官方效率分从 0.15 提升到 0.46。

💡 评估判定：论文系统研究离散扩散因子生成、引导式测试期束搜索与测试时计算缩放律，属于推理扩展与测试时计算赛道，但不是测试期参数训练；应用限定于半素数分解，故相关性给 8 分而非接近满分。作者全部来自 Google DeepMind，权威度很高，实验覆盖多模型规模、多比特长度和 68 位分解。
白话概述：传统半素数分解依赖数论先验和专门算法，这篇论文只让 Transformer 从大量样本中学会把半素数 $n$ 拆成两个素数因子。它把整数写成二进制串，用离散扩散模型反复“盖住一部分因子位再猜回来”，并在测试时多花算力做带引导的束搜索，同时保留多条候选因子路径；核心直觉是模型只负责当生成先验提出“像因子”的候选，再由精确乘法验证或格基后处理确认。论文还拟合数据量、模型规模、比特长度和测试时计算量之间的经验缩放律，发现固定精度所需算力随比特长度指数增长，因此对现实密码安全没有威胁。
输入 Input: 输入是半素数 $n$ 的定长二进制位串（$2k$ 位，作为未掩码固定前缀）以及待生成因子 $p,q$ 的 $2k$ 位掩码序列；不涉及物理传感器信号。
输出 Output: 输出是 $p,q$ 的 $2k$ 位二进制因子串，或束搜索产生的候选因子集合，可经精确验证或格基后处理得到最终分解结果。
核心机制与技术实现 (Method & Formulation)
  • 将 $n=p\times q$ 编码为长度 $4k$ 的二进制序列：前 $2k$ 位是固定的 $n$，后 $2k$ 位是待生成的 $p,q$；采用连续块掩码而非独立比特掩码，迫使模型学习长程进位与全局乘法约束。
  • 训练离散去噪扩散模型：按 $p(\eta)\propto 2\eta$ 采样噪声水平并用 $w=1/(2\eta)$ 做重要性加权，通过自条件模块 $\mathbf{S}(\boldsymbol{\ell})=\sqrt{d}\,\mathrm{softmax}(\boldsymbol{\ell})\hat{\mathbf{E}}$ 把上一步 logits 的连续不确定性传回去噪器。
  • 推理时用引导式测试期束搜索和祖先采样扩展去噪步数 $T$，在 $T\gg 2k$ 时反复重掩码与重评估候选块；缩放律拟合数据、模型规模、比特长度与测试时计算量对分解成功率的影响。
关键评测与消融结论 (Empirical Takeaway)
在留出半素数上，离散扩散加测试期束搜索将学习型分解前沿从 56 位推进到 68 位，并显示固定精度所需测试时算力随比特长度指数增长。

💡 评估判定：论文直接处理 RLHF/DPO 后训练中的噪声偏好鲁棒优化，提出 token 级重加权并给出梯度偏差上界分析，属于目标轨道核心问题；机构为俄亥俄州立大学，属知名研究型大学但非顶尖工业界或顶尖高校实验室，权威度中等偏上。
白话概述：偏好对齐（比如 DPO）高度依赖人工标注的“哪条回答更好”，但标注常出错，甚至把好坏标反。现有鲁棒方法把整条回答当成一个整体，统一判断对错；可是被拒绝的回答里也可能有正确的推理步骤，被选中的回答里也可能藏着细微错误。PORT 的做法是：给每个 token 分配一个“可信度权重”，也就是按该 token 的对数概率在经验累积分布函数（CDF）中的位置来赋权——概率特别离谱的 token 大概率是噪声污染点，于是压低它的权重。这样做的关键依据是：这种仅需前向计算的加权，等价于一种便宜的“梯度范数惩罚”替代方案，能抑制噪声标签带来的梯度偏差，而且不用额外反向传播、也不用训练奖励模型。
输入 Input: 提示词、成对的偏好/非偏好回答（标签可能被翻转污染）、参考策略与当前策略在每个 token 上的条件对数概率
输出 Output: 优化后的语言模型策略参数，以及训练中每个 token 的鲁棒重加权系数与偏好优化损失梯度
核心机制与技术实现 (Method & Formulation)
  • 把序列级偏好目标拆成各 token 对数比之和，并依据 token 对数概率的经验累积分布函数为每个位置生成权重 $w_t$，从而选择性抑制疑似被噪声污染的 token 对 DPO/IPO 损失的贡献。
  • 理论证明该重加权是梯度范数惩罚的一种高效前向代理，可最小化噪声偏好标签引起的梯度偏差上界，因此无需额外反向传播或外部奖励模型。
  • 在广义偏好优化框架 $\min_\theta \mathbb{E}[f(\beta h(x,y_w,y_l;\theta))]$ 中仅改动每个 token 的损失权重，保持原有训练流程，可直接插入现有 DPO 类后训练管线。
关键评测与消融结论 (Empirical Takeaway)
在 AlpacaFarm 的 0.3 标签翻转噪声下，PORT 在 LLaMA2-7B 上取得 3.82 Gold RM 分数与 67.6% GPT Win Rate，优于最强序列级基线 $\beta$-DPO 的 3.42 与 63.2%，并在多噪声设置与多基准上整体领先。

白话概述：Verilog 生成的一个难点是：仿真只能告诉你整个模块通过还是失败，一个模块里明明有几句写对了，也会因为另一句错而被整体判为失败，训练信号太粗糙。这篇论文做两件事：先把模块拆到每个输出信号上单独看对错，保留部分正确；再用反事实干预判断哪几句代码真正对输出负责，也就是只改这一句、其余全不动、重新编译跑同一个测试平台，看目标信号的错误是否变多，以此判定这句是否真正对输出负责。这样得到的语句级信用再转成每个 token 的权重，做加权 DPO：有证据的片段强更新、没证据的片段弱更新，避免因为一个片段对就把整段错误代码一起强化。
输入 Input: 自然语言硬件规格或 Verilog 代码前缀；训练阶段额外输入候选 RTL 模块、testbench 及仿真得到的信号级错误计数。
输出 Output: 完整 Verilog RTL 模块代码（token 序列），须可编译并通过 testbench 功能验证。
核心机制与技术实现 (Method & Formulation)
  • 以输出信号级错误向量 $e_y(s)$ 替代模块级二元奖励 $R_{\mathrm{mod}}(y)=\mathbb{I}[e_y(s_1)=0 \wedge e_y(s_2)=0]$，保留部分正确 RTL 作为偏好监督。
  • 对输出驱动赋值跨度施加五类局部反事实干预，固定其余模块与 testbench 重编译重仿真，由目标信号误差变化合成连续语句信用。
  • 将语句信用映射为响应 token 权重 $w_t$，在 DPO 目标中对正负样本做严格加权，使不确定证据产生小更新、强支持证据产生大更新。
关键评测与消融结论 (Empirical Takeaway)
在 Qwen2.5-Coder-7B 上，CSCA 将 VerilogEval 2.0 代码补全 T=0.8 的 Pass@1 从 SFT 的 32.7% 提升至 55.1%，领先所比 7B 模型并与 GPT-5.4-mini 可比。

💡 评估判定：论文直接针对后训练偏好优化（DPO 变体）这一目标轨道的核心问题，属于对齐算法的实质改进，且保持离线、能作为标准 DPO 训练器的直接替换改动，相关性较高；但 token 级 DPO 改进已有 TIS-DPO、SePO、T-REG 等工作，本文的“逐 token 风险分解 + 课程调度 + 风险筛选”属于稳健的增量式组合，机制突破有限；作者机构为宾夕法尼亚大学与独立研究者，并非顶尖对齐实验室，且实验文本以设置描述为主、缺少完整量化表格，故权威度与实验分适中。
白话概述：标准 DPO 在训练时只看整条回答的“总分”：把好回答与坏回答的对数概率差放在一起比较，所以它没法指出一条整体还行、只有一两处出错的回答里，究竟是哪几个词让内容变得不安全。TLRS-DPO 把这种序列级的总分拆成逐 token 的贡献，在被拒回答上计算“新模型对这个词给出的概率比原始参考模型高出多少”（即对数概率比，也就是隐式奖励）；差值越大，说明模型在该位置对劣质内容过度自信，于是把它当作一个局部风险分数。随后用课程式调度先轻微、后加重地施加惩罚，并且只惩罚分数超过阈值的高风险 token，而不是对整条回答一刀切。核心直觉相当于老师批改作文时只圈出真正出错的那几个词，而不是把整篇判为不合格，同时全程离线、不引入奖励模型。
输入 Input: 提示词，以及成对偏好数据（被选中回答与被拒绝回答的完整 token 序列）和固定参考模型的逐 token 对数概率；不需要奖励模型，也不需要在线采样。
输出 Output: 更新后的大模型策略参数（逐 token 条件概率分布），以及训练中每个 token 的风险分数与自适应惩罚权重（作为损失项参与反向传播）。
核心机制与技术实现 (Method & Formulation)
  • 把 DPO 隐式奖励按自回归链式分解为逐 token 项 $s_{\theta,t}(x,y)=\log\pi_{\theta}(y_t\mid x,y_{<t})-\log\pi_{\mathrm{ref}}(y_t\mid x,y_{<t})$，在被拒回答 $y^{\ell}$ 上把偏大的 $s_{\theta,t}$ 视为策略相对参考模型过度自信的高风险位置。
  • 据此构造 token 级鲁棒补偿项 $\mathcal{C}_{\mathrm{TLRS}}$，并用课程式调度令惩罚系数 $\lambda$ 由 $0.1$ 线性升至 $0.5$，总损失为 $\mathcal{L}_{\mathrm{TLRS\text{-}DPO}}=\mathcal{L}_{\mathrm{DPO}}+\lambda\,\mathcal{C}_{\mathrm{TLRS}}$。
