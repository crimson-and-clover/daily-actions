Routes of Reasoning: Reading and Reshaping Test-Time Compute in MoE Models

💡 评估判定：论文直接面向测试期计算优化，提出无需训练、基于 MoE 路由行为的测试时干预机制，属于 test-time compute 方向的核心机制创新；但并非 TTT、PRM/MCTS 式推理扩展，且依赖行为标注与逐模型专家筛选，故相关性给高分但非满分；UCLA 团队权威度较强。
白话概述：推理模型常会“想太多”：答案已经算对，却仍反复检查、重新推导，浪费测试期算力，甚至把结果改坏。作者发现，在 MoE（混合专家）模型里，路由器像分诊台，负责把每个 token 分给不同“专科专家”；而路由器选了哪些专家，能相当准确地暴露模型此刻是在规划、推导、复述、回忆事实、反思还是下结论。于是他们在推理时直接调高或调低对应专家的路由分数，让模型在结论专家占上风时及时收尾。核心直觉是：不用重新训练模型，也不用等长思维链生成完再压缩，而是在路由层实时识别并抑制无用的反思与重复验证。
输入 Input: 文本问题提示（数学、代码、科学、知识、常识等），以及推理过程中每个 token 在各 MoE 层的路由器 logits、Top-K 专家选择与门控权重；探针训练阶段还需句级推理行为标签。
输出 Output: 经推理时路由编辑后的推理文本与最终答案，以及显著缩短的生成 token 数；模型参数不更新。
核心机制与技术实现 (Method & Formulation)
  • 将推理轨迹切分为句或子句级片段，标注六类行为 $y_m\in\{\text{planning},\text{execution},\text{restatement},\text{fact},\text{reflection},\text{conclusion}\}$，再把片段标签对齐到 token 形成行为读出监督信号。
  • 用线性探针读取 MoE 路由器 logits $z_t^{(\ell)}=W_r^{(\ell)}h_t^{(\ell)}$ 预测当前 token 的推理行为；单层路由状态已可解码，拼接 $L8$ 至 $L16$ 九层路由 logits 可接近残差流探针。
  • 推理时对选定专家集合修改 log-softmax 路由分数 $s_{t,e}^{(\ell)}=\log\operatorname{softmax}(z_t^{(\ell)})$，对激活集置为 $s_{t,\max}^{(\ell)}+\epsilon$、对失活集置为 $s_{t,\min}^{(\ell)}-\epsilon$，再重算 softmax、Top-K 与门控，在不更新参数下抑制过度反思与验证。
关键评测与消融结论 (Empirical Takeaway)
在四个 MoE 推理模型和四个基准上，行为定向路由编辑中位减少 30.4% 生成 token（最高 63.3%），准确率下降不超过 0.5 个百分点且常提升，说明路由编辑能有效削减过度思考。

💡 评估判定：论文属于机械可解释性与安全监控的核心议题，实证揭示 persona 会系统性重组潜空间语义几何，使线性探针与 SAE 分类器跨人格失效；但它未提出新的后训练（RLHF/DPO）算法或新的 SAE/回路发现方法，故相关性高而不到满分。
白话概述：线性探针和稀疏自编码器（SAE）在监控大模型时都默认一个前提：同一个特征在不同语境下保持同一种表征。本文指出这个前提并不成立。线性探针本质上是在模型的潜空间里给每个概念划出一条分类边界；SAE 则把激活拆解成一组稀疏的“概念开关”，并假定每个开关的含义固定。作者用一句系统提示让模型“扮演自由派”或“扮演保守派”，然后提取九千多个常用词和33条语义轴的内部向量，发现这些语义轴之间的夹角和词在轴上的位置会被成体系地“转动”：在人格条件下，原本中性的词义坐标系发生了重组。关键直觉是：人格或视角并不只是表面上的措辞风格，它会重新排列模型内部的概念几何；因此，用中性数据训练出的真理性、道德性监控器一旦遇到带人格的模型，就会给出带有政治倾向的评分。
输入 Input: 系统提示词（自由派民主党人、保守派共和党人、空提示、有帮助的AI助手四种人格条件），再加上包含目标词的文本模板。对 Llama 3.1 8B 等指令微调模型执行前向传播，读取最后一个 token 处的残差流激活。
输出 Output: 各层词表征向量、33 条语义轴向量，以及轴间余弦相似度和词在轴上的归一化投影；此外还包括线性探针、SAE 分类器和人工选词分类器输出的真理性与道德性评分。
核心机制与技术实现 (Method & Formulation)
  • 用四种系统提示词诱导人格，每个词填入 5 个模板，取最终 token 的残差流激活求平均得到 $\mathbf{h}_{c}^{(\ell)}(w)$；主分析用 Llama 3.1 8B 第 24 层，并在 8 个 4B–70B 指令微调模型上复现。
  • 33 条语义轴由 10 组对比锚点对平均构造：$\mathbf{a}_{f,c}^{(\ell)}=\frac{1}{10}\sum_{j=1}^{10}\left(\mathbf{h}_{c}^{(\ell)}(\text{pos}_{f,j})-\mathbf{h}_{c}^{(\ell)}(\text{neg}_{f,j})\right)$，以 $\cos(\mathbf{a}_{f,c},\mathbf{a}_{g,c})$ 度量轴间对齐、以 $\cos(\mathbf{h}_{c}(w),\mathbf{a}_{f,c})$ 度量词在轴上的投影。
  • 把人格条件下的轴相似度差矩阵与党派语料训练的 word2vec 差矩阵做相关，并用无 persona 训练的三类分类器检验真理性与道德性评分是否出现政治倾斜。
关键评测与消融结论 (Empirical Takeaway)
在 Llama 3.1 8B 第 24 层，空系统提示下 liberal–conservative 轴与 good–bad 轴投影几乎无关（$r=.02$），自由派人格下升至 $r=.75$、保守派下反转为 $r=-.79$，说明人格会系统性重组语义几何，并据此扭曲安全分类器输出。

💡 评估判定：论文将DPO偏好优化与安全关键神经元逐步移除结合，属于后训练对齐与机械可解释性交叉的实用算法改进，但未提出全新的RLHF/DPO方法或可解释性工具；机构为杜伊斯堡-埃森大学，安全领域有一定声誉但非顶级；实验覆盖四个模型、多类攻击和消融，较扎实。
白话概述：大模型的安全对齐往往很“脆”：只靠少数几个“安全关键神经元”或隐空间里的一个“拒绝方向”撑着，一旦把这些小部件剪掉或屏蔽，模型就容易输出有害内容。本文提出“减法即加法”（ABS-Align）：在微调时主动逐步删掉这些安全关键神经元，同时用DPO偏好优化让模型的其他部分重新学会拒绝有害请求，使安全行为不再依赖稀疏组件，从而对剪枝和越狱攻击更稳。通俗说，“安全关键神经元”就是MLP里对拒绝有害请求起决定作用的小开关；“拒绝方向”是模型内部一个方向，往那拨就倾向拒绝；“DPO”则是用成对的好回答/坏回答直接调整模型偏好，不需要单独奖励模型。
输入 Input: 用户输入的文本提示（prompt），即一段自然语言指令或问题。
输出 Output: 模型逐token自回归生成的文本回复，即对用户提示的安全对齐响应（拒绝有害请求或给出合规回答）。
核心机制与技术实现 (Method & Formulation)
  • 先用TwinBreak、NeuroStrike等方法定位MLP门控/上投影层中对安全行为关键的神经元，在微调中按计划逐步将这些神经元权重置零或掩码，主动模拟并超越剪枝攻击。
  • 在移除安全关键神经元的同时，用DPO损失 $\mathcal{L}_{\text{DPO}}$ 在偏好对 $(x,y_c,y_r)$ 上优化，迫使拒绝行为从被删神经元迁移到模型其余参数。
  • 训练数据混合PKU-SafeRLHF安全偏好样本、Alpaca通用指令样本和XSTest安全样本，以平衡安全鲁棒性、通用能力与过度拒绝。
关键评测与消融结论 (Empirical Takeaway)
在Llama-3-8B、Llama-3.2-3B、Gemma-2-2B和Qwen-3-4B四个模型上，ABS-Align将部分攻击成功率降低最多90%，并泛化到拒绝方向消融和黑盒越狱攻击，同时TruthfulQA真实性提升且MMLU等通用基准基本保持。

💡 评估判定：论文聚焦后训练强化学习中的多奖励校准与奖励黑客问题，提出不更新奖励模型的自进化记忆校准机制，与GRPO后训练核心问题直接相关；但不涉及机械可解释性、SAE或回路分析，也非典型RLHF/DPO偏好优化，故相关性未给满分。机构为HKUST与腾讯混元，实验覆盖多种RL算法与跨模型迁移，权威度与扎实度较高，但主指标部分依赖VideoAlign，情绪评估主观性仍存。
白话概述：这篇论文要解决的是视频生成强化学习里的奖励难题：情绪表达好不好没法用对错判定，而固定权重地把面部、动作、画质几路评分加起来，策略很容易钻空子（即奖励黑客，只把评分刷高而不真正表达情绪）。它把情绪提示先拆成可观测的评估线索，如面部动作强度、身体姿态、表情出现的时间窗，再让多路评分器各自打分并标出证据是否可信；然后根据当前视频里证据是否可见、是否互相冲突做实例级门控，再查询一张从上一轮完整训练中统计出的可靠性记忆表，决定每一路该信多少，融合成校准后的情绪奖励。核心直觉是：先核实证据是否在场、是否可信，再分配信任权重，而且奖励模型全程冻结不更新，从而在GRPO后训练中提供更抗钻空子的奖励信号。
输入 Input: 情绪文本提示；候选视频的RGB帧序列，用于提取面部动作单元、身体动作、时序变化与VLM判断等证据；以及由已完成参考训练运行统计得到的RewardMemory可靠性表。
输出 Output: 每段候选视频的校准后情绪标量奖励，与通用视频奖励按权重融合成总奖励，供GRPO计算组内优势；最终产物为策略生成的视频。
核心机制与技术实现 (Method & Formulation)
  • Plan-Act-Reflect-Evolve流水线先由Plan把提示转为EmoScript $e(p)=(v^{\star},a^{\star},\mathbf{q}^{\star}_{\mathrm{AU}},\mathbf{b}^{\star},\Omega)$，Act由七类评分器输出分数与有效位 $(s_k,u_k)$，Reflect结合实例门控 $g_k$ 与记忆乘子 $m_k(r)$ 在有效集上重归一化得到 $R_{\mathrm{emo}}$。
  • 针对静态融合 $R_{\mathrm{emo}}^{\mathrm{static}}=\sum_k w_k^0 s_k$ 无法适应面部可见性与运动相关性随场景变化的问题，用有效性掩码与门控剔除缺失或冲突证据，并以 $R_{\mathrm{total}}=(\alpha R_{\mathrm{vid}}+\beta R_{\mathrm{emo}})/(\alpha+\beta)$ 与原视频奖励混合。
  • RewardMemory从完成参考运行的rollout分数与结果中估计各评分器在情绪上下文签名 $z$ 下的可靠性，Evolve导出有界乘子 $m_k(r)$ 供下一轮训练冻结使用，避免在线更新奖励模型带来的奖励黑客风险。
关键评测与消融结论 (Empirical Takeaway)
在HunyuanVideo 1.5上，SAGE-GRPO加EmoReward将VideoAlign Overall从-0.8269提升至-0.2624（提升0.5645），FlowGRPO提升0.2343，DanceGRPO配置提升0.3218，且SD 3.5与FLUX迁移实验支持该自进化奖励校准的有效性。

💡 评估判定：论文直接针对少步流匹配和扩散模型的蒸馏核心机制，提出速度场对抗蒸馏并统一多种分布匹配目标，在文本到图像和33B文本到视频上验证，属于目标赛道核心突破；机构为港科大(广州)与Sea AI Lab，权威度高但非最顶级工业实验室，故权威分略低。
白话概述：扩散或流模型生成一张图要采样几十步，太慢；想压缩到四步，但中间每一步学生模型输出的分布都难以准确估计，导致画质塌陷。作者换个角度看问题：不强行估计学生的分数（score，即去噪方向），而是让学生和教师各自给出速度场（velocity field，直观理解就是每一步“从噪声往数据走”的箭头方向），再让一个可学习的裁判（critic）比较这两组箭头，箭头不一致的地方就当作训练信号反馈回去。这样把原先零散的多种蒸馏目标统一进同一个对抗框架，并进一步沿学生的四步轨迹对每一次中间转移做监督，也就是不要求一步生成干净图，只要求把当前含噪状态降到下一个更干净的含噪状态，结果在四步文生图与大模型文生视频上都超过现有少步方法。
输入 Input: 文本提示条件、高斯噪声初始样本，以及少步采样轨迹中当前含噪状态与对应时间步
输出 Output: 四步采样生成的图像或视频；每步输出的去噪转移结果与速度场
核心机制与技术实现 (Method & Formulation)
  • 把学生从 $\mathbf{x}_t$ 到 $\mathbf{x}_s$ 的单步转移参数化为干净锚点与残差速度 $\hat{\mathbf{x}}_0=\mathbf{x}_t-t\,v_\theta(\mathbf{x}_t,t)$，并在扰动时刻 $\tau>s$ 用教师分数监督学生路径分布。
  • 用可学习 critic 比较学生速度场 $v_\theta$ 与教师速度场 $\mathbf{u}_t(\mathbf{x}_t,\mathbf{c})$，把二者的分歧转为对抗训练反馈，统一了 score distillation、Fisher-based matching 与 moment matching。
  • VA-TDM 沿 $K$ 步学生轨迹对每个中间转移做部分去噪监督，结合 transition-aware 在线速度学习与 dual-form VAD 监督，使各中间状态都贴近教师边际分布。
关键评测与消融结论 (Empirical Takeaway)
四步 SD3.5-Medium 上 GenEval 由最强基线 TDM 的 0.61 升至 0.67、HPSv3 由 11.54 升至 11.89；FLUX.2 4B 上 GenEval 达 0.80、OCR 达 0.69，并在 33B MiniMax-H3 上人类偏好显著优于 Fast-H3。

💡 评估判定：直击循环 Transformer 的缓存随循环膨胀、深度无法按部署预算伸缩这一长上下文架构痛点，publish-once 与多预算随机深度训练属于机制层面的实质突破；但模型仅 204M、缺少数学与代码推理评测，且循环训练算力开销为单次基线的 2.9-4.7 倍。
白话概述：循环 Transformer 的想法是把同一批层反复跑几遍，用重复计算来“加深”网络，但代价很实在：每多循环一次，缓存里就多存一份键值对（KV cache，即模型为已读过的每个 token 存下的“记忆条目”，避免重复计算），显存随循环次数线性膨胀；而且循环只能整块加减，训练完再想改循环次数几乎要重训。LooM 的做法是把“写记忆”和“读记忆”拆开：编码器和解码器第一层为每个 token 只写一次全局记忆，之后被循环的解码器层只读不写；某个 token 的局部键值对也只在该层第一次访问它时“发布”一次（publish-once），后面再访问只更新当前 token 的隐状态、不新增缓存。于是缓存大小与循环路径彻底解耦，同一份缓存在 3 到 21 次层执行的算力预算下都通用；再配合“随机深度”训练（每个样本随机抽一个预算和一条层深路径），一个模型即可覆盖全部预算，部署时按算力选深度，无需额外路由器。
输入 Input: 文本 token 序列（提示词与已生成历史），编码器及解码器第一层据此构建全局 KV 记忆，各解码器层维护宽度为 128 的局部滑动窗口历史。
输出 Output: 下一 token 的概率分布与自回归生成的文本；推理期维护布局固定的全局 KV bank 与各层局部 KV cache。
核心机制与技术实现 (Method & Formulation)
  • 编码器与解码器第一层为每个 token 一次性写入全局 KV bank，解码器第 2 至第 6 层作为纯读取层独立循环，反复读取同一份 $M_{\leq t}$ 与本地历史 $H_{\leq t,\ell}$，只更新当前 token 的隐状态 $s_{\ell}^{(r)}$。
  • publish-once 规则：某层对 token $t$ 仅在首次访问时发布其局部 KV 条目，后续访问重算 query 改变注意力分布但不写缓存；因此缓存量为 $\sum_j n_j(T)\,k_j+\sum_{\ell=1}^{12}\min(T,W)\,k^{\mathrm{loc}}_{\ell}$，与循环路径和预算无关。
  • Random-Depth 训练：先采样预算 $B\sim\pi$，再从满足 $C(d)=B$ 的合法路径中均匀采样各层深度 $d$，展开到最大采样深度并屏蔽未执行的重复，从而在不训练路由器的情况下让单一模型覆盖 3 至 21 次层执行。
