💡 评估判定：该论文直接面向测试期计算分配这一核心问题，提出免训练的固定点检测与 replay 解码，属于推理扩展/测试期计算赛道的机制创新；但机构为俄克拉荷马大学与斯坦福大学混合署名、非顶尖实验室主导，权威度略降，实验覆盖较扎实。
白话概述：这篇论文要解决测试期推理扩展中的关键取舍：面对一个已生成的解，是继续修改它，还是放弃并重新采样。所谓固定点，就是让修订算子再运行一次，输出仍与当前解完全相同，相当于“改不动了”；replay decoding 先以当前解为草稿，一次并行核对多个未变的 token，从而用很低的串行开销判断是否到达固定点。核心思路是：一旦继续修订的收益耗尽，就把算力从继续修订切换到独立采样，避免在无望的解上继续消耗预算。
输入 Input: 自然语言问题（数学或逻辑推理题）、当前候选解的 token 序列、冻结语言模型，以及每题测试期 FLOPs 预算 $B$；不涉及物理传感器信号。
输出 Output: 最终答案（对完整根解做多数投票）、测试期计算分配策略（继续修订或新采样），以及修订解或新独立样本序列。
核心机制与技术实现 (Method & Formulation)
  • 将修订定义为平稳算子 $F_x(y)=G_\theta(\rho(x,y))$，检测 $F_x(y)=y$ 是否成立；一旦到达固定点，就停止该根的修订，并把预算转给新的独立采样。
  • Replay decoding 把当前解当作 draft，以块大小 $W$ 一次并行验证至多 $W-1$ 个 draft token，接受最长一致前缀；首个不一致后切回标准贪心解码，保证输出与原修订算子精确等价。
  • 分配策略在活跃根宽度 $N$、总预算 $B$ 和块大小 $W$ 下维护多个根，修订耗尽后替换为新根，最终对每个根的最后完整解做多数投票，无需训练控制器或依赖可能错误的自验证信号。
关键评测与消融结论 (Empirical Takeaway)
在 MATH500 上以仅 41% 的串行 pass 达到 84.6% 准确率，并在等算力下于 5 个数学推理基准中的 3 个匹配多数投票，关键路径串行 pass 最多减少 2.4 倍。

💡 评估判定：论文直接改进推理期搜索的重采样算子，属于推理扩展与测试期计算的核心算法层面工作，与目标赛道高度相关；但对象是扩散 LLM 解码而非测试期训练本身，且为 USC 中坚机构的扎实工作而非顶级实验室，故权威度与综合分适中。
白话概述：扩散语言模型（diffusion LLM）生成答案时不是从左到右逐词写，而是先给出整条全掩码序列，再分块把掩码位置逐步填成词元。本文在推理阶段并行维护多条半成品答案（称为粒子），给每条答案按奖励打分（奖励可以是模型自身置信度，也可以是外部过程奖励模型对已写前缀的评分），再用序列蒙特卡洛（SMC，一种按权重复制或淘汰候选、从而把算力集中到高分路径的搜索方法）来搜索更可能正确的推理路径，全程无需重新训练模型。核心痛点是：传统多项式重采样会把高分候选复制多份、同时彻底消灭早期得分低但后面仍可能走通的候选谱系，导致搜索过早收敛、多样性塌缩；而通常用来监控权重退化的有效样本量（ESS，衡量权重是否集中在少数粒子上）在重采样后会被重置为最大值，完全看不出谱系已经消失。本文提出保留谱系的 SMC（LP-SMC）：Chopthin 重采样只约束最大与最小权重的比值而不把权重全部拉平，再给权重设一个下限，让早期低分候选保留翻盘机会，从而在推理扩展中兼顾利用与探索。
输入 Input: 文本提示（prompt），以及扩散语言模型在每步对部分掩码序列输出的词元预测分布与置信度；外部引导模式下还输入过程奖励模型对当前已提交前缀的逐步打分
输出 Output: 最终解码出的完整答案词元序列（从多条候选中按选择规则选出一条作为回答）
核心机制与技术实现 (Method & Formulation)
  • 把扩散 LLM 解码写成粒子滤波：粒子权重按增量势连乘累积 $U_{t-1}=U_t\,G_{t-1}(x_t,x_{t-1})$，势 $G_{t-1}$ 可取解码器置信度或外部过程奖励模型分数，并在 $\mathrm{ESS}<N/2$ 时于块边界触发重采样。
  • 用 Chopthin 重采样替代多项式重采样，使返回权重的最大与最小比值不超过 $\eta$，且不强制等权，从而保留多条谱系而非复制高权重粒子。
  • 叠加输入权重下限 $\kappa=\ln N$，使早期低权重但仍有潜力的谱系在重采样后保有最低权重，维持探索并给出对目标测度扰动的界。
关键评测与消融结论 (Empirical Takeaway)
在 LLaDA-1.5 与 Dream-7B 上，LP-SMC 在全部 12 个设置的 oracle coverage 上提升 1.8 至 25.6 点，端到端准确率在 12 个设置中 11 个提升（LLaDA-1.5 最高 +7.9，Dream-7B 最高 +18.3）。

💡 评估判定：论文核心是循环固定点模型的测试时自适应计算分配与停机机制，直接落在推理扩展赛道上，并给出球面几何重构与收敛性证明；但它不属于测试期参数更新的 TTT，也未涉及 CoT/过程奖励/MCTS 推理，所以相关性没有给到满分。作者为 EPFL Cevher Lab 等，理论与实验较为扎实。
白话概述：循环权重共享 Transformer 可以“难题多想几轮、简单题少想几轮”，但已有的固定点推理器在无界欧氏空间里迭代，状态范数会无限膨胀，只能靠互相耦合的缩放系数来维持稳定，停机判断也要依赖相对范数，阈值很难设。这篇论文把循环状态强制限制在单位超球面上：所谓固定点推理，就是同一个网络反复迭代直到状态不再变化；球面插值（slerp）则是沿着球面最短的大圆弧走一段，保证每一步都落在球上；角度残差指的是看当前状态和候选状态相差多少度来决定何时停机。这样一来，状态有界由结构保证，系数之间不再耦合，收敛可以证明，而且每个样本停机的迭代次数直接等于它消耗的测试时计算量。
输入 Input: 离散推理任务的 token 或网格序列，即 Sudoku 数独盘面、Maze 迷宫栅格、ARC/Mini-ARC 彩色网格经嵌入后得到的 token 序列。
输出 Output: 任务答案，即补全的数独网格、迷宫解路径或 ARC 输出网格；同时输出每个样本自适应停机时的循环迭代次数，即消耗的测试时计算量。
核心机制与技术实现 (Method & Formulation)
  • 循环状态由权重共享的 nGPT 块约束在单位超球面上，子层做归一化回缩 $\mathbf{z}\leftarrow\mathrm{Norm}(\mathbf{z}+\alpha_A\odot(\mathrm{Norm}(\mathrm{Attn}(\mathbf{z}))-\mathbf{z}))$，因此有界性由结构本身保证，欧氏版本所需的四个系数耦合式被彻底去除。
  • 输入注入与阻尼改为球面测地操作：注入执行 $\mathrm{Slerp}_{\lambda}(\mathbf{z}_i^{2D},\mathbf{x})$ 沿大圆弧向输入移动，阻尼执行 $\mathrm{Slerp}_{\eta_i}(\mathbf{z}_i,\tilde{\mathbf{z}}_i)$ 向候选状态旋转，停机则改用角度残差 $r_{c,i}=\max_t\arccos(\langle \mathbf{z}_{i,t},\tilde{\mathbf{z}}_{i,t}\rangle)<\tau_c$。
  • 论文证明固定点 $\mathbf{z}^\star=F_\theta(\mathbf{z}^\star;\mathbf{x})$ 存在、在显式步长条件下局部收敛，并在强注入下全局收敛；训练采用窗口截断 BPTT、深监督与窗口间状态截断。
关键评测与消融结论 (Empirical Takeaway)
SFPRM 在 Sudoku-Extreme、Maze-Hard、Mini-ARC 上分别取得 96.6%、87.9%、59.1% 准确率，超过 FPRM 与其他循环推理基线，并且按角度判据更有效地分配测试时计算。

白话概述：这篇论文追问大模型的“品牌品味”是在哪一步被训练出来的：模型被问“说出一个跑鞋品牌”时常答 Nike，被问“推荐一个跑鞋品牌”时却常答 Brooks。作者把提问分成 Name（命名）、Choose（选择）、Recommend（推荐）和两轮 Pick（先推荐、再问会选哪个），在 102 个模型、42 个品牌类别上统计答案漂移，并借助公开的开放训练流程（base→SFT→DPO→RL）逐阶段定位。通俗地说，预训练像在记“谁有名”，SFT 像教模型“按要求答题”，而 DPO 这类偏好优化是在教模型“哪个回答更好”；后者会整体改变模型的判断口味。即使偏好训练数据里几乎没有出现品牌名，模型的推荐仍会从大众品牌转向小众、专业品牌，作者推测这种口味来自训练时充当裁判、判断哪个回答更好的 judge models。核心直觉是：推荐并不只取决于模型知道多少品牌事实，更取决于它学到的那套“什么算更好的回答”的偏好结构。
输入 Input: 纯文本品牌询问提示，包括 Name、Choose、Recommend 以及两轮 Pick；同时输入不同训练阶段的模型检查点。不涉及物理传感器信号
输出 Output: 模型生成的品牌名称、两轮对话中的最终品牌选择，以及各模型和各训练阶段在 42 类品牌上的品牌分布、共识品牌与一致性比例
核心机制与技术实现 (Method & Formulation)
  • 构建 42 类品牌库，每类用 Name、Choose、Recommend 与两轮 Pick 提问，在 temperature 1 下对 102 个模型多次采样，并用别名归并比较领域共识品牌与模型自身 Named 品牌的保持率。
  • 利用 OLMo 3 7B、OLMo 3.1 32B、Tulu 3 8B 的 base/SFT/DPO/RL 检查点逐阶段比较，检验偏好数据 $\mathcal{D}_{\text{pref}}$ 几乎不含品牌时，偏好优化目标 $\mathcal{L}_{\text{DPO}}$ 是否仍使推荐分布移动。
  • 分析两轮推荐列表，检验模型是否把自身 Named 品牌从首位降级而非直接拒绝，并用 split-half 一致性、关闭推理、搜索可用性等对照排除简单记忆或随机抽取解释。
关键评测与消融结论 (Empirical Takeaway)
在 102 个模型、42 个品牌类别上，Picked 与 Named 品牌在 26/42 类中不同；三条开放训练流程中 DPO 阶段使 pick 移动 11 到 24 个百分点，而偏好数据几乎不含品牌。

白话概述：标准DPO默认训练时的偏好数据与上线后的偏好分布一致，但真实部署中用户群体、提问方式、偏好标准都会变，训练集上好用的对齐模型可能在新环境翻车。这篇论文把这种偏移拆成三层：群体比例变化、提示词写法变化、偏好标准变化，然后用分布鲁棒优化应对，也就是不赌某一种分布，而是假设最坏情况下分布会在一个小范围内波动，并优化这个最坏情况。作者用Wasserstein距离给每一层画出一个波动范围，即模糊集，最终推导出一个能直接训练的损失：既惩罚偏好边际不够大，又给提示嵌入加对抗扰动，还按最坏情况的群体权重重新加权。
输入 Input: 提示词、成对候选回复及二值偏好标签，附带样本所属群体索引；训练中还使用参考策略与回复的提示嵌入。
输出 Output: 经三级分布鲁棒偏好优化后的语言模型策略参数，以及在分布偏移下更稳健的偏好排序与偏好边际。
核心机制与技术实现 (Method & Formulation)
  • 将偏好数据分解为 $P_g(U)=P_g^X(X)P_g^V(V\mid X)P_g^S(S\mid V,X)$，在群体权重、提示边际与条件偏好三层构建分层矩形模糊集，并用Wasserstein距离分别控制各层半径。
  • 推导出可计算目标，包含偏好级闭式margin惩罚、提示嵌入对抗扰动 $\tilde{h}=h+\delta$ 与最坏情况群体重加权 $\sup_{\omega}\sum_g \omega_g \mathbb{E}_{P_g}[\mathcal{L}]$。
  • 给出有限样本收敛保证，并用TPO(Group)、TPO(Prompt)、TPO(Preference)单层变体做消融，验证三级鲁棒项的独立贡献。
关键评测与消融结论 (Empirical Takeaway)
在情感偏好OOD、偏好投毒与Open LLM Leaderboard v2上，TPO相比DPO及GRPO、Dr.DPO、WDPO等鲁棒基线提升了平均与最差群体偏好准确率，且三级组合优于任一单层变体。

白话概述：大模型做长上下文推理时，每生成一个词都要回看全部历史 Key-Value 缓存（KV cache，即把过去每个 token 的键和值存下来反复复用），上下文越长越慢，于是出现了“稀疏注意力”：只挑一小部分 token 计算。但极端稀疏时两条路都不好走——按注意力分数做确定性 top-k 检索（只保留打分最高的那批 token）会整体丢掉排在后面的注意力质量，纯随机采样覆盖面更广却方差大、噪声多。SSA 的做法是把两者拼起来：高分 token 照旧精确算，剩下的预算用“代理分数”（一个便宜的近似打分器估出的重要性）做有偏采样去补漏，再按逆概率加权（每个被抽中的 token 除以它被抽中的概率，把采样偏差折算回去）无偏地还原完整注意力输出，等于用同样的计算预算换到更接近稠密注意力的结果，并配了优化 CUDA 内核把精度收益变成真实提速。
输入 Input: 当前查询向量、随生成长度增长的 KV cache（键值缓存）、代理打分器给出的 token 重要性估计，以及设定的稀疏预算
输出 Output: 稀疏注意力层的输出向量（供后续层与词表投影使用），并伴随更低的解码时延
核心机制与技术实现 (Method & Formulation)
  • 把 token 划分为重集 $\mathcal{H}$（确定性 top-$k$）与残差采样集 $\mathcal{S}$，重集内精确计算 $\mathbf{o}_{\mathcal{H}}=\frac{\sum_{i\in\mathcal{H}}w_i\mathbf{v}_i}{\sum_{j\in\mathcal{H}}w_j}$，其中 $w_i=\exp(s_i)$、$s_i=\mathbf{q}^{\top}\mathbf{k}_i/\sqrt{d}$。
  • 残差部分用代理分数构造提议分布并按包含概率 $\pi_i$ 抽取，再用逆概率加权估计 $\hat{\mathbf{o}}=\frac{\sum_{i\in\mathcal{S}}(w_i/\pi_i)\mathbf{v}_i}{\sum_{i\in\mathcal{S}}w_i/\pi_i}$，补回被 top-$k$ 丢弃的注意力质量。
  • 该框架将 top-$k$、top-$p$ 与 top-$k$ 加均匀采样等策略统一为特例，并配合优化 CUDA kernel 降低长上下文解码开销。
