Verification Trap: Understanding Test-Time Selection Failures under False Premises in Code Generation

💡 评估判定：论文聚焦测试期计算中验证器选择的可靠性，属 test-time compute / inference scaling 的机理诊断，提出并量化了错误前提下生成器与验证器耦合导致的失效，与目标轨道高度相关；但偏诊断分析而非全新算法突破，机构为中科大/新国大/南洋理工等知名研究型院校，权威度中上。
白话概述：现在提升代码生成质量常用一招「测试期计算」：让模型一次写出很多份候选代码，再用一个「验证器」比较这些候选，挑出最可能正确的那份交卷。这套做法默认验证器能独立纠错。作者发现一个被忽视的坑：如果题目描述里被塞进一句误导性前提（比如「这个函数必须用递归实现」这种错误约束），生成器会顺着错误前提写出看似合理、实则错误（过不了隐藏测试）的捷径代码，而验证器自己写的测试也继承了同一个错误盲点，于是验证器反而会给这些错代码打高分。结果就是候选池里明明有正确程序，选择器却挑错了。作者把这种「生成器和验证器因共享同一错误信念而被耦合、导致误选」的现象命名为 Verification Trap（验证陷阱）。关键点在于：证据不再「解耦」——验证器提供的证据跟生成器的错误绑定在一起，越筛选越偏。
输入 Input: 自然语言编程题目描述（可被植入误导性前提），以及生成器据此采样出的 N 个候选程序；验证器使用同一提示条件生成的可见测试或自写测试。
输出 Output: 测试期选择器最终返回的程序（被选中的候选代码），以及一个无需隐藏测试的金标准无关预测器对「是否发生验证陷阱」给出的预测概率。
核心机制与技术实现 (Method & Formulation)
  • 构造匹配的三类提示条件（原始基线、无关对照、虚假前提），仅改动自然语言描述而固定函数签名与隐藏测试，使性能变化可严格归因于前提干预而非任务语义。
  • 提出 $\mathrm{Trap}@N$ 指标：当 $N$ 个候选池中至少有一个隐藏测试正确的程序、而选择器却返回隐藏测试错误的程序时记为 trapped，并用虚假前提减基线的 $\Delta_{\mathrm{trap}}$ 量化可恢复误选的放大。
  • 机制层面发现验证器自写测试继承前提级盲点并重塑验证器可见候选空间，进而提出仅用验证器可见特征的轻量金标准无关预测器，在隐藏执行前以 0.846 AUROC 预测验证陷阱。
关键评测与消融结论 (Empirical Takeaway)
在 HumanEval+、MBPP、LiveCodeBench 三个基准与五种代码模型上，虚假前提一致拉低 Selected@64（如 Qwen-14B 由 85.23 降至 75.17）并放大 Trap@64 可恢复误选，表明验证器与生成器共享错误前提是测试期选择失败的关键放大器。

💡 评估判定：论文属于测试期技能自进化与测试期算力扩展方向（无参数更新、依赖验证器反馈与多次采样），与目标赛道相关，但落在文本/提示层面的自适应而非参数更新的核心 TTT 机理突破；北京大学具权威性，然而实验使用 GPT-5.5、DeepSeek-V4、USAMO 2026 等未来化设定，且关键消融明确标注为“规划场景、非实测结果”，削弱了可信度与实验扎实度。
白话概述：这篇论文解决的问题是：不动大模型一个参数，让 Lean 形式化定理证明器通过“技能进化”越用越强。以往的方法靠对比成功与失败的证明轨迹来改进策略，可一旦某个难题下所有采样轨迹全挂，就没有成功样本可参照，更新方向无从下手；而且它们只盯着根指令文件，忽略了数学概念等参考知识。作者把技能拆成根策略、参考知识、示例三块，正常情况下用成功/失败轨迹做渐进式局部修订；一旦全军覆没，就触发“变异”——围绕数学概念采样并生出新的技能候选，再用 Lean 验证器当裁判筛选保留。这里的关键名词“变异”不是生物学含义，而是在文本技能空间里做概念引导的随机扰动，用以从无解局面硬闯出新思路；“渐进进化”则是稳扎稳打的局部微调，两者互补。
输入 Input: Lean 定理的形式化陈述、当前证明状态与 Lean 语言服务器返回的编译器反馈；以及此前积累的成功/失败证明轨迹与当前技能文档。
输出 Output: 可提交的证明动作序列（Lean 证明脚本/策略），以及迭代更新后的技能文档（含根求解策略、参考知识条目与示例）。
核心机制与技术实现 (Method & Formulation)
  • 技能形式化为 $sk=(\mathcal{M},\mathcal{R},\mathcal{E})$，即根策略、参考知识与示例三部分，并抽取为可定位编辑的位置树 $\mathcal{P}_S=\operatorname{ExtractPositionTree}(S)$，使更新只改相关节点而非整篇重写。
  • 渐进式进化对同一问题对比成功与失败轨迹集 $\mathcal{T}_i^{+}$ 与 $\mathcal{T}_i^{-}$，经 LLMCompare/LLMLocate/LLMSuggest/LLMRewrite 生成局部更新 $\delta S_i=(P_i,A_i)$ 并跨问题合并。
  • 当所有轨迹均失败时触发概念引导变异：采样数学概念生成 20 个技能候选，用 Lean 验证器反馈筛选并保留有效更新，以跳出技能空间的局部困境。
关键评测与消融结论 (Empirical Takeaway)
在相同主干模型、采样预算与测试期算力下，本方法在 MiniF2F 与 PutnamBench 上较最强基线提升约 5.3 至 18.3 个百分点，且概念引导变异比随机文本变异再高 6.9 与 8.2 个百分点。

PreCoG: Preview-Edit for Efficient Video Correction in Generation-Time

💡 评估判定：论文聚焦文生视频生成时的迭代纠错，核心机制为预览诊断加缓存轨迹编辑，属于视频生成基础模型的效率与对齐改进，与目标赛道强相关，但偏纠错框架而非 flow matching/rectified flow 的底层生成机理突破；机构为香港大学 NICE Lab，属强研究团队，实验覆盖 VBench/T2V-CompBench/VS2 及人工评估。
白话概述：现有迭代式文生视频纠错，每改一次错就得完整重跑一遍生成，既费算力又容易把本来正确的画面改坏。PreCoG 的思路是"先低价预览、再定点改轨迹"：先用很短的步数（只跑前14步）生成一个廉价预览来诊断哪些提示词要求没实现（PreQA），然后直接对缓存下来的去噪轨迹做编辑（PreEdit）。它用人话叫"反事实对照"的办法——把出错的那个属性替换成它当前错误的样子再预测一遍，两次预测相减就得到一条"从错误指向正确"的修正方向，只沿这个方向改动、压制其它正交的杂散变化，从而不重跑整段生成就把视频改对。最后只对选中的候选做完整渲染，并复用它的缓存轨迹，既省算力又保证预览和成片语义一致。
输入 Input: 原始文本提示词；由此生成的廉价短步数中间预览视频及其缓存的去噪轨迹；以及视觉语言模型对预览逐条语义要求的判定
输出 Output: 经语义纠错后的最终完整视频（81帧，832×480分辨率）
核心机制与技术实现 (Method & Formulation)
  • 保留原生调度器前 $K_p$ 步（如14步）生成低成本预览，实测语义结构在此阶段已基本成形，预览与完整渲染的评估一致率达98.24%，据此在完整渲染前完成语义纠错
  • PreQA 将提示词分解为固定原子要求集 $\mathcal{Q}=\{q_j\}_{j=1}^{M}$，编号 $i$ 的候选对应二值判定 $a_{i,j}\in\{0,1\}$，未满足集 $\mathcal{F}_i=\{q_j:a_{i,j}=0\}$，覆盖度 $S_i=\sum_{j=1}^{M}a_{i,j}$，取 $b_i=\arg\max_{0\le j\le i}S_j$ 作为下一轮纠错起点
  • PreEdit 在失败属性上取观测错误值构造目标条件 $P_i^{tar}$ 与反事实条件 $P_i^{cf}$，用二者预测差估计修正方向，再以分块软投影调制源轨迹更新以抑制正交变化，最多编辑4轮后仅对选中候选做完整渲染
关键评测与消融结论 (Empirical Takeaway)
基于 Wan2.2-T2V-A14B，PreCoG 相较直接生成 VBench 提升1.43、T2V-CompBench 提升7.01、VS2 提升0.146，用时仅2.26倍直接生成；相比 VSR 以0.56倍推理时间取得更高的 VBench/T2V-CompBench 分数。

💡 评估判定：论文聚焦 Mamba-3/选择性状态空间模型的长上下文架构机理，将输入依赖旋转解释为欠阻尼二阶动力学，与目标轨道的 Mamba、状态空间模型和长上下文高度相关；清华人工智能学院权威度高。但工作偏理论解释与机理验证，不是全新推理模型或工程部署方案，故工程分略低。
白话概述：这篇论文追问 Mamba-3 里新加的输入依赖旋转到底有什么用：作者把它看成二阶欠阻尼动力学，也就是状态不会一路单调衰减，而会像弹簧一样边衰减边来回摆动。所谓旋转相位，就是让旧隐状态在传给下一步时改变方向；所谓阻尼，是控制它还留多少、衰减多快。核心发现是这种受控振荡能帮助模型记住和追踪状态、做长上下文预测与长度泛化，而且干预预训练学到的相位会明显掉点，说明它并非装饰。
输入 Input: 变长 token 序列（语言建模的 token IDs/嵌入，或状态追踪任务的符号序列），以及 Mamba-3 循环隐状态、输入依赖的保留系数与旋转相位。
输出 Output: 下一 token 概率分布或长上下文预测/状态追踪结果；并给出把转移矩阵解释为二阶系统后的阻尼比、自然频率等诊断量。
核心机制与技术实现 (Method & Formulation)
  • 将 Mamba-3 的离散衰减-旋转更新 $z_{t+1}=\rho_t R(\theta_t)z_t$ 写成连续时间生成元 $A_t^{\mathrm{rot}}=-a_t I+\nu_t J$，其中 $a_t=-\log\rho_t/\Delta_t$、$\nu_t=\theta_t/\Delta_t$，说明每个旋转步都是该连续流的精确离散。
  • 对旋转状态对消元得到二阶方程 $\ddot{H}=-2a\dot{H}-(a^2+\nu^2)H$，对应自然频率 $\omega_0=\sqrt{a^2+\nu^2}$ 与阻尼比 $\zeta=a/\sqrt{a^2+\nu^2}$；$\zeta<1$ 即欠阻尼振荡。
  • 通过控制实验对比欠阻尼与非振荡阻尼，并在预训练模型中干预学习到的相位，显示振荡能调节保留信息与当前输入的融合，并提升状态追踪和长上下文表现。
关键评测与消融结论 (Empirical Takeaway)
在状态追踪任务上欠阻尼动力学优于非振荡阻尼；语言模型预训练中它提升长上下文预测与长度泛化，干预预训练相位会破坏性能，表明学习到的振荡相位是关键。

S$^3$R: Fast and Faithful RL Rollouts via Self-Sparse Speculative Decoding

💡 评估判定：论文直击大模型推理赛道核心的 KV cache 与长上下文生成效率问题，并在 RLVR 场景给出「稀疏草拟加稠密验证保持组分布一致」的机制与理论命题，属核心算法突破；但为 HKUST(GZ) 单校团队、实验仅覆盖 Qwen3-1.7B/8B 两档模型，权威度与评测广度略低于顶级工业界实验室。
白话概述：论文要解决的是长上下文强化学习（RLVR，即用可验证答案做奖励的强化学习，例如数学题训练）里「让模型生成回答（rollout）太慢」的痛点：作者实测发现，自回归解码时注意力读取 KV cache 占了 72-76% 的时间，于是想用稀疏注意力省算力。但稀疏注意力会改变回答的分布，而 GRPO 这类「组相对」算法要靠同一道题下多条回答互相比较来算优势，分布一变优势就失真——论文进一步证明，即使按每条回答的真实概率做精确重加权也还原不了稠密策略下的组更新，因为一条回答的优势还取决于同组其他回答的奖励。作者因此提出 S3R：用稀疏注意力「草拟」候选 token，再用完整注意力做精确投机采样（speculative sampling，即先用便宜方式快速猜出一串候选 token，再用完整模型逐个验证，接受就保留、被拒位置就从残差分布重新采样）来「验证」，草拟和验证共用同一套策略参数，所以不用额外训练草稿模型，最终采出的回答组分布与稠密策略完全一致；再配一个 KV 感知调度器减少显存反复换入换出。
输入 Input: 长上下文数学推理的题目提示词、已生成的前缀 token 序列，以及稠密策略模型参数与其完整历史 KV cache
输出 Output: 分布与稠密策略一致的响应组（每道题多条完整回答 token 序列）用于强化学习策略优化，以及端到端训练吞吐的加速比
核心机制与技术实现 (Method & Formulation)
  • 指出稀疏采样引入重要性采样失配项 $w_s=\pi^{\mathrm{dense}}_{\theta_{\mathrm{old}}}/\pi^{\mathrm{sparse}}_{\theta_{\mathrm{old}},s}$，并证明（命题1）按每条回答精确权重 $W_i=P(o^i|x)/Q_s(o^i|x)$ 重加权仍无法恢复 GRPO 期望更新，因为优势依赖同组其他回答的奖励
  • 用精确投机采样把稀疏化限定在候选生成环节：以 $\min\{1,p(v)/q_s(v)\}$ 接受草拟 token，被拒位置从残差分布 $r_s(v)=\frac{[p(v)-q_s(v)]_+}{\sum_u[p(u)-q_s(u)]_+}$ 重采样，保证输出响应组分布等于稠密策略分布 $\prod_i P(o^i|x)$
  • 草拟与验证共用同一策略参数，免去独立 draft 模型训练；并以 KV 感知 AIMD 调度器限制稠密验证所需完整历史 KV cache 的反复换出换入，同时维持 rollout 并行度
关键评测与消融结论 (Empirical Takeaway)
在 Qwen3-1.7B/8B 上基于 DAPO-MATH-17k 训练，S3R 相比自回归 rollout 取得 1.39 倍与 1.35 倍端到端训练吞吐加速，且 AIME26 与 ArXiv-Math 的 pass@1 与原方法相当（1.7B 上 37.1/9.89 对 37.2/9.95）。

白话概述：动作分块策略一次预测一长串未来控制,却只执行最前面一小段就重新规划,于是"固定的动作token预算该怎么花"成了关键问题。本文提出Joint Action Chains(JAC):把同一份token预算拆成两条链——稀疏的"参考链"每隔几步取一个较远的未来控制作粗指引,稠密的"执行链"取出紧邻的连续控制作细动作;两条链共用同一套网络参数、放在同一条物理时间轴上一起做去噪,并用有向注意力让执行token能读取参考token、反向则被禁止。通俗地说,就是让一个动作专家"既看得远又做得细",而完全不增加token和参数量。
输入 Input: 当前多视角RGB图像、语言指令、机器人本体感觉(proprioception)、宿主允许的历史动作与缓存,以及宿主世界模型的中间状态
输出 Output: 两条动作链:稀疏的未来控制参考序列(每隔数步采样的未来控制量)与稠密的执行目标序列(近距离连续控制量);推理时只有执行链的前缀被真正下发给机器人作为关节/末端控制
核心机制与技术实现 (Method & Formulation)
  • 在固定预算 $B=n_R+n_A$ 下把目标拆为稀疏参考链 $R_0=[u_0,u_3,\dots,u_{45}]$ 与稠密执行链 $A_0=[u_0,u_1,\dots,u_{15}]$,二者共享同一动作专家的输入输出投影、时间嵌入与Transformer层,仅靠目标、物理位置与可见性区分角色。
  • 两链在同一物理时间轴对齐,位置向量 $p=[0,3,\dots,45;\,0,1,\dots,15]$,以流匹配独立加噪 $R_\sigma=(1-\sigma)R_0+\sigma\epsilon_R$、$A_\sigma=(1-\sigma)A_0+\sigma\epsilon_A$,并用物理时间相对偏移 $3j-i$ 取代拼接槽位偏移。
  • 用有向注意力掩码 $M_{\rm JAC}=M_{\rm host}\land M_{\rm role}$ 实现跨链可见性,其中 $M_{\rm role}|_{R,A}=\begin{bmatrix}1&0\\1&1\end{bmatrix}$,即执行链可读取参考链、参考链不可读取执行链,且不新增任何参数。

白话概述：过去的 JEPA 世界模型要分三步走：先学视觉表征，再学「给定动作后未来画面会变成什么样」的动力学，最后才额外接一个策略或规划器，阶段割裂、规划还慢。LeWAM 把两件事塞进同一个 Mixture-of-Transformers 里端到端联合训练：一边用「潜空间动力学」预测未来的紧凑抽象特征（不重建像素，只预测编码器输出的低维表征，所以省算力、抗无关细节），一边用「动作流匹配」把高斯噪声逐步积分成动作块（流匹配即学习一条从噪声到真实动作的连续速度场，沿它积分就得到动作，比一步回归更适合多模态动作分布）。再用 SIGReg 把潜表征约束成各向同性高斯分布（即让不同观测编码出的向量方向均匀散布、不塌缩成一点），于是同一个模型既能直接输出动作，又能用自己学到的潜动力学在测试时对采样动作做梯度精修来规划。核心直觉是：世界模型与策略共享同一潜空间互相监督，省掉多阶段训练，规划在潜空间里跑比像素级或分阶段方案快数十倍。
输入 Input: 历史多帧 RGB 观测序列与对应历史动作块；视觉规划额外提供目标图像的潜嵌入及距目标的剩余时间步。所有观测（历史、未来目标、目标图）共用同一 ResNet-18 编码器转成潜表征。
输出 Output: 动作条件下的未来潜状态预测，以及流匹配生成的动作块（连续多步控制量）用于直接执行或规划候选；规划时对候选动作块做梯度精修，选出最低代价的动作序列。
核心机制与技术实现 (Method & Formulation)
  • 端到端联合目标：在 Mixture-of-Transformers 上同时优化潜动力学损失 $\mathcal{L}_{\mathrm{dyn}}=\mathbb{E}[\mathrm{MSE}(\hat{\bm{z}}_{t+K},\bm{z}_{t+K})]$ 与动作流匹配损失 $\mathcal{L}_{\mathrm{act}}=\mathbb{E}[\mathrm{MSE}(\hat{\bm{v}}_{t,C},\bm{A}_{t,C}-\bm{\epsilon})]$，其中 $\bm{A}^{(s)}_{t,C}=(1-s)\bm{\epsilon}+s\bm{A}_{t,C}$，且状态查询只读历史潜状态与干净动作、噪声动作 token 只读历史与自身因果前缀，阻断动作分支对干净动作的间接泄漏。

  • 规划时从高斯噪声采样 $N$ 个动作块，各取前 $K$ 步在冻结潜动力学中前向推进，以目标状态代价做梯度下降精修，再选最低代价的 $\bm{A}^{\star}$，比 CEM 采样规划更高效。

白话概述：这类自进化智能体通常只在“怎么做”上下功夫——靠积累经验、反思、攒技能来变强，可一旦它对环境动态的认知本身是错的、缺的或过时的，动作再熟练也照样翻车。EvoBelief 换了个方向：进化“对环境怎么响应的信念”。它把每条环境知识写成一条可被证伪的假设——大白话就是“在什么条件下、做哪个动作、会看到什么结果”，比如“温度升到 80 度以上，样品就会分解”；这种写法的好处是能直接拿去做实验检验：满足条件、执行动作、看结果对不对。当出现“预测和实际不一样”的意外，或某个未知会改变下一步决策时，就触发新假设；随后由平凡任务中的偶发观测（被动证据）或专门设计的干预实验（主动证据）来独立验证；一旦出现反例，就把这条规则的适用范围收窄甚至淘汰。全程语言模型参数不动，每条规则都挂着它的证据链和它改变过的决策。最关键的机制是“授权”：新假设一开始没有任何话语权，必须跨多个回合、多个对象、多次独立测试都成立（达到阈值）后，才被允许用来指导预测和规划；支持不足就降级，持续反例就退役。核心直觉是——让环境知识像科学假设那样可测试、可追溯、可撤销，从而在部署中自己变聪明，而不是靠重训参数。
输入 Input: 智能体与环境的交互历史（每步观测、执行的动作及其真实后果）与任务目标；环境给出文本或符号化的观测。
输出 Output: 持久化的环境动态规则集合（世界模型 $W_t$）、由此产生的下一步预测与规划动作，以及必要时为验证假设而主动选择的干预实验。
核心机制与技术实现 (Method & Formulation)
  • 将世界知识的基本单元定义为可证伪假设 $H := (C \wedge A \Rightarrow Y)$：当条件 $C$ 成立时，执行动作或程序 $A$ 应产生可观测后果 $Y$，使每条知识都能通过“建立 $C$、执行 $A$、检查 $Y$”直接检验。
  • 证据分被动与主动两条路径：被动证据来自恰好检验已有假设的普通任务转移，主动证据来自为消解不确定性或区分竞争假设而专门执行的干预实验；两者写入同一证据记录，并给出支持、反例或不确定三种裁决，反例用于收窄规则适用范围。
  • 引入授权生命周期决定知识能否指导决策：仅当支持证据满足 $N_{ep}(S) \geq \tau_{ep}$、$N_{bind}(S) \geq \tau_{bind}$、$N_{test}(S) \geq \tau_{test}$ 时才提交为已验证规则，且首次形成假设的事件不能单独授予可复用授权；证据不足即降级，持续反例则退役。
