💡 评估判定：该论文直接研究测试期计算扩展，提出模型无关的测试期对称化方法与 $O(\log |G|)$ 重写缩放律，属于推理扩展核心机制突破；虽不涉及测试期权重更新，但与目标轨道中的 test-time compute 与 inference scaling 高度一致。Harvard SEAS 学术声誉强，理论与多模型实验较扎实，工程实现简单但需额外前向计算与可构造的等价重写群。
白话概述：大模型常会因输入写法变化而给出不同答案，比如图节点重新编号、选项顺序打乱或变量改名，但语义其实没变；传统测试期扩展只是在同一个提示上反复采样，很快饱和，覆盖不到其他等价写法。本文把等价改写看成有限群 $G$ 作用下的“轨道”，对每个重写分别让冻结模型解码，得到各自的答案分布或得分，再在重写维度上做群平均，相当于不改模型参数、只靠外部聚合把任务对称性“补”回来。理论证明单表示重复采样不能替代重写，而只需 $O(\log |G|)$ 个随机重写就能近似全部 $|G|$ 个重写的全群平均，且该对数规模一般最优。
输入 Input: 原始文本提示及其等价重写集合（如节点重编号、选项置换、示例重排等），以及冻结语言模型在每个重写提示上的前向采样轨迹或解码分布。
输出 Output: 对重写集合聚合后的答案类别、类别得分向量或最终答案。
核心机制与技术实现 (Method & Formulation)
  • 将提示重写形式化为有限群 $G$ 在提示空间上的作用，语义实例 $x$ 的轨道 $G\cdot x$ 包含全部等价重写；冻结模型在每个重写 $g\cdot x$ 上定义解码纤维 $p_{\theta,\tau}(\cdot\mid g\cdot x)$，并产生响应场 $F_x^{\mathcal{D}}(g)$。
  • 全对称化输出为群平均 $q_x^{\mathcal{D}}=\mathsf{P}_G F_x^{\mathcal{D}}=\frac{1}{|G|}\sum_{g\in G}F_x^{\mathcal{D}}(g)$，仅对重写坐标施加不变性而不抹平答案类别；稀疏随机重写子集平均以 $|S|^{-1/2}$ 误差逼近全群平均，常数至多按 $\sqrt{\log |G|}$ 增长。
  • 证明在单一表示上重复采样与重复解码无法替代重写所提供的信息，而同一组 $O(\log |G|)$ 个随机重写可同时跨模型、解码规则与采样推理轨迹提供近似，且对数缩放一般最优。
关键评测与消融结论 (Empirical Takeaway)
在 $n=24$ 的边计数任务上，64 次重写达到 99.5% 准确率而 64 次原提示重复采样仅 89%，16 次重写已达 100% 而 16 次重复采样为 83%，匹配预算下提升约 16.5 个百分点。

白话概述：LLM 部署后需要监控它是否在做危险或越界的事，现有“激活探针”各有短板：直接读原始激活无法解释，用 SAE（稀疏自编码器，把模型内部激活拆成许多可读的稀疏特征）虽然可解释，却要靠大编码器和加性分类器，内存和延迟都高。GateWatch 的做法是把每个探针的完整判定规则写成少量二值化 SAE 特征上的显式布尔电路，也就是用与、或、非门表达“哪几个可解释特征同时出现就报警”。核心直觉是：监控不必重建全部 16K 特征，只要挑出少数关键特征并配上几个逻辑门，就能接近全量 SAE 探针的精度，同时把部署开销压到极低。
输入 Input: 用户文本或 token 序列经 LLM 前向计算后选定层的内部激活值；部署时只计算并二值化少量被选中的 SAE 特征。
输出 Output: 每个监控探针输出的 0/1 判定，以及由少量 SAE 特征和逻辑门组成的可读布尔决策规则。
核心机制与技术实现 (Method & Formulation)
  • 把探针写成少量二值化 SAE 特征上的显式布尔函数，例如 $f(\mathbf{b})=\bigvee_{k}\bigwedge_{i\in S_k} b_i$，其中 $b_i=\mathbb{1}[a_i(x)>\tau_i]$，并在给定门数预算下构造电路。
  • 比较三种在门预算约束下构造布尔电路的方法，在精度、可解释性与逻辑门数量之间做折中。
  • GateWatchServe 只计算被选中的 SAE 特征，跨层流式传递二值位，并用紧凑查找表并行评估多个多层、多 token 探针，以降低内存与推理延迟。
关键评测与消融结论 (Empirical Takeaway)
在 Gemma-2-9B 的 24 个任务上，平均仅用 3.8 个 SAE 特征和 3.5 个逻辑门达到 80.49% 准确率，仅比 16K 全量 SAE 探针低 1.17 个百分点，探针内存降低 99.98%，vLLM 中 1000 个并发分类器保持 97-98% 吞吐。

白话概述：这篇论文研究符号音乐生成模型在 I…V→I 和声进行中预测终止主和弦根音时，内部到底依靠哪些计算。它把 Transformer 的前向传播拆成 token 之间的加权信息流图，再用 Auto-Emergence 抽出只占不足 6% 连边的稀疏“主电路”，并通过因果消融证明这条子网络是模型做出和声终止判断的主要驱动力。通俗地说，电路发现就是找出模型中真正传递关键信息的少数连边路径；因果干预就是把这些连边关掉，观察输出是否显著变差，从而判断它们是否真的有用，而不是仅凭相关性猜测。
输入 Input: 输入为 ABC 记谱的符号音乐文本前缀，包含调号、拍号、音符、小节线、和弦符号等，序列截断在 I…V→I 进行中最后一个主和弦根音 token 之前。
输出 Output: 输出为下一个 token 的预测分布，核心是终止主和弦的根音音级或音高类别，即模型对最终 tonic root 的预测。
核心机制与技术实现 (Method & Formulation)
  • 用 Information Flow Routes 将 Transformer 每层每个 token 表示建成有向加权图；边 $j\to i$ 的贡献定义为移除注意力归因向量 $\mathbf{a}^{(\ell)}_{i\leftarrow j}$ 后接收状态 $\mathbf{y}^{(\ell)}_i$ 的 $L_1$ 范数下降量，并归一化为下三角贡献矩阵 $\mathbf{C}^{(\ell)}$。
  • Auto-Emergence 从最后输入位置各层残差表示出发，反复在候选池中选择最强的跨 token 边，并递归加入源 token 的低层入边，最终得到稀疏主电路 $\{\mathbf{P}^{(\ell)}\}_{\ell=1}^{L}$。
  • 对每个样本的主电路做因果消融，并与同数量随机边对照，比较目标 tonic 的 logit、rank、top-1 准确率、KL 散度与十二根音 margin，验证该稀疏子网络对和声进行预测的必要性。
关键评测与消融结论 (Empirical Takeaway)
主电路仅包含不足 6% 的跨 token 边，但消融后 ChatMusician 与 MuPT 对终止主和弦根音的预测显著下降，而同数量随机边消融几乎无影响，且在复调 BCMH 数据上仍成立。

白话概述：论文问一个很实在的问题：大模型写出来的推理步骤（CoT，链式思维）到底是它真的在一步步思考，还是先有答案再补一段像样的理由？作者用“机械可解释性”的办法拆开看（也就是不只读模型输出，而是直接读取模型内部的激活）：把每轮推理切成一句一句，只给模型看前几句，反复问它“你觉得对手是谁”“你下一步合作还是背叛”，再从模型内部读出这两个答案的概率；接着做“句子消融”，就是把某一句删掉，看后面句子的预测分布偏了多少（用 KL 散度衡量，即两个概率分布差多远）。结果发现模型真会在推理中形成并不断修正对对手的内部信念，而且一旦过早认定了一个错误信念，基本就改不回来了，这种失败在文字轨迹和内部激活上都看得到。
输入 Input: 自然语言提示（收益矩阵、最近10轮对局历史、游戏将继续的暗示）以及按句切分的推理轨迹前缀；并读取模型末层残差流激活。
输出 Output: 合作/背叛动作的选择及其下一 token 概率、对对手策略类别的信念概率，以及句子间的因果影响度。
核心机制与技术实现 (Method & Formulation)
  • 把每轮 CoT 切成 $c_1,\dots,c_K$，用前缀 $\mathbf{c}_{\le k}$ 做多项选择探测，读取末层残差流的单字母 logits 并做 softmax，得到 $P(\text{act}=\mathtt{D})$ 与 $P(\text{opp}=\text{AllC})$。
  • 句子消融：对删去 $c_i$ 的轨迹 $\mathbf{c}_{-i}$ 与完整轨迹 $\mathbf{c}_{\le K}$，计算后续各句 token 分布的 KL 散度，度量句子 $i$ 对句子 $j$ 的因果影响。
  • 在 250 局迭代囚徒困境中逐句追踪信念与动作概率，归纳出回顾历史、形成并确认对手假设、计算期望收益三类计算阶段。
关键评测与消融结论 (Empirical Takeaway)
250 局迭代囚徒困境显示，CoT 整体提升对手识别准确率与最优动作概率；信念一旦锁定，约五个推理块内即转向背叛，过早锁定错误信念后极少恢复。

💡 评估判定：论文聚焦视频扩散 Transformer 推理加速中的稀疏注意力机制设计，属于视频生成基础模型落地的核心效率环节，机理上有「逐查询路由 + 质心补偿 + 键簇主序分桶内核」的实质创新，而非简单套用；但它是训练无关的推理优化，未改动流匹配/扩散的生成范式或训练目标，故相关性未给到最高档。机构为清华（傅昊桓组）联合哈工大深圳与深信服，声誉良好但非视频生成专属顶尖实验室。
白话概述：视频扩散 Transformer 要同时处理几十万个 token，注意力是绝对的算力瓶颈，于是大家用「稀疏注意力」：不算全部查询-键对，只挑一部分来算。已有方法（SVG2、SVG-EAR 等）为了能在 GPU 上切成规则方块，先把查询和键都做 k-means 聚类，同一个查询簇里的所有查询被迫共享同一张「选哪些键簇」的清单——本文用实验指出这正是精度损失的根源：键簇和密度固定时，查询簇分得越细越准，细到每条查询各选各的（等价于根本不对查询聚类）时最准。据此提出 PQRS：只聚类键，每条查询按自己的注意力分布挑选自己的键簇；对没被选中的键簇，不再直接丢弃，而是用该簇的中心向量近似它的键和值（即「质心补偿」，相当于用一张模糊缩略图代替被裁掉的高清区域），把漏掉的注意力权重和分母一并补回，防止 softmax 归一化被系统性低估。难点在于每条查询清单都不同，凑不成 GPU 喜欢的大块矩阵；作者把遍历顺序反过来以键簇为主序扫描，把清单完全一致的查询归成一桶当作稠密任务一次算完，并复用上一步去噪留下的固定归一化基准单趟合并，让这种不规则稀疏在硬件上依然跑得最快。
输入 Input: 文本提示词（T2V）或首帧图像加提示词（I2V）经 VAE 编码得到的带噪视频 latent token 序列，以及去噪过程中每层每个注意力头的查询、键、值张量
输出 Output: 逐查询路由并经质心补偿后的注意力输出，进而逐步去噪生成 720p 视频 latent 与视频帧
核心机制与技术实现 (Method & Formulation)
  • 逐查询键簇路由：仅对键做 k-means 得到簇心 $\bar{k}_c$，每条查询用自身簇级 logit $z_{ic}=q_i\bar{k}_c^{\top}/\sqrt{D}$ 独立挑选 top-$p$ 键簇集合 $\mathcal{S}_i$，彻底取消查询聚类，使低召回长尾显著改善（P1 由 0.560 升至 0.865）。
  • 质心补偿：对未选中的键簇，用查询自身的 $z_{ic}$ 与簇内 value 均值 $\bar{v}_c$ 近似其贡献，输出为 $\hat{o}_i=\frac{\sum_{j\in M_i}e^{s_{ij}}v_j+\sum_{c\notin\mathcal{S}_i}|K_c|e^{z_{ic}}\bar{v}_c}{\sum_{j\in M_i}e^{s_{ij}}+\sum_{c\notin\mathcal{S}_i}|K_c|e^{z_{ic}}}$，即选择用簇级分数、补偿用逐查询分数，二者解耦。

白话概述：论文针对一个关键痛点：视觉语言驾驶大模型通常只学“输出一串路点”，却学不到“这条轨迹会把车带向什么样的未来”，于是规划与未来场景演化是脱节的。TrajWAM 让同一个规划器的隐层状态额外承担一个辅助任务：把一条具体轨迹编码成“轨迹地址”（一串调制向量），去预测沿这条轨迹行驶时、若干秒后的鸟瞰图（BEV）未来特征；这些特征由冻结的 DINOv3 视觉大模型提供标准答案，使模型逐步对齐这一目标，类似用一位能力很强的视觉基础模型“打分”来蒸馏知识。通俗说，驾驶日志天然自带“这样开，之后看到这样场景”的因果配对，作者据此让模型练习“如果按这条轨迹走，未来会是什么样”的反事实推想；同时再输入一条被人工扰动过的假轨迹，要求假轨迹预测的未来特征与真轨迹预测的未来特征至少拉开一个语义差距，从而迫使模型真正把轨迹和未来场景绑定，而不是忽略轨迹条件乱猜。推理时直接输出路点，这条例外分支不参与，因此不增加部署开销。

输出 Output: 自回归生成未来 4 个自车坐标系下的二维路点（前向、横向），再由 PID 控制器转为底层控制量；训练阶段额外输出 5 个时间视界（0/0.5/1/1.5/2 秒）的 BEV 未来特征预测作为辅助监督
核心机制与技术实现 (Method & Formulation)
  • 动作编码器把轨迹映射为“轨迹地址”嵌入，经 Latent FiLM 对未来世界查询令牌逐通道调制：$\tilde{Q}_{t,\tau}(A)=(1+\Delta\gamma_t(A))\odot Q_{t,\tau}+\beta_t(A)$，FiLM 投影零初始化使训练起点等价于恒等变换，避免破坏预训练规划能力。
